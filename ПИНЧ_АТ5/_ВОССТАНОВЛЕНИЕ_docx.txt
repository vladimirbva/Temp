ВОССТАНОВЛЕНИЕ DOCX ИЗ B64-ЧАСТЕЙ (ПИНЧ_АТ5)

Канал записи на ГВР переносит только текст, поэтому docx хранится в репо в base64-частях.
Сборка: конкатенация частей по порядку, затем декодирование base64. Трим хвостовых
переводов строк допускается — декодер их игнорирует.

Файл: ТКП_ПРАЙНЭМ_АТ-5_рев2.docx — 46 378 байт,
sha256 2c11c6a1e001d7be1f8783a640553aa792ca4f5ff5c9f38897dc0787557ed121
Части: ТКП_ПРАЙНЭМ_АТ-5_рев2.docx.b64_1of5 … _5of5 (прототип b64-канала от 26.11.2026)

Проверка после сборки (Python, из папки ПИНЧ_АТ5):
python -c "import base64,hashlib;d=b''.join(open('ТКП_ПРАЙНЭМ_АТ-5_рев2.docx.b64_%dof5'%i,'rb').read() for i in (1,2,3,4,5));r=base64.b64decode(d);print(len(r),hashlib.sha256(r).hexdigest())"
Ожидается: 46378 2c11c6a1e001d7be1f8783a640553aa792ca4f5ff5c9f38897dc0787557ed121
