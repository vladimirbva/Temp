# ГВР / GVR — временный репозиторий GitHub

**Версия:** 1.0 (26.11.2026, указание владельца).

---

## Обозначение
- «ГВР» (латиницей «GVR») — сокращение владельца для временного репозитория GitHub:
  **https://github.com/vladimirbva/Temp**
  Аккаунт: vladimirbva, ветка по умолчанию: main.
- Обозначение распознаётся в ЛЮБОМ регистре (ГВР, Гвр, гвр, GVR, Gvr, gvr) и в
  обеих раскладках/алфавитах (рус/лат); команды владельца в целом — в любом регистре
  и в обеих раскладках, если из текста не следует иное.

## Применение команд
- Команды вида «запиши», «удали», «считай», «посмотри в папке Х на ГВР»
  (и близкие по смыслу: «положи», «проверь», «покажи», «что в папке Х») —
  относятся к работе с плагином GitHub по репозиторию ГВР:
  путь «папка Х» = каталог/путь внутри vladimirbva/Temp.
- Исключение: если из команды владельца явно указан другой репозиторий или
  канал — действует то, что указано явно.
- Неоднозначность (например, идёт параллельная работа с другим репозиторием) —
  одним коротким уточнением, не догадкой.

## Сфера действия
- Сокращение действует во всех проектах и всех сессиях, как любая команда
  владельца; правки в ГВР — по явной команде, «не трогать без команды».
