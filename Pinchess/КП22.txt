установки АТ-5 Ильского НПЗ. Вход: потоки (горячие источники + холодный приёмник-нефть),

Критерии владельца (не ломать): strict на факт-сцене АТ-5 Q_best ≥ 27,85 МВт (достигнуто

## 1. Описание задачи: узлы и что у них болит

Узел 1 — Физика узла (Simulator): фикс-точка Q при фиксированных K/UA; перекрестия напоров
(ThIn < TcOut) трактуются как «спящий» аппарат (Q=0, FailureClass=PINCH). Спорное: сходимость
fine (NIterMax=1000 на факт-сцене), критерий сходимости (по Q И по ΔT), Вегстейн/релаксация.

Узел 2 — Верхние оценки (UpperBound + PtaCascade): хвостовая UB (интеграл ∫min по парам
остаточных сегментов), аппаратная UB (сумма max_duty), глобальная UB — теперь PTA-каскад.
Спорное: строгость UB при перекрестиях в допуске SleepTolC (кумулятивный эффект по цепочке),
Э2 (хвостовая UB не покрывает перестановки R1).

Узел 3 — Поиск (SearchEngine): strict DFS (протокол В: R2→R3→остальные) + beam с архивом и
rescue; чекпоинт/resume; локальный подъём RefineBest от Best; лексикография M1 при равном Q.
Спорное: порядок обхода/детерминизм (закрыто v22.1 — Ordinal), строгий скан на новой глобальной
грани не замерен.

Узел 4 — Генерация ходов (Moves/StateOps): R1 перестановка (без сдвига — отозвано), R2 вставка,
R3 деление (MVP: одно на поток), R4 байпас, R5 изъятие, R1PairSwap (только для RefineBest).
Спорное: причина регресса At5Economy от ShiftSide не установлена (гипотеза — якоря ветвлений).

Узел 5 — Целевая функция: сейчас Q-максимум; IObjective добавлен (QMax бит-в-бит + FurnaceFuel),
к движку не подключён (нужен перевод правил в домен критерия). Спорное: fuel ≠ монотонная
функция Q при нескольких печных потоках.

namespace Pinchess.Engine.Sim;

using Pinchess.Engine.Domain;

/// <summary>Уровень расчёта: coarse — K=K0, энтальпийные кривые; fine — корреляции (S4).</summary>
public enum SimLevel { Coarse, Fine }

/// <summary>Результат расчёта одного аппарата.</summary>
public sealed record AppCalc(
    string ApparatusId,
    double ThInC, double ThOutC,
    double TcInC, double TcOutC,
    double QMw,
    double QHotMaxMw, double QColdMaxMw,
    int Iterations,
    bool Converged,
    string? FailureClass)
{
    /// <summary>Б1 (аудит 20.11): фактическая горячая нагрузка узла (энтальпия Δh·m·frac), МВт;
    /// заполняется только финальным расчётом узла; топология/байпас — 0/0 (правило П7 их пропускает).</summary>
    public double QHotMw { get; init; }
    public double QColdMw { get; init; }
}

/// <summary>Результат расчёта схемы.</summary>
public sealed class SimResult
{
    public List<AppCalc> Apparatus { get; } = new();
    /// <summary>Сошлись ли локальные фикс-точки всех аппаратов И глобальная итерация схемы.</summary>
    public bool AllConverged => GlobalConverged && Apparatus.All(a => a.Converged &&
        (a.FailureClass is null || (a.FailureClass == FailureClass.Pinch && Math.Abs(a.QMw) <= 1e-12)));
    public bool GlobalConverged { get; set; }
    public int GlobalIterations { get; set; }
    public double QTotalMw => Apparatus.Sum(a => a.QMw);
    public string? FirstFailure => Apparatus.FirstOrDefault(a => a.FailureClass is not null)?.FailureClass
        ?? (GlobalConverged ? null : FailureClass.Iterations);
}

/// <summary>Классификация причин несходимости (П8): PINCH, ITERATIONS, K0_MISSING, TOPOLOGY.</summary>
public static class FailureClass
{
    public const string Pinch = "PINCH";
    public const string Iterations = "ITERATIONS";
    public const string K0Missing = "K0_MISSING";
    public const string Topology = "TOPOLOGY";
}

/// <summary>
/// Симулятор последовательных схем (S3, coarse) с делениями потоков (S8, шаг 2а).
/// Двухфазный решатель: (1) проходы-волна по цепочкам (аппарат считается, когда вход
/// посчитан в этом проходе); противоточные взаимозависимости (A1↔A2) решаются
/// (2) глобальными итерациями Гаусса–Зейделя: вход берётся из последнего известного
/// выхода, при первом проходе — стартовая температура потока. Сходимость: max |ΔQ|
/// по аппаратам ≤ eps_conv·max(|Q|, 1e-6), лимит N_iter из CutParameters (П8).
/// S8: аппараты в ветвях делений считаются с долей расхода ветви (HotFraction/ColdFraction);
/// ветви сходятся в смеситель — энтальпийное смешение с прямыми (незанятыми) частями ветвей.
/// Rециклы/контуры и fine-физика — S4. Q — МВт; расход кг/ч; H — кДж/кг.
/// </summary>
public sealed class Simulator
{
    private readonly ProjectSpec _project;
    private readonly Dictionary<string, FlowSpec> _flows;
    // Б15/М6 (v19): история Вегстейна — xPrev (вход) и fPrev (выход прошлого прохода)
    private readonly Dictionary<string, (double xTh, double xTc)> _wegPrev = new();
    private readonly Dictionary<string, (double xTh, double xTc, double fTh, double fTc)> _wegHist = new();
    private readonly Dictionary<string, ApparatusSpec> _apps;
    private readonly Dictionary<string, EnthalpyCurve> _curves;
    private readonly Props.EnvironmentService _svc;

    public Simulator(ProjectSpec project)
    {
        _project = project;
        _flows = project.Flows.ToDictionary(f => f.Id);
        _apps = project.Apparatus.ToDictionary(a => a.Id);
        _curves = project.Environments.ToDictionary(e => e.Id, e => new EnthalpyCurve(e));
        _svc = new Props.EnvironmentService(project);
    }

    private Dictionary<string, AppInstance> _hotInst = new();
    private Dictionary<string, AppInstance> _coldInst = new();
    private Dictionary<(string FlowId, int Pos), AppInstance> _hotByPos = new();
    private Dictionary<(string FlowId, int Pos), AppInstance> _coldByPos = new();
    private Dictionary<string, PathInfo> _hotInfo = new();
    private Dictionary<string, PathInfo> _coldInfo = new();
    private Dictionary<string, SplitSpec> _splitByFlow = new();

    /// <summary>Путь аппарата по его стороне: ветвь деления или целый поток («P0»).</summary>
    private string PathOf(AppInstance inst) =>
        inst.Side == Side.Hot ? inst.HotPathId : inst.ColdPathId;

    /// <summary>Информация о входе аппарата: предшественник в пути или смесь ветвей.</summary>
    private sealed record PathInfo(AppInstance? Pred, MixSpec? Mix);

    /// <summary>Смесь в точке слияния деления: выходы последних аппаратов занятых ветвей + прямая доля незанятых.</summary>
    private sealed record MixSpec(
        List<(AppInstance Last, double Frac)> BranchTails,
        double DirectFrac,
        AppInstance? Anchor);

    public SimResult Simulate(IReadOnlyList<AppInstance> committed, SimLevel level = SimLevel.Coarse) =>
        SimulateWithSplits(committed, Array.Empty<SplitSpec>(), level);

    /// <summary>Расчёт состояния с делениями потоков (S8).</summary>
    public SimResult Simulate(State state, SimLevel level = SimLevel.Coarse) =>
        SimulateWithSplits(state.Committed, state.Splits, level);

    private SimResult SimulateWithSplits(IReadOnlyList<AppInstance> committed, IReadOnlyList<SplitSpec> splits, SimLevel level)
    {
        var cp = _project.Parameters;
        var result = new SimResult();

        _hotInst = committed.Where(i => i.Side == Side.Hot).GroupBy(i => i.ApparatusId, StringComparer.Ordinal)
            .ToDictionary(g => g.Key, g => g.First());
        _coldInst = committed.Where(i => i.Side == Side.Cold).GroupBy(i => i.ApparatusId, StringComparer.Ordinal)
            .ToDictionary(g => g.Key, g => g.First());
        _hotByPos = committed.Where(i => i.Side == Side.Hot)
            .ToDictionary(i => (i.FlowId, i.PositionIndex));
        _coldByPos = committed.Where(i => i.Side == Side.Cold)
            .ToDictionary(i => (i.FlowId, i.PositionIndex));
        _splitByFlow = splits.GroupBy(s => s.FlowId, StringComparer.Ordinal).ToDictionary(g => g.Key, g => g.First());

        // S1 (ревью-3, класс 1.5-историй): история Вегстейна — поле экземпляра; между симуляциями
        // (rescue, SplitRefiner, статистика) аппарат с тем же Id встречается с другими потоками —
        // старая история дала бы ложные шаги ускорителя. Сброс на каждом расчёте.
        _wegPrev.Clear();
        _wegHist.Clear();

        // входные пути по сторонам (S8): ветви, якоря, точки слияния
        _hotInfo = BuildPathInfo(_hotByPos, Side.Hot);
        _coldInfo = BuildPathInfo(_coldByPos, Side.Cold);

        var order = committed.Select(i => i.ApparatusId).Distinct().ToList();
        // байпас-аппараты вне цепочки: Q = 0, температуры не меняются
        var bypassIds = committed.Where(i => i.Bypass).Select(i => i.ApparatusId).ToHashSet();
        var activeOrder = order.Where(id => !bypassIds.Contains(id)).ToList();
        // порядок раскрытия: по возрастанию позиции в обеих цепочках — быстрее волна
        var ordered = activeOrder
            .OrderBy(id => _hotInst.TryGetValue(id, out var h) ? h.PositionIndex : 0)
            .ThenBy(id => _coldInst.TryGetValue(id, out var c) ? c.PositionIndex : 0)
            .ToList();

        var lastOut = new Dictionary<string, (double ThOut, double TcOut, double Q)>();
        var calcById = new Dictionary<string, AppCalc>();
        bool usedGuess;
        bool globalConverged = false;
        int globalIter;

        for (globalIter = 0; globalIter < cp.NIterMax; globalIter++)
        {
            usedGuess = false;
            calcById.Clear();
            calcCurrent = calcById; // ResolveInput читает расчёты текущего прохода
            var computedThisPass = new HashSet<string>();

            // проход-волна: повторяем до прогресса, чтобы раскрыть цепочки
            while (computedThisPass.Count < activeOrder.Count)
            {
                bool progress = false;
                foreach (var appId in ordered.Where(id => !computedThisPass.Contains(id)))
                {
                    if (!_hotInst.TryGetValue(appId, out var hotInst) || !_coldInst.TryGetValue(appId, out var coldInst))
                    {
                        calcById[appId] = new AppCalc(appId, double.NaN, double.NaN, double.NaN, double.NaN,
                            0, 0, 0, 0, false, FailureClass.Topology);
                        computedThisPass.Add(appId);
                        progress = true;
                        continue;
                    }

                    var hotIn = ResolveInput(_hotInfo[appId], Side.Hot, hotInst.FlowId, computedThisPass, lastOut, ref usedGuess);
                    var coldIn = ResolveInput(_coldInfo[appId], Side.Cold, coldInst.FlowId, computedThisPass, lastOut, ref usedGuess);
                    if (!hotIn.Ready || !coldIn.Ready) continue; // вход посчитается позже в этом проходе

                    if (hotIn.Failure is not null || coldIn.Failure is not null || double.IsNaN(hotIn.T) || double.IsNaN(coldIn.T))
                    {
                        calcById[appId] = new AppCalc(appId, hotIn.T, hotIn.T, coldIn.T, coldIn.T,
                            0, 0, 0, 0, false, hotIn.Failure ?? coldIn.Failure ?? FailureClass.Topology);
                        computedThisPass.Add(appId);
                        progress = true;
                        continue;
                    }

                    calcById[appId] = SimulateApparatus(appId, hotIn.T, coldIn.T, level);
                    computedThisPass.Add(appId);
                    progress = true;
                }

                if (!progress && computedThisPass.Count < order.Count)
                {
                    // цикл не раскрылся — но глобальная итерация всё равно продолжится по lastOut
                    foreach (var appId in ordered.Where(id => !computedThisPass.Contains(id)))
                    {
                        if (!_hotInst.TryGetValue(appId, out var h) || !_coldInst.TryGetValue(appId, out var c)) continue;
                        var hotIn = ResolveInput(_hotInfo[appId], Side.Hot, h.FlowId, computedThisPass, lastOut, ref usedGuess);
                        var coldIn = ResolveInput(_coldInfo[appId], Side.Cold, c.FlowId, computedThisPass, lastOut, ref usedGuess);
                        if (hotIn.Failure is not null || coldIn.Failure is not null || double.IsNaN(hotIn.T) || double.IsNaN(coldIn.T))
                        {
                            calcById[appId] = new AppCalc(appId, hotIn.T, hotIn.T, coldIn.T, coldIn.T,
                                0, 0, 0, 0, false, hotIn.Failure ?? coldIn.Failure ?? FailureClass.Topology);
                        }
                        else
                        {
                            calcById[appId] = SimulateApparatus(appId, hotIn.T, coldIn.T, level);
                        }
                        computedThisPass.Add(appId);
                    }
                }
            }

            // глобальная сходимость: max |ΔQ| И max |ΔT| по аппаратам против прошлого прохода (М3, аудит
            // 20.11: по-Q-критерий допускает колебания температур после схождения Q; стандарт HEN —
            // температурный критерий). coarse — не применяется (скорость слоя; допуски — ТЗ Р7).
            double maxDelta = 0;
            double maxDeltaT = 0;
            foreach (var (appId, calc) in calcById)
            {
                if (lastOut.TryGetValue(appId, out var prev))
                {
                    maxDelta = Math.Max(maxDelta, Math.Abs(calc.QMw - prev.Q));
                    maxDeltaT = Math.Max(maxDeltaT,
                        Math.Max(Math.Abs(calc.ThOutC - prev.ThOut), Math.Abs(calc.TcOutC - prev.TcOut)));
                }
            }
            bool allTrivial = calcById.Values.All(a => Math.Abs(a.QMw) <= 1e-12);
            bool firstPass = globalIter == 0 || lastOut.Count == 0;
            double epsT = level == SimLevel.Coarse ? double.PositiveInfinity : 0.2;
            if (!firstPass && (allTrivial || (maxDelta <= cp.EpsConv * Math.Max(1e-6, calcById.Values.Count == 0 ? 0 : calcById.Values.Max(a => Math.Abs(a.QMw))) && maxDeltaT <= epsT)))
            {
                globalConverged = true;
                globalIter++;
                break;
            }

            // S1 (ревью-3, 1.2): prevOut — значения ПРЕДЫДУЩЕГО прохода (lastOut ДО Clear).
            // Раньше lastOut.Clear() стоял прямо перед заполнением — ветка релаксации
            // (TryGetValue по только что очищенному словарю) никогда не выполнялась:
            // RelaxAlpha и Вегстейн были мёртвым кодом; вывод v19 «21 итерация — информационный
            // минимум» сравнивал две одинаковые реализации и ОТЗЫВАЕТСЯ.
            var prevOut = new Dictionary<string, (double ThOut, double TcOut, double Q)>(lastOut);
            lastOut.Clear();
            foreach (var (appId, calc) in calcById)
            {
                // релаксация (CutParameters.RelaxAlpha): при α<1 — сглаживание выходов между проходами
                // стабилизирует жёсткие петли (факт-сцены с большими UA); при α=1 — прежнее поведение.
                // Б15/М6 (v19): UseWegstein — Вегстейн-ускорение: x_{n+1} = x_n + (f_n − x_n)/(1 − q),
                // q = (f_n − f_{n−1})/(x_n − x_{n−1}), кламп q ∈ [0; 0,9].
                if (cp.UseWegstein && _wegPrev.TryGetValue(appId, out var wp) && _wegHist.TryGetValue(appId, out var wh))
                {
                    double q1 = Math.Abs(calc.ThOutC - wh.fTh) > 1e-12 && Math.Abs(wp.xTh - wh.xTh) > 1e-12
                        ? (calc.ThOutC - wh.fTh) / (wp.xTh - wh.xTh) : 0.5;
                    double q2 = Math.Abs(calc.TcOutC - wh.fTc) > 1e-12 && Math.Abs(wp.xTc - wh.xTc) > 1e-12
                        ? (calc.TcOutC - wh.fTc) / (wp.xTc - wh.xTc) : 0.5;
                    q1 = Math.Clamp(q1, 0.0, 0.9); q2 = Math.Clamp(q2, 0.0, 0.9);
                    // S1: ограничитель шага — новый x не дальше 2× классического шага (иначе
                    // при q→0,9 шаг ×10 уводит факт-сцену из сходимости)
                    double dx1 = calc.ThOutC - wp.xTh, dx2 = calc.TcOutC - wp.xTc;
                    double x1 = wp.xTh + dx1 / (1.0 - q1);
                    double x2 = wp.xTc + dx2 / (1.0 - q2);
                    x1 = Math.Clamp(x1, Math.Min(wp.xTh, calc.ThOutC) - Math.Abs(dx1),
                                    Math.Max(wp.xTh, calc.ThOutC) + Math.Abs(dx1));
                    x2 = Math.Clamp(x2, Math.Min(wp.xTc, calc.TcOutC) - Math.Abs(dx2),
                                    Math.Max(wp.xTc, calc.TcOutC) + Math.Abs(dx2));
                    lastOut[appId] = (x1, x2, calc.QMw);
                }
                else if (cp.RelaxAlpha < 1.0 && prevOut.TryGetValue(appId, out var prevL))
                {
                    double ra = cp.RelaxAlpha;
                    lastOut[appId] = (prevL.ThOut + ra * (calc.ThOutC - prevL.ThOut),
                                      prevL.TcOut + ra * (calc.TcOutC - prevL.TcOut),
                                      prevL.Q + ra * (calc.QMw - prevL.Q));
                }
                else
                {
                    lastOut[appId] = (calc.ThOutC, calc.TcOutC, calc.QMw);
                }
                // S1 (ревью-3, 1.2): история Вегстейна ведётся безусловно при UseWegstein —
                // раньше _wegHist заполнялся только в мёртвых ветках, ускорение не включалось;
                // x_n для следующего шага — ПРИНЯТОЕ значение (lastOut), а не сырой выход аппарата.
                if (cp.UseWegstein)
                {
                    var lo = lastOut[appId];
                    if (_wegPrev.TryGetValue(appId, out var wprev))
                        _wegHist[appId] = (wprev.xTh, wprev.xTc, calc.ThOutC, calc.TcOutC);
                    _wegPrev[appId] = (lo.ThOut, lo.TcOut);
                }
            }
        }

        // байпас-аппараты: вне цепочки, теплопередачи нет
        foreach (var appId in bypassIds)
        {
            double tH = _hotInst.TryGetValue(appId, out var hi) ? _flows[hi.FlowId].TStartC : double.NaN;
            double tC = _coldInst.TryGetValue(appId, out var ci) ? _flows[ci.FlowId].TStartC : double.NaN;
            calcById[appId] = new AppCalc(appId, tH, tH, tC, tC, 0, 0, 0, 0, true, null);
        }

        result.GlobalConverged = globalConverged;
        result.GlobalIterations = globalIter;
        result.Apparatus.AddRange(order.OrderBy(id => id, StringComparer.Ordinal).Select(id => calcById[id]));
        return result;
    }

    private sealed record InputState(bool Ready, double T, string? Failure);

    /// <summary>
    /// Входные пути стороны (S8): предшественники внутри путей и смесители делений.
    /// Один путь «P0» — целая цепочка; ветви деления — отдельные цепочки от входа сегмента
    /// (выход якоря) до смесителя; смеситель — вход первого аппарата пути P0 после точки слияния.
    /// </summary>
    private Dictionary<string, PathInfo> BuildPathInfo(Dictionary<(string FlowId, int Pos), AppInstance> byPos, Side side)
    {
        var info = new Dictionary<string, PathInfo>();
        foreach (var flowGroup in byPos.Values.GroupBy(i => i.FlowId))
        {
            string flowId = flowGroup.Key;
            _splitByFlow.TryGetValue(flowId, out var split);
            if (split is null || split.IsHot != (side == Side.Hot))
            {
                // без деления — прежняя логика предшественников
                var chain = flowGroup.OrderBy(i => i.PositionIndex).Where(i => !i.Bypass).ToList();
                for (int i = 0; i < chain.Count; i++)
                    info[chain[i].ApparatusId] = new PathInfo(i == 0 ? null : chain[i - 1], null);
                continue;
            }

            // деление: пути P0 (до якоря — до деления; после слияния — после), ветви A/B
            var all = flowGroup.Where(i => !i.Bypass).OrderBy(i => i.PositionIndex).ToList();
            var chainP0 = all.Where(i => PathOf(i) == "P0").ToList();
            var branchA = all.Where(i => PathOf(i) == split.PathIdA).ToList();
            var branchB = all.Where(i => PathOf(i) == split.PathIdB).ToList();

            for (int i = 0; i < chainP0.Count; i++)
                info[chainP0[i].ApparatusId] = new PathInfo(i == 0 ? null : chainP0[i - 1], null);
            for (int i = 0; i < branchA.Count; i++)
                info[branchA[i].ApparatusId] = new PathInfo(
                    i == 0 ? AnchorInst(split, chainP0, branchA, branchB, flowId) : branchA[i - 1], null);
            for (int i = 0; i < branchB.Count; i++)
                info[branchB[i].ApparatusId] = new PathInfo(
                    i == 0 ? AnchorInst(split, chainP0, branchA, branchB, flowId) : branchB[i - 1], null);

            // смеситель: первый аппарат пути P0 после точки слияния
            int maxBranchPos = -1;
            if (branchA.Count > 0) maxBranchPos = Math.Max(maxBranchPos, branchA[^1].PositionIndex);
            if (branchB.Count > 0) maxBranchPos = Math.Max(maxBranchPos, branchB[^1].PositionIndex);
            int splitAfterPos = AnchorPos(split, chainP0);
            if (maxBranchPos < 0) maxBranchPos = splitAfterPos;

            var afterMerge = chainP0.Where(i => i.PositionIndex > maxBranchPos).OrderBy(i => i.PositionIndex).ToList();
            if (afterMerge.Count == 0) continue; // слияние в конце потока — учитывает ResidualTails

            double fracA = Math.Clamp(split.FractionA, 0.0, 1.0);
            var tails = new List<(AppInstance, double)>();
            if (branchA.Count > 0) tails.Add((branchA[^1], fracA));
            if (branchB.Count > 0) tails.Add((branchB[^1], 1.0 - fracA));
            double direct = (branchA.Count == 0 ? fracA : 0) + (branchB.Count == 0 ? 1.0 - fracA : 0);
            AppInstance? anchorInst = AnchorInst(split, chainP0, branchA, branchB, flowId);
            var mix = new MixSpec(tails, direct, anchorInst);
            info[afterMerge[0].ApparatusId] = new PathInfo(null, mix);
        }
        return info;
    }

    private AppInstance? AnchorInst(SplitSpec split, List<AppInstance> chainP0, List<AppInstance> branchA, List<AppInstance> branchB, string flowId)
    {
        if (split.AnchorApparatusId.Length == 0) return null;
        return chainP0.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId)
            ?? _hotByPos.Values.Concat(_coldByPos.Values).FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId);
    }

    private static int AnchorPos(SplitSpec split, List<AppInstance> chainP0)
    {
        if (split.AnchorApparatusId.Length == 0) return -1;
        var anchor = chainP0.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId);
        return anchor?.PositionIndex ?? -1;
    }

    private InputState ResolveInput(
        PathInfo pathInfo, Side side, string flowId,
        HashSet<string> computedThisPass,
        Dictionary<string, (double ThOut, double TcOut, double Q)> lastOut,
        ref bool usedGuess)
    {
        var flow = _flows[flowId];

        if (pathInfo.Mix is not null)
        {
            var mix = pathInfo.Mix;
            var curve = _curves[flow.EnvironmentId];
            double hSum = 0;
            double wSum = 0;
            foreach (var (last, frac) in mix.BranchTails)
            {
                double? t = OutTemp(last, side, computedThisPass, lastOut, fallback: null);
                if (t is null)
                {
                    // ветвь ещё не посчитана — грубое приближение: вход сегмента
                    usedGuess = true;
                    double anchorT = flow.TStartC;
                    if (mix.Anchor is not null && OutTemp(mix.Anchor, side, computedThisPass, lastOut, fallback: null) is { } at)
                        anchorT = at;
                    t = anchorT;
                }
                hSum += frac * curve.H(t.Value);
                wSum += frac;
            }
            if (mix.DirectFrac > 0)
            {
                double anchorT = flow.TStartC;
                if (mix.Anchor is not null && OutTemp(mix.Anchor, side, computedThisPass, lastOut, fallback: null) is { } at)
                    anchorT = at;
                hSum += mix.DirectFrac * curve.H(anchorT);
                wSum += mix.DirectFrac;
            }
            if (wSum <= 0) return new InputState(true, flow.TStartC, null);
            return new InputState(true, curve.T(hSum / wSum), null);
        }

        var pred = pathInfo.Pred;
        if (pred is null)
            return new InputState(true, flow.TStartC, null); // первый в эффективной цепочке

        if (computedThisPass.Contains(pred.ApparatusId))
        {
            var predCalc = calcCurrent![pred.ApparatusId];
            double t = side == Side.Hot ? predCalc.ThOutC : predCalc.TcOutC;
            return double.IsNaN(t)
                ? new InputState(true, double.NaN, FailureClass.Topology)
                : new InputState(true, t, null);
        }

        usedGuess = true;
        if (lastOut.TryGetValue(pred.ApparatusId, out var lo))
            return new InputState(true, side == Side.Hot ? lo.ThOut : lo.TcOut, null);
        return new InputState(true, flow.TStartC, null); // первое приближение — старт потока
    }

    private double? OutTemp(AppInstance inst, Side side, HashSet<string> computedThisPass, Dictionary<string, (double ThOut, double TcOut, double Q)> lastOut, double? fallback)
    {
        if (computedThisPass.Contains(inst.ApparatusId) && calcCurrent!.TryGetValue(inst.ApparatusId, out var calc))
            return side == Side.Hot ? calc.ThOutC : calc.TcOutC;
        if (lastOut.TryGetValue(inst.ApparatusId, out var lo))
            return side == Side.Hot ? lo.ThOut : lo.TcOut;
        return fallback;
    }

    private Dictionary<string, AppCalc>? calcCurrent;

    private AppCalc SimulateApparatus(string appId, double thIn, double tcIn, SimLevel level)
    {
        var hotInst = _hotInst[appId];
        var coldInst = _coldInst[appId];
        var hotFlow = _flows[hotInst.FlowId];
        var coldFlow = _flows[coldInst.FlowId];
        var app = _apps[appId];
        var hotCurve = _curves[hotFlow.EnvironmentId];
        var coldCurve = _curves[coldFlow.EnvironmentId];
        var cp = _project.Parameters;

        // S8: аппарат в ветви — доля расхода ветви
        double mh = hotFlow.FlowRateKgH * Math.Clamp(hotInst.HotFraction, 0, 1);
        double mc = coldFlow.FlowRateKgH * Math.Clamp(coldInst.ColdFraction, 0, 1);
        // Терминирующие нагрузки (МВт): горячий до TTarget, холодный до TTarget
        double qHotMax = Thermo.KjPerHourToMw(mh * (hotCurve.H(thIn) - hotCurve.H(hotFlow.TTargetC)));
        double qColdMax = Thermo.KjPerHourToMw(mc * (coldCurve.H(coldFlow.TTargetC) - coldCurve.H(tcIn)));
        double qMax = Math.Max(0, Math.Min(qHotMax, qColdMax));

        if (app.AreaM2 <= 0 || app.K0Wm2K <= 0)
            return new AppCalc(appId, thIn, thIn, tcIn, tcIn, 0, qHotMax, qColdMax, 0, false, FailureClass.K0Missing);

        double k = level == SimLevel.Coarse ? app.K0Wm2K : FineK0(app, hotFlow, coldFlow, thIn, tcIn, mh, mc);
        double uaMwK = app.AreaM2 * k / 1e6; // МВт/К

        double q = 0;
        int iter;
        bool converged = false;
        string? failure = null;
        double kCur = k;
        double thOutPrev = thIn;
        double tcOutPrev = tcIn;

        for (iter = 1; iter <= cp.NIterMax; iter++)
        {
            // fine-слой: K пересчитывается по текущим температурам на каждой итерации
            if (level == SimLevel.Fine)
                kCur = FineK(app, hotFlow, coldFlow, thIn, thOutPrev, tcIn, tcOutPrev, mh, mc);
            double ua = app.AreaM2 * kCur / 1e6;

            // q (МВт) → кДж/ч: q·3.6e6; → кДж/кг: q·3.6e6/m
            double thOut = hotCurve.T(hotCurve.H(thIn) - q * 3.6e6 / mh);
            double tcOut = coldCurve.T(coldCurve.H(tcIn) + q * 3.6e6 / mc);
            thOutPrev = thOut; tcOutPrev = tcOut;
            double d1 = thIn - tcOut;
            double d2 = thOut - tcIn;
            if (d1 <= 0 || d2 <= 0)
            {
                // S8-дополнение: перекрестие напоров = корректное «выключение» аппарата:
                // Q=0 — детерминированный физический режим (нет напора — нет теплообмена).
                // Классификация PINCH сохраняется для отчётности; при Q=0 она не считается
                // несходимостью (см. SimResult.AllConverged) — П8 не режет «спящие» аппараты
                q = 0;
                converged = true;
                failure = FailureClass.Pinch;
                break;
            }
            double qNew = Math.Clamp(ua * Thermo.Lmtd(d1, d2), 0, qMax);
            if (Math.Abs(qNew - q) <= cp.EpsConv * Math.Max(Math.Abs(qNew), 1e-9))
            {
                q = qNew;
                converged = true;
                break;
            }
            q = 0.5 * (q + qNew); // релаксация против осцилляции фиксированной точки
        }

        if (!converged && failure is null) failure = FailureClass.Iterations;

        double thOutFinal = hotCurve.T(hotCurve.H(thIn) - q * 3.6e6 / mh);
        double tcOutFinal = coldCurve.T(coldCurve.H(tcIn) + q * 3.6e6 / mc);
        // Б1 (аудит 20.11): фактические нагрузки сторон сохраняются отдельно — правило П7
        // проверяет невязку по ним (в однородной модели узла они согласованы по построению;
        // рассинхрон появится при фазовых переходах/Network-смесителях — теперь он ЛОВИТСЯ)
        double qhMw = Thermo.KjPerHourToMw(mh * (hotCurve.H(thIn) - hotCurve.H(thOutFinal)));
        double qcMw = Thermo.KjPerHourToMw(mc * (coldCurve.H(tcOutFinal) - coldCurve.H(tcIn)));
        return new AppCalc(appId, thIn, thOutFinal, tcIn, tcOutFinal, q, qHotMax, qColdMax, iter, converged, failure)
        {
            QHotMw = qhMw,
            QColdMw = qcMw,
        };
    }

    /// <summary>Fine-слой: K по корреляциям с нормировкой на K0 (S4); S8 — расход ветви vs номинал потока.</summary>
    private double FineK0(ApparatusSpec app, FlowSpec hotFlow, FlowSpec coldFlow, double thIn, double tcIn, double mh, double mc)
    {
        var hot = new Physics.SideContext(hotFlow.EnvironmentId, mh, hotFlow.FlowRateKgH, thIn, thIn, true);
        var cold = new Physics.SideContext(coldFlow.EnvironmentId, mc, coldFlow.FlowRateKgH, tcIn, tcIn, false);
        return Physics.FinePhysics.K(app, hot, cold, _svc, _project.Parameters.KMin, _project.Parameters.KMax, _project.Parameters.KHardMultMax);
    }

    private double FineK(ApparatusSpec app, FlowSpec hotFlow, FlowSpec coldFlow, double thIn, double thOut, double tcIn, double tcOut, double mh, double mc)
    {
        var hot = new Physics.SideContext(hotFlow.EnvironmentId, mh, hotFlow.FlowRateKgH, thIn, thOut, true);
        var cold = new Physics.SideContext(coldFlow.EnvironmentId, mc, coldFlow.FlowRateKgH, tcIn, tcOut, false);
        return Physics.FinePhysics.K(app, hot, cold, _svc, _project.Parameters.KMin, _project.Parameters.KMax, _project.Parameters.KHardMultMax);
    }
}









### 3.2 FinePhysics.cs — физика fine-слоя (полный листинг)

```csharp









namespace Pinchess.Engine.Physics;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Log;
using Pinchess.Engine.Props;

/// <summary>Сторона аппарата для расчёта физики.</summary>
public sealed record SideContext(
    string EnvironmentId,
    double RateKgH,
    double NominalRateKgH,
    double TInC,
    double TOutC,
    bool IsHot);

/// <summary>
/// Полная физика fine-слоя (S4): пересчёт K по корреляциям с нормировкой на K0.
/// h' = Nu'·λ' (диаметр одинаков); относительный поправочный множитель стороны:
/// f_side = (Nu'/Nu_ref)·(λ'/λ_ref). K' = K0·√(f_hot·f_cold) (среднегеометрическое сторон;
/// полный учёт сопротивлений стенки — при достоверных данных труб АТ-5).
/// Скорость: по площади сечения, если известна (FlowAreaHm2/Cm2), иначе
/// v' = v_nom·m'/m_nom (номинальный расход — полный расход потока из FlowSpec).
/// Интервальные оценки (ТЗ v3 разд. 32): K_max/K_min — неопределённость корреляций ±20 %
/// плюс принятые пороги k_min/k_max (0,5/2,0) и жёсткие клампы (1/5·K0).
/// Если аппарат не калиброван (Ref-данных нет) — поправка не применяется (K' = K0) + ANOM.
/// </summary>
public static class FinePhysics
{
    public const double CorrelationUncertainty = 0.20;

    /// <summary>
    /// Пересчитанный K, Вт/(м²·К): K' = K0·√(f_hot·f_cold) с клампами порогов.
    /// </summary>
    public static double K(
        ApparatusSpec app,
        SideContext hot,
        SideContext cold,
        EnvironmentService svc,
        double kMinFrac, double kMaxFrac, double kHardMultMax)
    {
        if (app.K0Wm2K <= 0 || app.RefTHAvgC is null || app.RefTCAvgC is null)
        {
            LogMiss.Anom("SIM", $"Аппарат «{app.Id}»: нет номинальных данных для нормировки — используется K0 без поправки.");
            return app.K0Wm2K;
        }

        double dTube = Math.Max(app.TubeDiMm, 1.0) / 1000.0;
        double dOverL = 1.0 / 50.0; // типовое L/d ≈ 50 кожухотрубных секций; уточняется данными труб

        double fHot = SideFactor(app, hot, app.RefTHAvgC.Value, svc, dTube, dOverL);
        double fCold = SideFactor(app, cold, app.RefTCAvgC.Value, svc, dTube, dOverL);
        if (double.IsNaN(fHot) || double.IsNaN(fCold))
            return app.K0Wm2K;

        double factor = Math.Sqrt(Math.Max(fHot, 0) * Math.Max(fCold, 0));
        double k = app.K0Wm2K * factor;

        double lo = Math.Max(kMinFrac * app.K0Wm2K, app.K0Wm2K / kHardMultMax);
        double hi = Math.Min(kMaxFrac * app.K0Wm2K, app.K0Wm2K * kHardMultMax);
        if (hi < lo) hi = lo;
        return Math.Clamp(k, lo, hi);
    }

    /// <summary>Интервальные оценки K (для UB и чувствительности): K_min/K_max.</summary>
    public static (double KMin, double KMax) Interval(double k, ApparatusSpec app, double kMinFrac, double kMaxFrac)
    {
        double kMin = Math.Max(k * (1 - CorrelationUncertainty), kMinFrac * app.K0Wm2K);
        double kMax = Math.Min(k * (1 + CorrelationUncertainty), kMaxFrac * app.K0Wm2K);
        return (kMin, Math.Max(kMax, kMin));
    }

    private static double SideFactor(
        ApparatusSpec app, SideContext ctx, double refTAvgC, EnvironmentService svc, double dTube, double dOverL)
    {
        double tAvg = 0.5 * (ctx.TInC + ctx.TOutC);
        double rho = svc.DensityKgM3(ctx.EnvironmentId, tAvg);
        double mu = svc.ViscosityPaS(ctx.EnvironmentId, tAvg);
        double cp = svc.CpKjKgK(ctx.EnvironmentId, tAvg);
        double lambda = svc.ThermalConductivityWmK(ctx.EnvironmentId, tAvg);
        double v = Velocity(app, ctx, rho);
        if (v <= 0 || mu <= 0 || rho <= 0 || lambda <= 0 || cp <= 0) return double.NaN;

        double re = KCorrelations.Reynolds(rho, v, dTube, mu);
        double pr = KCorrelations.Prandtl(mu, cp, lambda);
        if (re <= 0 || pr <= 0) return double.NaN;
        double nu = KCorrelations.Nusselt(re, pr, dOverL);

        // номинальные условия
        double rho0 = svc.DensityKgM3(ctx.EnvironmentId, refTAvgC);
        double mu0 = svc.ViscosityPaS(ctx.EnvironmentId, refTAvgC);
        double cp0 = svc.CpKjKgK(ctx.EnvironmentId, refTAvgC);
        double lambda0 = svc.ThermalConductivityWmK(ctx.EnvironmentId, refTAvgC);
        double v0 = NominalVelocity(app, ctx.IsHot);
        if (v0 <= 0 || mu0 <= 0 || rho0 <= 0 || lambda0 <= 0 || cp0 <= 0) return 1.0; // нет номинала — фактор 1

        double re0 = KCorrelations.Reynolds(rho0, v0, dTube, mu0);
        double pr0 = KCorrelations.Prandtl(mu0, cp0, lambda0);
        if (re0 <= 0 || pr0 <= 0) return 1.0;
        double nu0 = KCorrelations.Nusselt(re0, pr0, dOverL);

        return (nu / nu0) * (lambda / lambda0);
    }

    private static double Velocity(ApparatusSpec app, SideContext ctx, double rho)
    {
        double? area = ctx.IsHot ? app.FlowAreaHm2 : app.FlowAreaCm2;
        if (area is not null && area.Value > 0)
            return ctx.RateKgH / 3600.0 / (rho * area.Value);
        double vNom = ctx.IsHot ? app.NominalVhMs : app.NominalVcMs;
        return vNom > 0 && ctx.NominalRateKgH > 0 ? vNom * ctx.RateKgH / ctx.NominalRateKgH : 0;
    }

    /// <summary>Скорость стороны, м/с (для П4): по площади сечения или по номинальной с пересчётом по расходу.</summary>
    public static double VelocityOf(ApparatusSpec app, SideContext ctx, EnvironmentService svc)
    {
        double tAvg = 0.5 * (ctx.TInC + ctx.TOutC);
        double rho = svc.DensityKgM3(ctx.EnvironmentId, tAvg);
        return Velocity(app, ctx, rho);
    }

    /// <summary>Число Рейнольдса стороны (для Ф2): Re = ρ·v·d/μ.</summary>
    public static double ReynoldsOf(ApparatusSpec app, SideContext ctx, EnvironmentService svc)
    {
        double tAvg = 0.5 * (ctx.TInC + ctx.TOutC);
        double rho = svc.DensityKgM3(ctx.EnvironmentId, tAvg);
        double mu = svc.ViscosityPaS(ctx.EnvironmentId, tAvg);
        double v = Velocity(app, ctx, rho);
        if (v <= 0 || rho <= 0 || mu <= 0) return double.NaN;
        return KCorrelations.Reynolds(rho, v, Math.Max(app.TubeDiMm, 1.0) / 1000.0, mu);
    }

    private static double NominalVelocity(ApparatusSpec app, bool isHot) =>
        isHot ? app.NominalVhMs : app.NominalVcMs;
}
```

### 3.3 CutPipeline.cs — конвейер правил и beam-архив (полный листинг)

```csharp









namespace Pinchess.Engine.Rules;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Log;
using Pinchess.Engine.Sim;

/// <summary>Статистика отсечений (ТЗ v3 разд. 26): счётчики по правилам.</summary>
public sealed class CutStats
{
    private readonly Dictionary<string, (int Pass, int Cut, int Flag)> _counters = new();
    private readonly Dictionary<string, string> _lastCutReason = new();

    public void Add(RuleResult r)
    {
        if (!_counters.TryGetValue(r.RuleId, out var c))
            c = (0, 0, 0);
        _counters[r.RuleId] = r.Verdict switch
        {
            CutVerdict.Pass => (c.Pass + 1, c.Cut, c.Flag),
            CutVerdict.Cut => (c.Pass, c.Cut + 1, c.Flag),
            CutVerdict.Flag => (c.Pass, c.Cut, c.Flag + 1),
            _ => c,
        };
        if (r.Verdict == CutVerdict.Cut && !string.IsNullOrEmpty(r.Reason))
            _lastCutReason[r.RuleId] = r.Reason;
    }

    /// <summary>S9: топ-N правил по числу отсечений + образец последней причины (для отчёта «нет решения»).</summary>
    public IReadOnlyList<(string RuleId, int Cuts, string? Sample)> TopCuts(int n)
    {
        return _counters
            .Where(kv => kv.Value.Cut > 0)
            .OrderByDescending(kv => kv.Value.Cut).ThenBy(kv => kv.Key, StringComparer.Ordinal)
            .Take(n)
            .Select(kv => (kv.Key, kv.Value.Cut, _lastCutReason.TryGetValue(kv.Key, out var r) ? r : (string?)null))
            .ToList();
    }

    public int RulesCount => _counters.Count;

    public int Total => _counters.Values.Sum(v => v.Pass + v.Cut + v.Flag);
    public IReadOnlyDictionary<string, (int Pass, int Cut, int Flag)> Counters => _counters;

    public string Snapshot()
    {
        var lines = _counters.OrderBy(kv => kv.Key, StringComparer.Ordinal)
            .Select(kv => $"{kv.Key}: PASS {kv.Value.Pass} · CUT {kv.Value.Cut} · FLAG {kv.Value.Flag}");
        return $"{Total} срабатываний | " + string.Join(" · ", lines);
    }
}

/// <summary>
/// Конвейер отсечений (С → П → Ф → Г): правила как данные, первое CUT — состояние отсечено.
/// Финальные П5/П7/П8 — только на complete-состояниях (free пуст).

public sealed class CutPipeline
{
    private readonly ProjectSpec _project;
    private readonly Simulator _sim;
    private readonly List<ICutRule> _coarseRules;
    private readonly List<ICutRule> _fineRules;
    private readonly Dictionary<string, RuleConfig> _config;
    public CutStats Stats { get; } = new();

    public CutPipeline(ProjectSpec project, List<RuleConfig>? config = null)
    {
        _project = project;
        _sim = new Simulator(project);
        _config = (config ?? RulesConfigIO.Defaults()).ToDictionary(r => r.Id);

        ICutRule[] all =
        {
            new Impl.P1Thermodynamic(), new Impl.P2Monotonic(), new Impl.P3MinApproach(),
            new Impl.P4Speeds(), new Impl.P5Lb(), new Impl.P6Structure(),

            new Impl.M1MountChanges(),
        };
        _coarseRules = all.Where(r => _config.TryGetValue(r.Id, out var c) && c.Enabled).ToList();
        _fineRules = all.Where(r => _config.TryGetValue(r.Id, out var c) && c.Enabled).ToList();
    }

    public bool IsComplete(State state) => state.FreeApparatusIds.Count == 0;

    /// <summary>Прогон конвейера по состоянию; sim — решение симулятора уровня слоя.</summary>
    public PipelineOutcome Evaluate(State state, bool coarse, double qBestMw, bool beamMode = false)
    {
        var sim = _sim.Simulate(state, coarse ? SimLevel.Coarse : SimLevel.Fine);
        var ctx = new RuleContext(_project, state, coarse, qBestMw, _project.QglobMw, sim) { BeamMode = beamMode };

        var results = new List<RuleResult>();
        var rules = coarse ? _coarseRules : _fineRules;

        // финальные правила — только на complete
        bool complete = IsComplete(state);
        foreach (var rule in rules)
        {
            bool isFinal = rule.Id is "П5" or "П7" or "П8";
            if (isFinal && !complete) continue;
            var r = rule.Evaluate(ctx);
            // S8 (шаг 4): мягкость П2/Г5 на делениях снята — П2 сравнивает только в пределах путей
            // (протокол В: конфигурационные отсечения ветвей, не сам факт деления);
            // Г2/Г5 применяются к дочерним состояниям (протокол Д), родительский R3 не режется
            // (dQ=0, dUA=0 — Г2 не срабатывает; Г5 — по аппаратам ветвей).
            Stats.Add(r);
            results.Add(r);
            LogMiss.Info("CUT", $"{r.RuleId}: {r.Verdict} {r.Reason}");
            if (r.Verdict == CutVerdict.Cut)
                return new PipelineOutcome(true, r, results, sim);
        }
        return new PipelineOutcome(false, null, results, sim);
    }

    /// <summary>
    /// Г2. Непродуктивный ход: ΔQ &lt; eps_q и (ΔUA &gt; eps_UA или ΔdP &gt; eps_dP) и ход не
    /// открывает новых сопряжений [Р8] — ход не порождается; открывает — FLAG NEUTRAL (не режем).
    /// </summary>
    public static (bool PruneChild, RuleResult Verdict) G2Unproductive(
        RuleContext parent, RuleContext child, double parentQ, double childQ,
        double parentUa, double childUa, HashSet<string> parentCouplings, HashSet<string> childCouplings)
    {
        var p = parent.Project.Parameters;
        double epsQ = Math.Max(p.EpsQAbsMw, p.EpsQRel * Math.Max(parent.QglobMw, 1e-9));
        bool opensNew = childCouplings.Except(parentCouplings).Any();
        double dQ = childQ - parentQ;
        double dUa = childUa - parentUa;
        if (dQ < epsQ && (dUa > p.DomEpsUa * Math.Max(parentUa, 1e-9)) && !opensNew)
            return (true, RuleResult.Cut("Г2", $"ΔQ={dQ:0.000} < eps_q, ΔUA={dUa:0.000}, сопряжений нет"));
        if (dQ < epsQ && opensNew)
            return (false, RuleResult.Flag("Г2", "непродуктивный по Q, но открывает новые сопряжения", SoftSeverity.Low));
        return (false, RuleResult.Pass("Г2"));
    }

    /// <summary>
    /// Множество допустимых сопряжений [Р8]: свободный аппарат × остаточный сегмент потока
    /// (куда он может встать). Вставка/изъятие/перестановка, создающие новые пары
    /// (свободный аппарат, сегмент), открывают новые возможности.
    /// </summary>
    public static HashSet<string> CouplingSet(ProjectSpec project, State state)
    {
        var set = new HashSet<string>();
        foreach (var appId in state.FreeApparatusIds)
        {
            foreach (var seg in state.ResidualHot.Concat(state.ResidualCold))
                set.Add($"{seg.FlowId}|{appId}|{seg.PathId}");
            // и «в конец цепочки» потока (новая позиция всегда доступна)
            foreach (var flow in project.Flows.Where(f => f.AllowedApparatusIds.Contains(appId)))
                set.Add($"{flow.Id}|{appId}|post");
        }
        return set;
    }
}

/// <summary>
/// Г3. Beam с архивом (структура для S7): на уровне держим W лучших по UB; выбитые —
/// в архив с UB; после прохода возвращаем тех, у кого UB &gt; Q_best (rescue).
/// </summary>
public sealed class BeamArchive
{
    private readonly int _w;
    private readonly List<(State State, double Ub)> _current = new();
    private readonly List<(State State, double Ub)> _archive = new();

    public BeamArchive(int w) => _w = Math.Max(1, w);

    public void Add(State state, double ub)
    {
        _current.Add((state, ub));
        if (_current.Count > _w)
        {
            _current.Sort((a, b) => b.Ub.CompareTo(a.Ub));
            var evicted = _current[^1];
            _current.RemoveAt(_current.Count - 1);
            _archive.Add(evicted);
            // Б6 (аудит 20.11): лимит архива 10·W — иначе архив растёт без границы при деградации
            if (_archive.Count > 10 * _w)
            {
                _archive.Sort((a, b) => b.Ub.CompareTo(a.Ub));
                _archive.RemoveRange(10 * _w, _archive.Count - 10 * _w);
            }
        }
    }

    /// <summary>Rescue: вернуть из архива состояния с UB &gt; Q_best (после прохода уровня).</summary>
    public List<State> Rescue(double qBestMw)
    {
        var rescued = _archive.Where(x => x.Ub > qBestMw).Select(x => x.State).ToList();
        _archive.RemoveAll(x => x.Ub > qBestMw);
        return rescued;
    }

    public IReadOnlyList<State> Current => _current.Select(x => x.State).ToList();
    public int ArchivedCount => _archive.Count;
}
```

```csharp









namespace Pinchess.Engine.Search;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Sim;

/// <summary>Остаточный температурный сегмент потока для UB (фактический хвост после последнего аппарата).</summary>
public sealed record ResidualTail(
    string FlowId,
    bool IsHot,
    double RateKgH,
    double TLowC,
    double THighC,
    double QResidualMw);

/// <summary>
/// Верхняя оценка Г1 (ТЗ v3 разд. 8.5–8.6, раскладка Г1):
/// UB(S) = Q_fix + min(Q_comp_res, Q_cap_res).
/// Q_comp_res — перекрытие остаточных кривых горячих и холодных потоков при Tmin
/// (пары сегментов, противоток, интегрирование по энтальпийным кривым).
/// Q_cap_res — Σ по свободным аппаратам max по парам min(A·K_max·LMTD_max, Q_hot, Q_cold).
/// На coarse к Q_comp_res добавляется eps_margin (Д2) — отсечение остаётся безопасным.
/// </summary>
public static class UpperBound
{
    /// <summary>Остаточные хвосты потоков по посчитанному решению (последний активный аппарат цепочки).</summary>
    public static List<ResidualTail> ResidualTails(ProjectSpec project, State state, SimResult sim)
    {
        var tails = new List<ResidualTail>();
        var byId = sim.Apparatus.ToDictionary(a => a.ApparatusId);
        foreach (var flow in project.Flows)
        {
            var side = flow.IsHot ? Side.Hot : Side.Cold;
            var chain = state.Committed
                .Where(i => i.FlowId == flow.Id && i.Side == side && !i.Bypass)
                .OrderBy(i => i.PositionIndex)
                .ToList();

            double tLow, tHigh;
            // S8: делённый поток — хвост ЦЕЛОГО потока от смешанной температуры ветвей,
            // если после точки слияния аппаратов пути нет (иначе — прежняя логика)
            double? mixedT = null;
            var split = state.Splits.FirstOrDefault(s => s.FlowId == flow.Id);
            if (split is not null)
            {
                var branchInsts = chain.Where(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) != "P0").ToList();
                int maxBranchPos = branchInsts.Count > 0 ? branchInsts.Max(i => i.PositionIndex) : -1;
                bool afterExists = chain.Any(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) == "P0"
                                                  && i.PositionIndex > maxBranchPos);
                if (!afterExists)
                    mixedT = MixedTailTemperature(project, state, sim, flow, byId);
            }

            if (flow.IsHot)
            {
                // горячий остаток: от остывшего после последнего аппарата до целевой
                double tAfter = mixedT ?? (chain.Count > 0 ? byId[chain[^1].ApparatusId].ThOutC : flow.TStartC);
                tLow = Math.Min(tAfter, flow.TTargetC);
                tHigh = Math.Max(tAfter, flow.TTargetC);
            }
            else
            {
                // холодный остаток: от догретого после последнего аппарата до целевой
                double tAfter = mixedT ?? (chain.Count > 0 ? byId[chain[^1].ApparatusId].TcOutC : flow.TStartC);
                tLow = Math.Min(tAfter, flow.TTargetC);
                tHigh = Math.Max(tAfter, flow.TTargetC);
            }

            if (tHigh - tLow < 1e-9) continue;
            var curve = new EnthalpyCurve(project.Environments.First(e => e.Id == flow.EnvironmentId));
            double q = flow.IsHot
                ? Thermo.KjPerHourToMw(flow.FlowRateKgH * (curve.H(tHigh) - curve.H(tLow)))
                : Thermo.KjPerHourToMw(flow.FlowRateKgH * (curve.H(tHigh) - curve.H(tLow)));
            tails.Add(new ResidualTail(flow.Id, flow.IsHot, flow.FlowRateKgH, tLow, tHigh, q));
        }
        return tails;
    }

    /// <summary>
    /// S8: смешанная температура выходов ветвей деления (энтальпийное смешение с прямыми
    /// незанятыми частями ветвей) — как выход сегмента для хвоста целого потока (консервативно).
    /// </summary>
    private static double MixedTailTemperature(
        ProjectSpec project, State state, SimResult sim, FlowSpec flow, Dictionary<string, Sim.AppCalc> byId)
    {
        var split = state.Splits.First(s => s.FlowId == flow.Id);
        Side side = flow.IsHot ? Side.Hot : Side.Cold;
        var curve = new EnthalpyCurve(project.Environments.First(e => e.Id == flow.EnvironmentId));
        double anchorT = flow.TStartC;
        if (split.AnchorApparatusId.Length > 0 && byId.TryGetValue(split.AnchorApparatusId, out var ac))
            anchorT = flow.IsHot ? ac.ThOutC : ac.TcOutC;

        double hSum = 0, wSum = 0;
        foreach (var (pathId, frac) in new[] { (split.PathIdA, split.FractionA), (split.PathIdB, 1.0 - split.FractionA) })
        {
            var branchInsts = state.Committed
                .Where(i => i.FlowId == flow.Id && i.Side == side && !i.Bypass &&
                            (side == Side.Hot ? i.HotPathId : i.ColdPathId) == pathId)
                .OrderBy(i => i.PositionIndex).ToList();
            if (branchInsts.Count > 0 && byId.TryGetValue(branchInsts[^1].ApparatusId, out var bc))
            {
                double t = flow.IsHot ? bc.ThOutC : bc.TcOutC;
                hSum += frac * curve.H(t);
            }
            else
            {
                hSum += frac * curve.H(anchorT);
            }
            wSum += frac;
        }
        if (wSum <= 0) return anchorT;
        return curve.T(hSum / wSum);
    }

    /// <summary>
    /// Перекрытие пары остаточных сегментов (горячий × холодный) при Tmin: интеграл
    /// ВОНУТОЙ ОБОЛОЧКИ min(M·h(ξ), N·c(ξ)) по общему окну ξ = T_cold (горячий сдвинут
    /// на −Tmin); M/N — максимальное число частей потоков после делений (S8).
    /// Протокол совещания 18:53 (пункт А): любая конфигурация делений даёт поточечно
    /// Σ_ij min(α_i·h, β_j·c) ≤ min(M·h, N·c) — интеграл миноранты минорирует миноранты
    /// и является доказуемо верхней оценкой для всех допустимых делений; при M=N=1 —
    /// прежний интеграл min(h,c). min линейных кусков — вогнутая огибающая. Мощности
    /// кВт/К из энтальпийных кривых; результат в МВт.
    /// </summary>
    public static double QPairOverlapMw(
        ResidualTail hot, ResidualTail cold,
        EnthalpyCurve hotCurve, EnthalpyCurve coldCurve,
        double tminC, double stepC = 2.0,
        double hotBranchesMax = 1.0, double coldBranchesMax = 1.0)
    {
        // общий интервал по ξ = T_cold: горячий соответствует ξ + Tmin
        double lo = Math.Max(hot.TLowC, cold.TLowC + tminC);
        double hi = Math.Min(hot.THighC, cold.THighC + tminC);
        if (hi - lo < 1e-9) return 0;

        double PowerPerK(EnthalpyCurve curve, double rateKgH, double t)
        {
            double dh = curve.H(t + 1.0) - curve.H(t);
            return rateKgH * dh / 3600.0; // кВт/К
        }

        double sum = 0; // кВт·°C
        int n = Math.Max(2, (int)Math.Ceiling((hi - lo) / stepC) + 1);
        double gPrev = 0;
        for (int i = 0; i < n; i++)
        {
            double xi = lo + (hi - lo) * i / (n - 1);
            double g = Math.Min(hotBranchesMax * PowerPerK(hotCurve, hot.RateKgH, xi + tminC),
                                coldBranchesMax * PowerPerK(coldCurve, cold.RateKgH, xi));
            if (i > 0)
                sum += 0.5 * (gPrev + g) * (xi - (lo + (hi - lo) * (i - 1) / (n - 1)));
            gPrev = g;
        }
        return Math.Max(0, Math.Min(sum / 1000.0, Math.Min(hot.QResidualMw, cold.QResidualMw))); // МВт
    }

    /// <summary>
    /// Максимум частей потока после делений: AllowSplit — MaxSplits+1, иначе 1.
    /// М1 (аудит 20.11, ОТЛОЖЕНО Э1): снятие множителей ДАЛО ЛОЖНЫЕ ОТСЕЧЕНИЯ —
    /// UbGlobal 24,752 МВт < beam-оптимума 27,739 (тест E2Tests.UbGlobal_CoversFactSceneBeams
    /// красный). Причина: каскадный предел ∫min(H,C) не покрывает делённые конфигурации
    /// с допуском SleepTolC (легализованные перекрестия дают Q выше «чистого» предела).
    /// Прежний множитель оставлен как БЕЗОПАСНЫЙ (завышение не режет оптимум);
    /// честная верхняя оценка — после Э1-калибровки (права аудитора на «не отсекает» — учтены).
    /// Единая релаксация UB: родительский UB обязан покрывать любые допустимые
    /// деления детей — используем верхнюю (максимальную) оценку числа частей.
    /// </summary>
    public static double BranchesMaxOf(ProjectSpec project, string flowId) =>
        project.Flows.FirstOrDefault(f => f.Id == flowId) is { AllowSplit: true, MaxSplits: var ms } && ms > 0
            ? ms + 1.0
            : 1.0;

    /// <summary>UB частичного состояния (ГАРАНТИРОВАННОЕ — перестановочно-безопасное), МВт:
    /// max(хвостовая оболочка, аппаратная оценка); coarse — с eps_margin (Д2).</summary>
    public static double UbMw(
        ProjectSpec project, State state, SimResult sim,
        IReadOnlyList<ResidualTail> tails,
        double qBestMw, bool coarse,
        Props.EnvironmentService? svc = null)
    {
        double ubTail = UbTailMw(project, state, sim, tails, qBestMw, coarse, svc);
        double ubApp = UbApparatusMw(project, state, coarse);
        return Math.Max(ubTail, ubApp);
    }

    /// <summary>
    /// Хвостовая UB: Q_fix + min(Q_comp (вогнутая оболочка делений) + margin, Q_cap).
    /// Безопасна для вставок/делений; для перестановок R1 — эвристика: строгий режим
    /// до деградации использует UbMw (с аппаратной добавкой), в beam — ради скорости.
    /// </summary>
    public static double UbTailMw(
        ProjectSpec project, State state, SimResult sim,
        IReadOnlyList<ResidualTail> tails,
        double qBestMw, bool coarse,
        Props.EnvironmentService? svc = null)
    {
        var cp = project.Parameters;
        double qFix = sim.QTotalMw;
        var flowCurves = project.Flows.ToDictionary(f => f.Id,
            f => new EnthalpyCurve(project.Environments.First(e => e.Id == f.EnvironmentId)));
        var hotTails = tails.Where(t => t.IsHot).ToList();
        var coldTails = tails.Where(t => !t.IsHot).ToList();

        double qComp = 0;
        foreach (var h in hotTails)
        {
            // Вогнутая оболочка (протокол 18:53): множители — максимум частей потоков (BranchesMaxOf);
            // М1 (аудит 20.11, ОТЛОЖЕНО Э1): снятие множителей дало ложные отсечения — оставлен безопасный завышенный вариант.
            double mHot = BranchesMaxOf(project, h.FlowId);
            foreach (var c in coldTails)
                qComp += QPairOverlapMw(h, c, flowCurves[h.FlowId], flowCurves[c.FlowId], cp.TminC,
                    hotBranchesMax: mHot, coldBranchesMax: BranchesMaxOf(project, c.FlowId));
        }

        // Q_cap_res: свободные аппараты, максимум по парам
        double qCap = 0;
        var byId = sim.Apparatus.ToDictionary(a => a.ApparatusId);
        foreach (var appId in state.FreeApparatusIds)
        {
            var app = project.Apparatus.FirstOrDefault(a => a.Id == appId);
            if (app is null || app.K0Wm2K <= 0) continue;
            double kMax = Math.Min(cp.KMax, cp.KHardMultMax) * app.K0Wm2K /* Б14 (аудит 20.11): потолок = kMaxFrac·K0 из FinePhysics */;
            double best = 0;
            foreach (var h in hotTails)
                foreach (var c in coldTails)
                {
                    // безопасная верхняя оценка напора: аппарат может сопрягаться с любым
                    // концом остаточных хвостов — берём максимум из перекрёстных напоров
                    double lmtdMax = Math.Max(h.THighC - c.TLowC, h.TLowC - c.THighC);
                    if (lmtdMax <= 0) continue;
                    double cap = Math.Min(app.AreaM2 * kMax * lmtdMax / 1e6, Math.Min(h.QResidualMw, c.QResidualMw));
                    best = Math.Max(best, cap);
                }
            qCap += Math.Max(0, best);
        }

        double qCompSafe = qComp + (coarse ? cp.EpsMarginRel * Math.Max(project.QglobMw, 1.0) : 0);
        double ub = qFix + Math.Min(qCompSafe, qCap);
        return ub;
    }

    /// <summary>
    /// Перестановочно-безопасная аппаратная оценка (протокол 18:53: максимум из нескольких
    /// доказуемо верхних оценок): суммарная передача ЛЮБОЙ конфигурации данного набора
    /// аппаратов ≤ min(Σ max_duty, полная горячая навалка, полная холодная ёмкость).
    /// </summary>
    public static double UbApparatusMw(ProjectSpec project, State state, bool coarse)
    {
        var cp = project.Parameters;
        var curves = project.Flows.ToDictionary(f => f.Id,
            f => new EnthalpyCurve(project.Environments.First(e => e.Id == f.EnvironmentId)));
        double hotTotal = 0, coldTotal = 0;
        foreach (var f in project.Flows)
        {
            var crv = curves[f.Id];
            double q = Thermo.KjPerHourToMw(f.FlowRateKgH * Math.Abs(crv.H(f.TStartC) - crv.H(f.TTargetC)));
            if (f.IsHot) hotTotal += q; else coldTotal += q;
        }
        double sumDuty = 0;
        // набор аппаратов: активные + байпасные (байпас можно снять ходом R4) + свободные
        var apparatusSet = state.Committed.Select(i => i.ApparatusId)
            .Concat(state.FreeApparatusIds).Distinct().ToHashSet();
        foreach (var appId in apparatusSet)
        {
            var app = project.Apparatus.FirstOrDefault(a => a.Id == appId);
            if (app is null || app.K0Wm2K <= 0 || app.AreaM2 <= 0) continue;
            double kMax = Math.Min(cp.KMax, cp.KHardMultMax) * app.K0Wm2K /* Б14 (аудит 20.11): потолок = kMaxFrac·K0 из FinePhysics */;
            double best = 0;
            foreach (var hf in project.Flows.Where(f => f.IsHot && f.AllowedApparatusIds.Contains(appId)))
            foreach (var cf in project.Flows.Where(f => !f.IsHot && f.AllowedApparatusIds.Contains(appId)))
            {
                double hHi = Math.Max(hf.TStartC, hf.TTargetC);
                double hLo = Math.Min(hf.TStartC, hf.TTargetC);
                double cHi = Math.Max(cf.TStartC, cf.TTargetC);
                double cLo = Math.Min(cf.TStartC, cf.TTargetC);
                double lmtdMax = Math.Max(hHi - cLo, cHi - hLo);
                if (lmtdMax <= 0) continue;
                double cap = Math.Min(app.AreaM2 * kMax * lmtdMax / 1e6, Math.Min(hotTotal, coldTotal));
                best = Math.Max(best, cap);
            }
            sumDuty += Math.Max(0, best);
        }
        double ubApp = Math.Min(sumDuty, Math.Min(hotTotal, coldTotal));
        if (coarse)
            ubApp += cp.EpsMarginRel * Math.Max(project.QglobMw, 1.0); // Д2: гарантийный запас на coarse
        return ubApp;
    }

    /// <summary>
    /// Э2/S3: глобальная каскадная грань (PTA, см. PtaCascade) — доказуемо верхняя оценка
    /// нагрузки ЛЮБОЙ конфигурации сети с тем же составом потоков при сдвиге
    /// ΔT_eff = TminC − SleepTolC (перекрестия в допуске «спячки» легализованы).
    /// S3 (ревью-3 2.1): множители частей M/N в глобальной грани СНЯТЫ — энтальпийные
    /// тоталы потоков деления не меняют, каскадная грань покрывает все конфигурации
    /// по теории пинча; занижение интеграла ∫min (контрпример ревьюера: hot 100→50,
    /// cold 20→40, τ=10) устранено каскадом. Независима от состояния → покрывает
    /// перестановки R1/вставки R2/деления R3/байпасы R4/R5. stepC сохранён в сигнатуре
    /// для совместимости (точный интервальный метод сетки не требует).
    /// </summary>
    public static double UbGlobalMw(ProjectSpec project, double stepC = 0.5)
    {
        var cp = project.Parameters;
        double dEff = cp.TminC - cp.SleepTolC;
        return PtaCascade.QRecoverableMw(project, dEff);
    }
}
```

### 3.5 PtaCascade.cs — НОВОЕ v23: каскадная грань (полный листинг)

```csharp

namespace Pinchess.Engine.Search;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Sim;

/// <summary>
/// S3 (ревью-3 2.1): каскадная верхняя грань (PTA — problem table algorithm).
/// Q_rec = ColdTotal − Q_H_min(ΔT_eff), ΔT_eff = TminC − SleepTolC — перекрестия в допуске
/// «спячки» легализованы, грань считается с ослабленным сдвигом (SleepTolC ≥ Tmin → отрицательный сдвиг).
/// Заменяет заниженный интеграл ∫min из v20 (контрпример ревьюера: hot 100→50, cold 20→40, τ=10 —
/// интеграл 0, реальная граница 20; PTA на нём даёт ровно 20).
/// Точный интервальный метод: уровни по ВСЕМ концам потоков (холодные как есть, горячие со
/// сдвигом −ΔT_eff), в интервале — энтальпия как интеграл кривой (нелинейный cp корректен),
/// каскад по убыванию T: net = avail − req, кумулятив вниз, Q_H_min = max(0, −min cum).
/// Тепло горячих УРОВНЯМИ ВЫШЕ верхней цели холодных не теряется — оно каскадируется вниз
/// (иначе контрпример ревьюера не покрыт). Свойство: грань — верхняя оценка нагрузки ЛЮБОЙ
/// конфигурации сети из тех же потоков при сдвиге ΔT_eff; деления потоков энтальпийные
/// тоталы не меняют — множители M/N не нужны.
/// </summary>
public static class PtaCascade
{
    /// <summary>Тепло потока на интервале [a, b] (энтальпийный интеграл кривой среды), МВт.</summary>
    private static double StreamQ(EnthalpyCurve crv, double rateKgH, double a, double b)
    {
        if (b - a <= 1e-12) return 0;
        double q = Thermo.KjPerHourToMw(rateKgH * (crv.H(b) - crv.H(a)));
        return q > 0 ? q : 0;
    }

    /// <summary>
    /// Максимальная рекуперация между потоками проекта при сдвиге deltaT (К).
    /// Именованная функция: возвращает (QRec, HotTotal, ColdTotal, QHmin) для диагностики.
    /// </summary>
    public static (double QRecMw, double HotTotalMw, double ColdTotalMw, double QHminMw)
        QRecoverableDetailed(ProjectSpec project, double deltaT)
    {
        var curves = project.Flows.ToDictionary(f => f.Id,
            f => new EnthalpyCurve(project.Environments.First(e => e.Id == f.EnvironmentId)));
        double hotTotal = 0, coldTotal = 0;
        foreach (var f in project.Flows)
        {
            double a = Math.Min(f.TStartC, f.TTargetC), b = Math.Max(f.TStartC, f.TTargetC);
            double q = StreamQ(curves[f.Id], f.FlowRateKgH, a, b);
            if (f.IsHot) hotTotal += q; else coldTotal += q;
        }
        if (hotTotal <= 1e-12 || coldTotal <= 1e-12) return (0, hotTotal, coldTotal, 0);

        // уровни: все концы холодных потоков и все сдвинутые концы горячих
        var bps = new List<double>();
        foreach (var f in project.Flows)
        {
            double a = Math.Min(f.TStartC, f.TTargetC), b = Math.Max(f.TStartC, f.TTargetC);
            if (f.IsHot) { bps.Add(a - deltaT); bps.Add(b - deltaT); }
            else { bps.Add(a); bps.Add(b); }
        }
        var levels = bps.Distinct().OrderByDescending(t => t).ToList();

        double cum = 0, minCum = 0;
        for (int k = 0; k + 1 < levels.Count; k++)
        {
            double top = levels[k], bot = levels[k + 1];
            if (top - bot <= 1e-12) continue;
            double req = 0, avail = 0;
            foreach (var f in project.Flows)
            {
                double a = Math.Min(f.TStartC, f.TTargetC), b = Math.Max(f.TStartC, f.TTargetC);
                if (f.IsHot)
                {
                    // горячий интервал на оси ξ: [a − ΔT, b − ΔT] ∩ [bot, top]
                    double lo = Math.Max(a - deltaT, bot), hi = Math.Min(b - deltaT, top);
                    if (hi > lo) avail += StreamQ(curves[f.Id], f.FlowRateKgH, lo + deltaT, hi + deltaT);
                }
                else
                {
                    double lo = Math.Max(a, bot), hi = Math.Min(b, top);
                    if (hi > lo) req += StreamQ(curves[f.Id], f.FlowRateKgH, lo, hi);
                }
            }
            cum += avail - req;
            minCum = Math.Min(minCum, cum);
        }
        double qHmin = Math.Max(0.0, -minCum);
        double qRec = Math.Max(0.0, Math.Min(coldTotal - qHmin, Math.Min(hotTotal, coldTotal)));
        return (qRec, hotTotal, coldTotal, qHmin);
    }

    public static double QRecoverableMw(ProjectSpec project, double deltaT) =>
        QRecoverableDetailed(project, deltaT).QRecMw;
}
```

```csharp
/// <summary>Параметры прогона поиска.</summary>

public enum SearchModeKind { StrictBnB, BeamSearch }

/// <summary>
/// Движок поиска переобвязки (S7).
/// StrictBnB: DFS по ходам с конвейером отсечений; frontier ограничен open_limit —
/// при превышении деградирует в beam-ограничение уровня с фиксацией «гарантия ограничена
/// памятью» (сертификат честно не заявляет полноту).
/// BeamSearch: уровневый отбор W лучших по UB (тайбрейк — канонический ключ, затем глубина);
/// выбитые — в архив; после уровня — rescue UB &gt; Q_best (Г3).
/// Детерминизм: сортировка детей по (UB desc, canonical key asc, depth asc); никакого
/// неупорядоченного перечисления словарей.
/// </summary>
public sealed class SearchEngine
{
    private readonly ProjectSpec _project;
    private readonly MoveGenerator _gen;
    private readonly CutPipeline _pipeline;
    private readonly Visited _visited;
    private readonly SearchRun _run;
    private readonly Func<double, double> _epsQ;
    // Шаг 6-остаток: кэш сырых метрик (Q, Ua, UB) по каноническому ключу и режиму beam.
    // Метрики не зависят от qBest и детерминированы по состоянию; рез-решение (Г1 по qBest)
    // пересчитывается: кэш-хит только пока UB ≥ текущий qBest (иначе Г1 обязан резать).
    private readonly Dictionary<string, (double Q, double Ua, double Ub)> _metricCache = new();
    private const string RulesGuaranteeLine =
        "гарантированные: С1,С2,С4,С5,П1,П5-lb,П7,П8,Г1,Г3; эвристические: С3,П2,П3,П4,П5,П6,Ф1,Ф2,Ф3,Ф4,Г2,Г4,Г5,М1";

    public int StatesEvaluated { get; private set; }
    public int StatesPruned { get; private set; }
    public int StatesFlagged { get; private set; }

    public SearchEngine(ProjectSpec project, SearchRun run)
    {
        _project = project;
        _run = run;
        _gen = new MoveGenerator(project);
        _pipeline = new CutPipeline(project);
        _visited = new Visited(project.Parameters);
        _epsQ = q => Math.Max(project.Parameters.EpsQAbsMw, project.Parameters.EpsQRel * Math.Max(project.QglobMw, 1e-9));
    }

    /// <summary>Оценка состояния на coarse: вердикт конвейера + метрики (Q, UB).
    /// beamMode — эвристическая хвостовая UB (после деградации/в beam); иначе — гарантированная.</summary>
    private (bool Cut, double Q, double Ua, double Ub, RuleResult? FirstCut) EvaluateCoarse(State state, double qBest, bool beamMode)
    {
        // Шаг 6-остаток: кэш метрик — симуляция (самая дорогая часть) не повторяется для
        // того же состояния; рез-правила, зависящие от qBest (Г1), валидны пока UB ≥ qBest
        var ck = state.CanonicalKey + "|" + (beamMode ? "b" : "s");
        if (_metricCache.TryGetValue(ck, out var mc) && mc.Ub >= qBest)
            return (false, mc.Q, mc.Ua, mc.Ub, null);
        var outcome = _pipeline.Evaluate(state, coarse: true, qBestMw: qBest, beamMode: beamMode);
        StatesEvaluated++;
        if (outcome.Cut)
        {
            StatesPruned++;
            return (true, 0, 0, 0, outcome.FirstCut);
        }
        foreach (var r in outcome.Results)
            if (r.Verdict == CutVerdict.Flag) StatesFlagged++;
        double ub = double.PositiveInfinity;
        var g1 = outcome.Results.FirstOrDefault(r => r.RuleId == "Г1" && r.Metrics.ContainsKey("UB"));
        if (g1 is not null) ub = g1.Metrics["UB"];
        double ua = StateOps.UaFix(_project, state);
        // Б5 (аудит 20.11): eviction кэша метрик — без него кэш растёт до сотен МБ на длинных сканах;
        // потеря кэша безопасна (это оптимизация, не инвариант корректности)
        if (_metricCache.Count >= 200_000) _metricCache.Clear();
        _metricCache[ck] = (outcome.Sim.QTotalMw, ua, ub);
        return (false, outcome.Sim.QTotalMw, ua, ub, null);
    }

    /// <summary>Fine-оценка complete-состояния: финальные правила + Q (штрафованный за «спящих»).</summary>
    private (bool Valid, double Q) EvaluateFineComplete(State state)
    {
        var outcome = _pipeline.Evaluate(state, coarse: false, qBestMw: _bestQ);
        StatesEvaluated++;
        if (outcome.Cut)
        {
            StatesPruned++;
            return (false, 0);
        }
        return (true, PenaltyAdjusted(outcome.Sim));
    }

    /// <summary>S2 (ревью-3, 1.3): M1-лексикография. Кандидат лучше Best, если Q выше (с запасом 1e-12);
    /// при равном Q — меньшее MountChanges (M1); при равном M1 — канонический ключ (детерминизм).</summary>
    private bool Better(State candidate, double qFine)
    {
        if (qFine > _bestQ + 1e-12) return true;
        if (Math.Abs(qFine - _bestQ) <= 1e-12)
        {
            if (candidate.MountChanges != _bestMount)
                return candidate.MountChanges < _bestMount;
            return string.CompareOrdinal(candidate.CanonicalKey, _bestKey) < 0;
        }
        return false;
    }

    /// <summary>S2 (ревью-3, 1.3): локальный подъём от Best — R1/R1PairSwap/R4/R5 (R3 исключён),
    /// coarse-фильтр, не более 20 шагов и 8 fine-оценок; вызывается в strict и beam ПЕРЕД сертификатом.
    /// Раскрывает перестановочный потенциал плотной цепочки вокруг найденного Best (PairSwap —
    /// только здесь: Generate(state, allowShiftPositions: true)). Подъём только по complete-состояниям;
    /// R5 порождает не-complete — остаётся на основном потоке скана.</summary>
    private void RefineBest(List<string> topKeys)
    {
        if (_bestState is null) return;
        var current = _bestState;
        double currentQ = _bestQ;
        int fineBudget = 8;
        bool improved = false;
        for (int step = 0; step < 20; step++)
        {
            State? next = null;
            double nextQ = 0;
            foreach (var move in _gen.Generate(current, allowShiftPositions: true))
            {
                if (move.Kind is MoveKind.R3Split or MoveKind.R2Insert) continue;
                State child;
                try { child = StateOps.ApplyMove(_project, current, move); }
                catch (IllegalMoveException) { continue; }
                if (child.FreeApparatusIds.Count > 0) continue;
                child = child.With(b => b.CanonicalKey = Canonizer.CanonicalKey(child));
                var (cut, q, ua, ub, _) = EvaluateCoarse(child, currentQ, beamMode: true);
                if (cut) continue;
                if (fineBudget <= 0) break;
                var (valid, qFine) = EvaluateFineComplete(child);
                if (!valid) continue;
                fineBudget--;
                if (qFine > currentQ + 1e-12 && (next is null || qFine > nextQ + 1e-12))
                {
                    next = child; nextQ = qFine;
                }
                else if (next is not null && Math.Abs(qFine - nextQ) <= 1e-12 && child.MountChanges < next.MountChanges)
                {
                    next = child; nextQ = qFine; // равный Q — меньшее M1
                }
            }
            if (next is null) break; // локальный оптимум достигнут
            current = next; currentQ = nextQ; improved = true;
            _bestQ = currentQ;
            _bestSleeping = _lastSleeping; _bestGross = _lastGross;
            _bestKey = current.CanonicalKey;
            _bestState = current;
            _bestMount = current.MountChanges;
            // S1 (ревью-3, 1.6): complete-Best — нижняя граница поддерева — сам узел: UB = Q_best
            _bestUb = currentQ;
            topKeys.Add(current.CanonicalKey);
            AddTop10(current, currentQ);
        }
        if (improved)
            LogMiss.Info("SEARCH", $"RefineBest: локальный подъём до Q_best={_bestQ:0.000} МВт (M1={_bestMount})");
    }

    /// <summary>Б3-штраф (решение владельца 00:03): из Q вычитается SleepingCount · SleepPenaltyMw —
    /// «спящий» аппарат (Q=0, перекрестие в допуске) не бесплатен для сети. Penalty=0 — прежнее поведение.</summary>
    private double PenaltyAdjusted(SimResult sim)
    {
        double pen = _project.Parameters.SleepPenaltyMw;
        if (pen <= 0) return sim.QTotalMw;
        int n = sim.Apparatus.Count(a => Math.Abs(a.QMw) <= 1e-9 && a.FailureClass == FailureClass.Pinch);
        _lastSleeping = n;
        _lastGross = sim.QTotalMw;
        return sim.QTotalMw - n * pen;
    }
    private int _lastSleeping;
    private double _lastGross;
    private int _bestSleeping;
    private double _bestGross;

    private double _bestQ = double.NegativeInfinity;
    // S2 (ревью-3, 1.3): M1-лексикография — при равном Q (±1e-12) побеждает меньшее MountChanges
    private int _bestMount;
    private string _bestKey = "";
    private State? _bestState;
    private double _bestUb = double.PositiveInfinity;
    // S11: топ-10 complete-вариантов (sorted by Q desc) + S13: resume-очередь из чекпоинта
    private readonly List<(State State, double QMw)> _top10 = new();
    private readonly List<(State State, double Ub)>? _resumeFrontier;
    private readonly double _resumeQBest;
    private readonly State? _resumeBest;

    /// <summary>S13: конструктор возобновления скана из чекпоинта (frontier + incumbent).</summary>
    public SearchEngine(ProjectSpec project, SearchRun run,
        IReadOnlyList<(State State, double Ub)> resumeFrontier, double resumeQBest, State? resumeBest = null)
        : this(project, run)
    {
        _resumeFrontier = resumeFrontier.ToList();
        _resumeQBest = resumeQBest;
        _resumeBest = resumeBest;
    }

    private void AddTop10(State state, double qFine)
    {
        // детерминизм: при равном Q — по каноническому ключу (протокол «incumbent при равном Q»)
        int i = 0;
        while (i < _top10.Count)
        {
            var (s2, q2) = _top10[i];
            if (q2 > qFine || (Math.Abs(q2 - qFine) < 1e-12 && string.CompareOrdinal(s2.CanonicalKey, state.CanonicalKey) < 0))
                i++;
            else break;
        }
        _top10.Insert(i, (state, qFine));
        if (_top10.Count > 10) _top10.RemoveAt(_top10.Count - 1);
    }

    private long _lastCheckpointAt = -1;

    private void MaybeCheckpoint(IReadOnlyList<(State State, double Ub)> frontierSnapshot)
    {
        if (_run.CheckpointEveryStates is not { } every || string.IsNullOrEmpty(_run.CheckpointPath)) return;
        // первый снимок — сразу (иначе на маленьких сценах чекпоинт может не случиться вовсе)
        if (_lastCheckpointAt >= 0 && StatesEvaluated - _lastCheckpointAt < every) return;
        _lastCheckpointAt = StatesEvaluated;
        try
        {
            var dto = new Io.SearchCheckpointDto
            {
                Version = "2",
                Mode = _run.Mode.ToString(),
                RulesVersion = _project.RulesVersion,
                Seed = _run.Seed,
                QBestMw = _bestQ,
                UbBestMw = _bestUb,
                BestKey = _bestKey,
                BestState = _bestState is null ? null : Io.SearchCheckpoint.ToDto(_bestState, _bestUb),
                StatesEvaluated = StatesEvaluated,
                StatesPruned = StatesPruned,
                ElapsedMs = 0,
                Frontier = frontierSnapshot.Select(x => Io.SearchCheckpoint.ToDto(x.State, x.Ub)).ToList(),
                VisitedKeys = _visited.Entries.Keys.ToList(),
            };
            System.IO.File.WriteAllText(_run.CheckpointPath, Io.SearchCheckpoint.ToJson(dto));
        }
        catch (Exception ex)
        {
            LogMiss.Warn("SEARCH", $"чекпоинт не записан: {ex.Message}");
        }
    }

    private List<(State State, double Ub)> ResumeFrontier() =>
        _resumeFrontier ?? new List<(State State, double Ub)>();

    public SearchOutcome Run(Action<SearchProgress>? progress = null)
    {
        var start = _run.WarmStart ?? StateOps.InitialState(_project);
        start = start.With(b => b.CanonicalKey = Canonizer.CanonicalKey(start));
        _bestQ = _resumeQBest;
        _bestKey = _resumeBest?.CanonicalKey ?? "";
        _bestState = _resumeBest;
        _bestMount = _resumeBest?.MountChanges ?? 0;
        // S1 (ревью-3, 1.6): после возобновления UB неизвестен до первого отсечения — Q_best как
        // UB complete-узла (нижняя граница поддерева найденного Best) вместо +∞ в сертификате.
        _bestUb = _resumeQBest > 0 ? _resumeQBest : double.PositiveInfinity;

        var sw = System.Diagnostics.Stopwatch.StartNew();
        var topKeys = new List<string>();

        if (_run.Mode == SearchModeKind.StrictBnB)
        {
            // каждый узел оценивается ОДИН раз — в момент попадания в frontier;
            // при извлечении повторно не переоценивается (иначе С2-Dominated отсекает своих же)
            var frontier = new Stack<(State State, double Ub, bool PreEvaluated)>();
            var resume = ResumeFrontier();
            if (resume.Count > 0)
            {
                for (int i = resume.Count - 1; i >= 0; i--)
                    frontier.Push((resume[i].State, resume[i].Ub, false));
            }
            else
                frontier.Push((start, double.PositiveInfinity, false));
            bool degraded = false;
            string? degradedReason = null;
            bool stateLimitHit = false;
            long openLimit = _project.Parameters.OpenLimit;
            var archiveDegraded = new BeamArchive(_project.Parameters.BeamW);
            int rescuedTotal = 0;
            double lastRescueQ = double.NegativeInfinity;
            var _simR = new Simulator(_project);

            while (frontier.Count > 0)
            {
                if (_run.Cancellation.IsCancellationRequested) break;

                // деградация — однократная: первое превышение open_limit
                if (!degraded && frontier.Count > openLimit)
                {
                    degraded = true;
                    degradedReason = "гарантия ограничена памятью: frontier превысил open_limit — переход на beam-отбор, архив недобран";
                    // S8/протокол: приоритизация вместо отсечений — R2-вставки вперед (спуск к complete);
                    var kept0 = frontier
                        .OrderByDescending(x => x.State.LastMoveId?.StartsWith("R2Insert", StringComparison.Ordinal) ?? false)
                        .ThenByDescending(x => x.State.LastMoveId?.StartsWith("R3Split", StringComparison.Ordinal) ?? false)
                        .ThenBy(x => double.IsPositiveInfinity(x.Ub) ? -1.0 : -x.Ub)
                        .ThenBy(x => x.State.CanonicalKey, StringComparer.Ordinal)
                        .ThenBy(x => x.State.Depth)
                        .Take(_project.Parameters.BeamW)
                        .ToList();
                    var keptKeys = kept0.Select(k => k.State.CanonicalKey).ToHashSet();
                    foreach (var dropped in frontier.Where(x => !keptKeys.Contains(x.State.CanonicalKey)))
                        archiveDegraded.Add(dropped.State, dropped.Ub);
                    frontier.Clear();
                    foreach (var k in kept0) frontier.Push(k);
                    LogMiss.Warn("SEARCH", $"open_limit={openLimit} превышен — деградация в beam (W={_project.Parameters.BeamW})");
                    continue;
                }

                // после деградации — обычный beam-лимит W (Г3): выбитые — в архив, rescue — в frontier
                if (degraded && frontier.Count > _project.Parameters.BeamW)
                {
                    // S8/протокол: R2-вставки приоритетны и в beam-лимите (иначе UB перестановок
                    // с нетронутыми хвостами вытесняет вставки — луч не спускается к complete)
                    var ranked = frontier
                        .OrderByDescending(x => x.State.LastMoveId?.StartsWith("R2Insert", StringComparison.Ordinal) ?? false)
                        .ThenByDescending(x => x.State.LastMoveId?.StartsWith("R3Split", StringComparison.Ordinal) ?? false)
                        .ThenBy(x => double.IsPositiveInfinity(x.Ub) ? -1.0 : -x.Ub)
                        .ThenBy(x => x.State.CanonicalKey, StringComparer.Ordinal)
                        .ThenBy(x => x.State.Depth)
                        .ToList();
                    frontier.Clear();
                    foreach (var k in ranked.Take(_project.Parameters.BeamW)) frontier.Push(k);
                    foreach (var evicted in ranked.Skip(_project.Parameters.BeamW))
                        archiveDegraded.Add(evicted.State, evicted.Ub);
                    // Э2-патч: rescue только при РОСТЕ Q_best — иначе при Q_best=-inf rescue
                    // вытягивает весь архив, beam-лимит снова эвиктит их же в архив —
                    // вечный цикл rank/rescue без pop (найдено на факт-сцене, OpenLimit=50).
                    if (_bestQ > lastRescueQ + 1e-9)
                    {
                        lastRescueQ = _bestQ;
                        var rescued = archiveDegraded.Rescue(_bestQ);
                        rescuedTotal += rescued.Count;
                        foreach (var st in rescued)
                        {
                            // Шаг 6-остаток: кэш метрик при доборе — симуляция не повторяется
                            var rk = st.CanonicalKey + "|s";
                            if (_metricCache.TryGetValue(rk, out var mRes))
                            {
                                frontier.Push((st, mRes.Ub, _visited.Entries.ContainsKey(st.CanonicalKey)));
                                continue;
                            }
                            var resR = _simR.Simulate(st, SimLevel.Coarse);
                            var tailsR = Search.UpperBound.ResidualTails(_project, st, resR);
                            double ubR = Search.UpperBound.UbMw(_project, st, resR, tailsR, _bestQ, coarse: true);
                            frontier.Push((st, ubR, _visited.Entries.ContainsKey(st.CanonicalKey)));
                        }
                    }
                    continue;
                }

                var (state, ubTuple, preEvaluated) = frontier.Pop();
                if (StatesEvaluated >= _run.MaxStates) { stateLimitHit = true; break; }

                double q, ua, ub;
                if (preEvaluated)
                {
                    // узел уже оценён при генерации и добавлен в Visited — переоценка дала бы
                    // ложное Dominated; метрики из Visited, UB — из кортежа frontier
                    q = _visited.Entries[state.CanonicalKey].QFixMw;
                    ua = _visited.Entries[state.CanonicalKey].UaFixMwK;
                    ub = ubTuple;
                }
                else
                {
                    (var cut0, q, ua, ub, _) = EvaluateCoarse(state, _bestQ, degraded);
                    progress?.Invoke(new SearchProgress(StatesEvaluated, frontier.Count, _bestQ, state.Depth));
                    // Э1 (20.11): факт-база АТ-5 содержит перекрестия факта (Т-3, Т-10) — П1 режет её
                    // на coarse, хотя fine «спит» эти аппараты и сходится. WarmStart-корень
                    // НЕ отбрасывается coarse-CUT — иначе полировка факта теряет Best и старт.
                    bool isWarmRoot = _run.WarmStart is not null && state.CanonicalKey == start.CanonicalKey;
                    if (cut0 && !isWarmRoot) continue;
                    var visit0 = _visited.Add(state.CanonicalKey, q, ua, SoftVector.Empty, coarse: true);
                    if (visit0 == VisitResult.Dominated) { StatesPruned++; continue; }
                }
                _visited.MarkRetained(state.CanonicalKey);

                if (state.FreeApparatusIds.Count == 0)
                {
                    var (valid, qFine) = EvaluateFineComplete(state);
                    // S8 шаг 7: непрерывная оптимизация доли деления (Нелдер–Мид) для complete со Splits
                    if (valid && Better(state, qFine) && state.Splits.Count > 0)
                    {
                        var (refined, qRef) = SplitRefiner.Refine(_project, state, _simR);
                        if (qRef > qFine)
                        {
                            qFine = qRef;
                            state = refined;
                            topKeys.Add(refined.CanonicalKey);
                        }
                    }
                    if (valid && Better(state, qFine))
                    {
                        _bestQ = qFine;
                        _bestSleeping = _lastSleeping; _bestGross = _lastGross;
                        _bestMount = state.MountChanges;
                        _bestKey = state.CanonicalKey;
                        _bestState = state;
                        // S1 (ревью-3, 1.6): UB родителя-корня (+∞) в сертификате — мусор; для
                        // complete-Best нижняя граница поддерева — сам узел: UB = Q_best. Иначе — UB узла.
                        _bestUb = double.IsPositiveInfinity(ub) ? qFine : ub;
                        topKeys.Add(state.CanonicalKey);
                        AddTop10(state, qFine);
                    }
                    else if (valid)
                    {
                        AddTop10(state, qFine);
                    }
                    // Х4 (аудит-приоритет 2): «полировка факта» — WarmStart complete-узел
                    // РАСШИРЯЕТСЯ ходами R1/R4/R5 (перестановки/байпас/изъятия от базы «ДО»).
                    // Прочие complete-узлы терминальны (R2/R3 невозможны).
                    if (_run.WarmStart is null || state.CanonicalKey != start.CanonicalKey)
                        continue;
                }

                // S13: чекпоинт по периодичности (frontier + incumbent)
                MaybeCheckpoint(frontier.Select(x => (x.State, x.Ub)).ToList());

                // Scheduler: детерминированный порядок раскрытия детей (UB desc, key, depth);
                // S8 шаг 4: R2-вставки наверх, затем R3-деления, R1/R4/R5 — на дно (протокол В).
                // S8 шаг 6 УРОК: ленивая оценка R1/R4/R5 (отложка до pop) рвёт R2-спуск АТ-5 —
                // перестановки нужны МЕЖДУ вставками; оценку вернули при генерации (S7).
                var children = new List<(State State, double Ub, MoveKind Kind, bool PreEvaluated)>();
                foreach (var move in _gen.Generate(state))
                {
                    if (StatesEvaluated >= _run.MaxStates) { stateLimitHit = true; break; }
                    State child;
                    try { child = StateOps.ApplyMove(_project, state, move); }
                    catch (IllegalMoveException) { continue; }
                    child = child.With(b => b.CanonicalKey = Canonizer.CanonicalKey(child));

                    var (cutChild, qChild, uaChild, ubChild, _) = EvaluateCoarse(child, _bestQ, degraded);
                    // Г2: непродуктивный ход
                    var couplings = CutPipeline.CouplingSet(_project, state);
                    var childCouplings = CutPipeline.CouplingSet(_project, child);
                    var (prune, _) = CutPipeline.G2Unproductive(
                        new RuleContext(_project, state, true, _bestQ, _project.QglobMw, null),
                        new RuleContext(_project, child, true, _bestQ, _project.QglobMw, null),
                        q, qChild, ua, uaChild, couplings, childCouplings);
                    if (prune)
                    {
                        StatesPruned++;
                        continue;
                    }
                    if (cutChild) continue;
                    var addRes = _visited.Add(child.CanonicalKey, qChild, uaChild, SoftVector.Empty, coarse: true);
                    if (addRes == VisitResult.Dominated)
                    {
                        StatesPruned++;
                        continue;
                    }
                    children.Add((child, ubChild, move.Kind, true));
                }

                // Scheduler: детерминированный порядок раскрытия; S8 шаг 4: R2-вставки наверх,
                // затем R3-деления, перестановки/байпасы/изъятия — на дно (протокол В: откладывать, не отбрасывать)
                var others = children.Where(x => x.Kind is not (MoveKind.R2Insert or MoveKind.R3Split))
                    .OrderBy(x => -x.Ub).ThenBy(x => x.State.CanonicalKey, StringComparer.Ordinal).ThenBy(x => x.State.Depth).ToList();
                var splits = children.Where(x => x.Kind == MoveKind.R3Split)
                    .OrderBy(x => -x.Ub).ThenBy(x => x.State.CanonicalKey, StringComparer.Ordinal).ThenBy(x => x.State.Depth).ToList();
                var inserts = children.Where(x => x.Kind == MoveKind.R2Insert)
                    .OrderBy(x => -x.Ub).ThenBy(x => x.State.CanonicalKey, StringComparer.Ordinal).ThenBy(x => x.State.Depth).ToList();
                foreach (var (child, ubChild, kind, pre) in others)
                    frontier.Push((child, ubChild, pre));
                foreach (var (child, ubChild, kind, pre) in splits)
                    frontier.Push((child, ubChild, pre));
                foreach (var (child, ubChild, kind, pre) in inserts)
                    frontier.Push((child, ubChild, pre));
            }

            sw.Stop();
            RefineBest(topKeys);
            var cert = new SearchCertificate(
                "StrictBnB", _bestQ, _bestUb,
                _bestQ >= 0 ? _bestUb - _bestQ : double.NaN,
                GuaranteeComplete: !degraded && !stateLimitHit && !_run.Cancellation.IsCancellationRequested
                    && (_bestQ <= 0 || _bestUb >= _bestQ - _project.Parameters.EpsUbRel * Math.Max(_project.QglobMw, 1e-9)),
                DegradedReason: stateLimitHit ? "лимит состояний MaxStates исчерпан — гарантия снята"
                    : (_bestQ > 0 && _bestUb < _bestQ - _project.Parameters.EpsUbRel * Math.Max(_project.QglobMw, 1e-9)
                        ? "Э2: UB узла ниже Q_best — гарантия снята (UB-tail занижен)"
                        : degradedReason),
                StatesEvaluated, StatesPruned, StatesFlagged, Rescued: rescuedTotal,
                sw.ElapsedMilliseconds, _project.RulesVersion, _run.Seed,
                Cancelled: _run.Cancellation.IsCancellationRequested,
                RulesGuarantee: RulesGuaranteeLine,
                SleepingCount: _bestSleeping,
                SleepPenaltyMwApplied: _project.Parameters.SleepPenaltyMw,
                QGrossMw: _bestSleeping > 0 ? _bestGross : _bestQ);
            LogMiss.Info("SEARCH", cert.ToString());
            var report = _bestState is null ? NoSolution.Build(_project, cert, _pipeline.Stats, _run.WarmStart) : null;
            return new SearchOutcome(_bestState, cert, topKeys, report, _top10.Count > 0 ? _top10.ToList() : null);
        }

        // BeamSearch: уровневый отбор; узлы уровня уже оценены при генерации (preEvaluated)
        bool stateLimitBeam = false;
        {
            int w = Math.Max(1, _run.BeamW);
            var archive = new BeamArchive(w);
            var level = ResumeFrontier().Count > 0
                ? ResumeFrontier().Select(x => (x.State, x.Ub, false, MoveKind.R2Insert)).ToList()
                : new List<(State State, double Ub, bool PreEvaluated, MoveKind Kind)> { (start, double.PositiveInfinity, false, MoveKind.R2Insert) };
            int rescuedTotal = 0;
            int depthGuard = 0;
            int maxDepth = _project.Parameters.DMaxOverride ??
                (_project.Apparatus.Count(a => _project.Flows.Any(f => f.AllowedApparatusIds.Contains(a.Id))) + _project.Parameters.NSplitMax + 4);

            while (level.Count > 0 && depthGuard <= maxDepth)
            {
                if (_run.Cancellation.IsCancellationRequested) break;
                var next = new List<(State State, double Ub, bool PreEvaluated, MoveKind Kind)>();
                foreach (var (state, ubTuple, preEvaluated, kindLevel) in level)
                {
                    if (_run.Cancellation.IsCancellationRequested || StatesEvaluated >= _run.MaxStates) break;

                    double q, ua, ub = ubTuple;
                    if (preEvaluated)
                    {
                        q = _visited.Entries[state.CanonicalKey].QFixMw;
                        ua = _visited.Entries[state.CanonicalKey].UaFixMwK;
                    }
                    else
                    {
                        (var cut, q, ua, ub, _) = EvaluateCoarse(state, _bestQ, beamMode: true);
                        progress?.Invoke(new SearchProgress(StatesEvaluated, level.Count, _bestQ, state.Depth));
                        // Э1: WarmStart-корень не отбрасывается coarse-CUT (перекрестия факта —
                        // П1 на coarse; fine «спит» их и сходится) — иначе Best теряет факт-базу.
                        bool isWarmRoot = _run.WarmStart is not null && state.CanonicalKey == start.CanonicalKey;
                        if (cut && !isWarmRoot) continue;
                        var visit = _visited.Add(state.CanonicalKey, q, ua, SoftVector.Empty, coarse: true);
                        if (visit == VisitResult.Dominated) { StatesPruned++; continue; }
                    }
                    _visited.MarkRetained(state.CanonicalKey);

                    if (state.FreeApparatusIds.Count == 0)
                    {
                        var (valid, qFine) = EvaluateFineComplete(state);
                        if (valid && Better(state, qFine))
                        {
                            _bestQ = qFine;
                            _bestSleeping = _lastSleeping; _bestGross = _lastGross;
                            _bestMount = state.MountChanges;
                            _bestKey = state.CanonicalKey;
                            _bestState = state;
                            _bestUb = ub;
                            topKeys.Add(state.CanonicalKey);
                        }
                        // Х4 (аудит-приоритет 2): «полировка факта» — WarmStart complete-узел
                        // расширяется ходами R1/R4/R5 (перестановки/байпас/изъятия от базы «ДО»);
                        // R2/R3 от complete невозможны. Прочие complete — терминалы.
                        if (_run.WarmStart is null || state.CanonicalKey != start.CanonicalKey)
                            continue;
                    }

                    foreach (var move in _gen.Generate(state))
                    {
                        if (StatesEvaluated >= _run.MaxStates) { stateLimitBeam = true; break; }
                        State child;
                        try { child = StateOps.ApplyMove(_project, state, move); }
                        catch (IllegalMoveException) { continue; }
                        child = child.With(b => b.CanonicalKey = Canonizer.CanonicalKey(child));
                        // complete-ребёнок — терминал: минует coarse-отсечение, оценивается сразу fine
                        // (финальные правила П5/П7/П8 по раскладке действуют только на complete)
                        if (child.FreeApparatusIds.Count == 0)
                        {
                            var (validFin, qFin) = EvaluateFineComplete(child);
                            // S8 шаг 7: Нелдер–Мид по доле для complete-ребёнка с делениями
                            if (validFin && Better(child, qFin) && child.Splits.Count > 0)
                            {
                                var (refined, qRef) = SplitRefiner.Refine(_project, child, new Simulator(_project));
                                if (qRef > qFin)
                                {
                                    qFin = qRef;
                                    child = refined;
                                    topKeys.Add(refined.CanonicalKey);
                                }
                            }
                            if (validFin && Better(child, qFin))
                            {
                                _bestQ = qFin;
                                _bestSleeping = _lastSleeping; _bestGross = _lastGross;
                                _bestMount = child.MountChanges;
                                _bestKey = child.CanonicalKey;
                                _bestState = child;
                                // S1 (ревью-3, 1.6): UB родителя-корня (+∞) в сертификате — мусор; для
                                // complete-Best нижняя граница поддерева — сам узел: UB = Q_best. Иначе — UB узла.
                                _bestUb = double.IsPositiveInfinity(ubTuple) ? qFin : ubTuple;
                                topKeys.Add(child.CanonicalKey);
                                AddTop10(child, qFin);
                            }
                            // S1 (ревью-3, 1.5): невалидные состояния (Q=0) не попадают в топ-10 —
                            // иначе отчёт забивается вариантами с Q=0 (пустой прогон v13)
                            else if (validFin)
                            {
                                AddTop10(child, qFin);
                            }
                            continue;
                        }
                        var (cutChild, qChild, uaChild, ubChild, _) = EvaluateCoarse(child, _bestQ, beamMode: true);
                        if (cutChild) continue;
                        var addRes = _visited.Add(child.CanonicalKey, qChild, uaChild, SoftVector.Empty, coarse: true);
                        if (addRes == VisitResult.Dominated) { StatesPruned++; continue; }
                        next.Add((child, ubChild, true, move.Kind));
                    }
                }

                // beam: R2-вставки наверх, затем R3-деления (шаг 4), затем остальные;
                // далее UB desc, тайбрейк — ключ, затем глубина
                var ranked = next
                    .OrderByDescending(x => x.Kind == MoveKind.R2Insert)
                    .ThenByDescending(x => x.Kind == MoveKind.R3Split)
                    .ThenBy(x => -x.Ub)
                    .ThenBy(x => x.State.CanonicalKey, StringComparer.Ordinal)
                    .ThenBy(x => x.State.Depth)
                    .ToList();
                // S13: чекпоинт по периодичности (уровень + incumbent)
                MaybeCheckpoint(next.Select(x => (x.State, x.Ub)).ToList());

                // beam: W лучших; pre-флаг сохраняется (ленивые R1/R4/R5 не в Visited — оценка при обработке)
                level = ranked.Take(w).Select(x => (x.State, x.Ub, x.PreEvaluated, x.Kind)).ToList();
                foreach (var evicted in ranked.Skip(w))
                    archive.Add(evicted.State, evicted.Ub);

                // Г3 rescue: вернуть из архива UB > Q_best
                var rescued = archive.Rescue(_bestQ);
                rescuedTotal += rescued.Count;
                foreach (var st in rescued)
                {
                    // Шаг 6-остаток: кэш метрик при доборе (beam-ключ)
                    var rk = st.CanonicalKey + "|b";
                    if (_metricCache.TryGetValue(rk, out var mRes))
                    {
                        level.Add((st, mRes.Ub, _visited.Entries.ContainsKey(st.CanonicalKey), MoveKind.R2Insert));
                        continue;
                    }
                    var sim = new Simulator(_project);
                    var res = sim.Simulate(st, SimLevel.Coarse);
                    var tails = UpperBound.ResidualTails(_project, st, res);
                    double ubRescued = UpperBound.UbMw(_project, st, res, tails, _bestQ, coarse: true);
                    level.Add((st, ubRescued, _visited.Entries.ContainsKey(st.CanonicalKey), MoveKind.R2Insert));
                }
                depthGuard++;
            }

            sw.Stop();
            RefineBest(topKeys);
            var cert = new SearchCertificate(
                $"BeamSearch(W={w})", _bestQ, _bestUb,
                _bestQ >= 0 ? _bestUb - _bestQ : double.NaN,
                GuaranteeComplete: false,
                DegradedReason: "beam-режим: гарантия ограничена шириной луча W; UB — coarse-оценка (завышена к fine)" + (stateLimitBeam ? "; лимит состояний MaxStates исчерпан" : ""),
                StatesEvaluated, StatesPruned, StatesFlagged, rescuedTotal,
                sw.ElapsedMilliseconds, _project.RulesVersion, _run.Seed,
                Cancelled: _run.Cancellation.IsCancellationRequested,
                RulesGuarantee: RulesGuaranteeLine,
                SleepingCount: _bestSleeping,
                SleepPenaltyMwApplied: _project.Parameters.SleepPenaltyMw,
                QGrossMw: _bestSleeping > 0 ? _bestGross : _bestQ);
            LogMiss.Info("SEARCH", cert.ToString());
            var report = _bestState is null ? NoSolution.Build(_project, cert, _pipeline.Stats, _run.WarmStart) : null;
            return new SearchOutcome(_bestState, cert, topKeys, report, _top10.Count > 0 ? _top10.ToList() : null);
        }
    }
}
```

```csharp









namespace Pinchess.Engine.Search;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Sim;

/// <summary>Исключение применения недопустимого хода — признак ошибки генерации, не пользовательская ситуация.</summary>
public sealed class IllegalMoveException : Exception
{
    public IllegalMoveException(string message) : base(message) { }
}

/// <summary>
/// Операции над частичными состояниями (S5): применение ходов, процедурная
/// перегенерация остаточных сегментов, метрики через симулятор.
/// </summary>
public static class StateOps
{
    /// <summary>
    /// Остаточные сегменты потоков: до первого аппарата, между аппаратами, после последнего
    /// (bypass-аппараты поток не режут). В S5 границы по температуре — границы потока
    /// (TStart/TTarget); уточнение по решению — в S6 (UB по остаточным кривым).
    /// </summary>
    public static List<ResidualSegment> ResidualSegments(ProjectSpec project, IReadOnlyList<AppInstance> committed)
    {
        var result = new List<ResidualSegment>();
        foreach (var flow in project.Flows)
        {
            var chain = committed
                .Where(i => i.FlowId == flow.Id && i.Side == (flow.IsHot ? Side.Hot : Side.Cold) && !i.Bypass)
                .OrderBy(i => i.PositionIndex)
                .ToList();

            var active = chain.Where(i => !i.Bypass).ToList();

            // сегмент «до первого» и «между» — по позициям; плюс хвост после последнего
            var cuts = new List<(int Pos, double Split)>(); // заготовка делений (S8)
            if (active.Count == 0)
            {
                result.Add(new ResidualSegment(flow.Id, flow.IsHot, flow.FlowRateKgH, flow.TStartC, flow.TTargetC, flow.AllowSplit, $"{flow.Id}:pre"));
                continue;
            }

            result.Add(new ResidualSegment(flow.Id, flow.IsHot, flow.FlowRateKgH, flow.TStartC, flow.TTargetC, flow.AllowSplit, $"{flow.Id}:pre"));
            for (int i = 1; i < active.Count; i++)
                result.Add(new ResidualSegment(flow.Id, flow.IsHot, flow.FlowRateKgH, flow.TStartC, flow.TTargetC, flow.AllowSplit, $"{flow.Id}:{active[i - 1].ApparatusId}->{active[i].ApparatusId}"));
            result.Add(new ResidualSegment(flow.Id, flow.IsHot, flow.FlowRateKgH, flow.TStartC, flow.TTargetC, flow.AllowSplit, $"{flow.Id}:post"));
        }
        return result;
    }

    /// <summary>Г1/v13: свободный старт поиска «с нуля» — независимо от InitialInstances:
    /// все аппараты свободны. Факт-схема остаётся в InitialInstances для сверки «ДО/ПОСЛЕ».</summary>
    public static State BlankState(ProjectSpec project)
    {
        var b = new StateBuilder(new State());
        b.FreeApparatusIds = project.Apparatus.Select(a => a.Id).ToList();
        b.ResidualHot = ResidualSegments(project, Array.Empty<AppInstance>()).Where(s => s.IsHot).ToList();
        b.ResidualCold = ResidualSegments(project, Array.Empty<AppInstance>()).Where(s => !s.IsHot).ToList();
        return b.Build();
    }

    /// <summary>Применение хода к состоянию. Частичное состояние всегда с двусторонними аппаратами.</summary>
    public static State ApplyMove(ProjectSpec project, State state, Move move)
    {
        var b = new StateBuilder(state);
        b.Depth = state.Depth + 1;
        b.ParentKey = state.CanonicalKey;
        b.LastMoveId = move.MoveId;

        var committed = new List<AppInstance>(state.Committed);
        var free = new List<string>(state.FreeApparatusIds);

        switch (move.Kind)
        {
            case MoveKind.R1Swap:
            {
                var byId = committed.Where(i => i.ApparatusId == move.ApparatusId).ToList();
                if (byId.Count < 2) throw new IllegalMoveException($"R1: аппарат «{move.ApparatusId}» не в схеме.");
                var hotInst = byId.First(i => i.Side == Side.Hot);
                var coldInst = byId.First(i => i.Side == Side.Cold);
                // S8 (шаг 2б): перестановка — только в пределах пути аппарата (делённый поток)
                int hotPos = move.HotPosition ?? hotInst.PositionIndex;
                int coldPos = move.ColdPosition ?? coldInst.PositionIndex;
                ValidatePathPosition(state, hotInst, hotPos);
                ValidatePathPosition(state, coldInst, coldPos);
                committed.RemoveAll(i => i.ApparatusId == move.ApparatusId);
                // S2: сдвиг R1 отозван (регресс At5Economy, PSR 2.26а) — v21-семантика;
                // целевая позиция обязана быть свободной (генератор её не предлагает — apply проверяет явно).
                if (hotPos != hotInst.PositionIndex && committed.Any(i => i.Side == Side.Hot && i.ApparatusId != move.ApparatusId
                        && i.FlowId == (move.HotFlowId ?? hotInst.FlowId) && i.PositionIndex == hotPos))
                    throw new IllegalMoveException($"R1: горячая позиция {hotPos} потока «{move.HotFlowId ?? hotInst.FlowId}» занята (сдвиг отозван).");
                if (coldPos != coldInst.PositionIndex && committed.Any(i => i.Side == Side.Cold && i.ApparatusId != move.ApparatusId
                        && i.FlowId == (move.ColdFlowId ?? coldInst.FlowId) && i.PositionIndex == coldPos))
                    throw new IllegalMoveException($"R1: холодная позиция {coldPos} потока «{move.ColdFlowId ?? coldInst.FlowId}» занята (сдвиг отозван).");
                committed.Add(new AppInstance(hotInst.ApparatusId,
                    move.HotFlowId ?? hotInst.FlowId,
                    Side.Hot,
                    hotPos,
                    hotInst.SplitFractionA, hotInst.Bypass, hotInst.PathId)
                {
                    HotFraction = hotInst.HotFraction,
                    ColdFraction = hotInst.ColdFraction,
                    HotPathId = hotInst.HotPathId,
                    ColdPathId = hotInst.ColdPathId,
                });
                committed.Add(new AppInstance(coldInst.ApparatusId,
                    move.ColdFlowId ?? coldInst.FlowId,
                    Side.Cold,
                    coldPos,
                    coldInst.SplitFractionA, coldInst.Bypass, coldInst.PathId)
                {
                    HotFraction = coldInst.HotFraction,
                    ColdFraction = coldInst.ColdFraction,
                    HotPathId = coldInst.HotPathId,
                    ColdPathId = coldInst.ColdPathId,
                });
                break;
            }
            case MoveKind.R2Insert:
            {
                if (move.HotFlowId is null || move.ColdFlowId is null || move.HotPosition is null || move.ColdPosition is null)
                    throw new IllegalMoveException("R2: должны быть заданы обе стороны и позиции.");
                if (!free.Contains(move.ApparatusId)) throw new IllegalMoveException($"R2: аппарат «{move.ApparatusId}» уже в схеме.");

                if (move.SegmentId is not null)
                {
                    // S8: вставка в ветвь деления. Сторона деления идёт в ветвь (в конец ветви,
                    // со сдвигом аппаратов пути после точки на +1), противоположная — обычная позиция пути.
                    var split = state.Splits.FirstOrDefault(s => s.PathIdA == move.SegmentId || s.PathIdB == move.SegmentId);
                    if (split is null)
                        throw new IllegalMoveException($"R2: ветвь «{move.SegmentId}» не найдена (деление отсутствует).");
                    Side splitSide = split.IsHot ? Side.Hot : Side.Cold;
                    double frac = move.SegmentId == split.PathIdA ? split.FractionA : 1.0 - split.FractionA;
                    string branch = move.SegmentId;

                    var branchInsts = committed
                        .Where(i => i.Side == splitSide && i.ApparatusId != move.ApparatusId &&
                                    (splitSide == Side.Hot ? i.HotPathId : i.ColdPathId) == branch)
                        .OrderBy(i => i.PositionIndex).ToList();
                    double anchorPos = -1;
                    if (split.AnchorApparatusId.Length > 0)
                        anchorPos = committed.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId)?.PositionIndex ?? -1;
                    int posBranch = (int)anchorPos + 1 + branchInsts.Count;

                    committed = ShiftFlow(committed, split.FlowId, splitSide, posBranch);

                    int hotPos = splitSide == Side.Hot ? posBranch : move.HotPosition.Value;
                    int coldPos = splitSide == Side.Cold ? posBranch : move.ColdPosition.Value;

                    committed.Add(new AppInstance(move.ApparatusId, move.HotFlowId, Side.Hot, hotPos, 1.0, false,
                        splitSide == Side.Hot ? branch : "P0")
                    {
                        HotFraction = splitSide == Side.Hot ? frac : 1.0,
                        ColdFraction = 1.0,
                        HotPathId = splitSide == Side.Hot ? branch : "P0",
                        ColdPathId = "P0",
                    });
                    committed.Add(new AppInstance(move.ApparatusId, move.ColdFlowId, Side.Cold, coldPos, 1.0, false,
                        splitSide == Side.Cold ? branch : "P0")
                    {
                        HotFraction = 1.0,
                        ColdFraction = splitSide == Side.Cold ? frac : 1.0,
                        HotPathId = "P0",
                        ColdPathId = splitSide == Side.Cold ? branch : "P0",
                    });
                    free.RemoveAll(id => id == move.ApparatusId);
                    break;
                }

                // S2: сдвиг R2 отозван (регресс At5Economy, PSR 2.26а) — позиция требует свободной (v21-семантика)
                committed.Add(new AppInstance(move.ApparatusId, move.HotFlowId, Side.Hot, move.HotPosition.Value, 1.0, false, "P0"));
                committed.Add(new AppInstance(move.ApparatusId, move.ColdFlowId, Side.Cold, move.ColdPosition.Value, 1.0, false, "P0"));
                free.RemoveAll(id => id == move.ApparatusId);
                break;
            }
            case MoveKind.R1PairSwap:
            {
                // S2 (ревью-3, 1.3): обмен позициями двух аппаратов одной стороны потока.
                if (move.HotFlowId is null && move.ColdFlowId is null)
                    throw new IllegalMoveException("R1PairSwap: не задана сторона обмена.");
                bool hotSide = move.HotFlowId is not null;
                string flowId = hotSide ? move.HotFlowId! : move.ColdFlowId!;
                Side side = hotSide ? Side.Hot : Side.Cold;
                int posB = hotSide ? move.HotPosition!.Value : move.ColdPosition!.Value;
                var instA = committed.FirstOrDefault(i => i.ApparatusId == move.ApparatusId && i.Side == side && i.FlowId == flowId);
                if (instA is null)
                    throw new IllegalMoveException($"R1PairSwap: аппарат «{move.ApparatusId}» не найден на {side} стороне потока «{flowId}».");
                if (instA.PositionIndex == posB) break; // вырожденный обмен — без изменений
                var instB = committed.FirstOrDefault(i => i.ApparatusId != move.ApparatusId && i.Side == side &&
                    i.FlowId == flowId && i.PositionIndex == posB && !i.Bypass);
                if (instB is null)
                    throw new IllegalMoveException($"R1PairSwap: на позиции {posB} потока «{flowId}» ({side}) нет аппарата для обмена.");
                committed = committed.Select(i => i == instA ? i with { PositionIndex = posB }
                    : (i == instB ? i with { PositionIndex = instA.PositionIndex } : i)).ToList();
                break;
            }
            case MoveKind.R3Split:
            {
                // S8: деление сегмента на две ветви со смесителем (MVP: одно деление на поток)
                if (move.SegmentId is null || move.SplitFractionA is null)
                    throw new IllegalMoveException("R3: не заданы сегмент деления и доля.");
                string segPath = move.SegmentId;
                int colon = segPath.IndexOf(':');
                if (colon <= 0) throw new IllegalMoveException($"R3: сегмент «{segPath}» без потока.");
                string flowId = segPath[..colon];
                var flow = project.Flows.FirstOrDefault(f => f.Id == flowId);
                if (flow is null) throw new IllegalMoveException($"R3: поток «{flowId}» не найден.");
                if (!flow.AllowSplit || flow.MaxSplits <= 0)
                    throw new IllegalMoveException($"R3: поток «{flowId}» не разрешает деление.");
                if (segPath.Contains('|'))
                    throw new IllegalMoveException("R3: вложенные деления — вне MVP шага 2а.");
                if (state.Splits.Any(s => s.FlowId == flowId))
                    throw new IllegalMoveException($"R3: поток «{flowId}» уже делён (MVP — одно деление на поток).");
                double f = move.SplitFractionA.Value;
                if (f < project.Parameters.FMinFrac || f > 0.5)
                    throw new IllegalMoveException($"R3: доля {f} вне сетки/лимита (f_min, ≤0,5).");
                var seg = ResidualSegments(project, committed).FirstOrDefault(s => s.PathId == segPath);
                if (seg is null) throw new IllegalMoveException($"R3: сегмент «{segPath}» не найден.");

                Side side = flow.IsHot ? Side.Hot : Side.Cold;
                var p0Chain = committed
                    .Where(i => i.FlowId == flowId && i.Side == side && !i.Bypass &&
                                (side == Side.Hot ? i.HotPathId : i.ColdPathId) == "P0")
                    .OrderBy(i => i.PositionIndex).ToList();

                string anchorId = "";
                if (segPath.EndsWith(":pre", StringComparison.Ordinal))
                {
                    anchorId = ""; // деление в начале потока: все аппараты пути — после слияния
                }
                else if (segPath.EndsWith(":post", StringComparison.Ordinal))
                {
                    anchorId = p0Chain.Count > 0 ? p0Chain[^1].ApparatusId : "";
                }
                else
                {
                    // сегмент «F:X->Y»: якорь — аппарат X
                    int arrow = segPath.IndexOf("->", StringComparison.Ordinal);
                    int lastColon = segPath.LastIndexOf(':');
                    if (lastColon < 0 || arrow < lastColon + 1)
                        throw new IllegalMoveException($"R3: сегмент «{segPath}» не распознан.");
                    anchorId = segPath.Substring(lastColon + 1, arrow - lastColon - 1);
                    if (!p0Chain.Any(i => i.ApparatusId == anchorId))
                        throw new IllegalMoveException($"R3: якорь «{anchorId}» не найден в цепочке потока.");
                }

                b.Splits = state.Splits.Concat(new[]
                {
                    new SplitSpec(flowId, flow.IsHot, segPath, f, anchorId, segPath + "|A", segPath + "|B"),
                }).ToList();
                break;
            }
            case MoveKind.R4Bypass:
            {
                if (move.Bypass is null) throw new IllegalMoveException("R4: не задан флаг байпаса.");
                for (int i = 0; i < committed.Count; i++)
                    if (committed[i].ApparatusId == move.ApparatusId)
                        committed[i] = committed[i] with { Bypass = move.Bypass.Value };
                break;
            }
            case MoveKind.R5Remove:
            {
                if (!committed.Any(i => i.ApparatusId == move.ApparatusId))
                    throw new IllegalMoveException($"R5: аппарат «{move.ApparatusId}» не в схеме.");
                if (state.Splits.Any(s => s.AnchorApparatusId == move.ApparatusId))
                    throw new IllegalMoveException("R5: аппарат — якорь деления (S8): сначала изъять ветвевые аппараты и пересобрать деление.");
                committed.RemoveAll(i => i.ApparatusId == move.ApparatusId);
                free.Add(move.ApparatusId);
                break;
            }
            default:
                throw new IllegalMoveException($"Неизвестный ход {move.Kind}.");
        }

        // позиционные инварианты: уникальность (flow, side, pos)
        var dup = committed
            .GroupBy(i => (i.FlowId, i.Side, i.PositionIndex))
            .FirstOrDefault(g => g.Count() > 1);
        if (dup is not null)
            throw new IllegalMoveException($"Конфликт позиций: {dup.Key} занят {string.Join(", ", dup.Select(i => i.ApparatusId))}.");

        b.Committed = committed;
        b.FreeApparatusIds = free.Distinct().ToList();
        b.ResidualHot = ResidualSegments(project, committed).Where(s => s.IsHot).ToList();
        b.ResidualCold = ResidualSegments(project, committed).Where(s => !s.IsHot).ToList();
        b.MountChanges = state.MountChanges + move.Kind switch
        {
            MoveKind.R1Swap => 1,
            MoveKind.R2Insert => 1,
            MoveKind.R3Split => 1,
            MoveKind.R5Remove => 1,
            _ => 0,
        };
        return b.Build();
    }

    /// <summary>S8 (шаг 2б): позиция аппарата должна оставаться в пределах его пути (делённый поток).</summary>
    private static void ValidatePathPosition(State state, AppInstance inst, int newPos)
    {
        var split = state.Splits.FirstOrDefault(s => s.FlowId == inst.FlowId);
        if (split is null || split.IsHot != (inst.Side == Side.Hot)) return;
        Side side = inst.Side;
        var chain = state.Committed
            .Where(i => i.FlowId == inst.FlowId && i.Side == side && !i.Bypass && i.ApparatusId != inst.ApparatusId)
            .OrderBy(i => i.PositionIndex).ToList();
        double anchorPos = -1;
        if (split.AnchorApparatusId.Length > 0)
            anchorPos = chain.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId)?.PositionIndex ?? -1;
        var branchPositions = chain
            .Where(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) != "P0")
            .Select(i => i.PositionIndex).ToList();
        int maxBranch = branchPositions.Count > 0 ? branchPositions.Max() : (int)anchorPos;
        string path = side == Side.Hot ? inst.HotPathId : inst.ColdPathId;
        bool ok = path == "P0"
            ? newPos <= (int)anchorPos || newPos > maxBranch
            : newPos > (int)anchorPos && newPos <= maxBranch;
        if (!ok)
            throw new IllegalMoveException($"R1: позиция {newPos} вне пути аппарата «{inst.ApparatusId}» (делённый поток).");
    }

    /// <summary>S2-доводка: сдвиг пер-поточный (FlowId+Side+PositionIndex) — остался только для
    /// вставки в ветвь деления (S8); R1/R2 — без сдвига (v21-семантика, PSR 2.26а).</summary>
    private static List<AppInstance> ShiftFlow(List<AppInstance> committed, string flowId, Side side, int fromPos)
    {
        var result = new List<AppInstance>();
        foreach (var i in committed)
            result.Add(i.Side == side && i.FlowId == flowId && i.PositionIndex >= fromPos ? i with { PositionIndex = i.PositionIndex + 1 } : i);
        return result;
    }

    /// <summary>Начальное состояние проекта: все аппараты свободны (кроме обязательных — они ставятся R2).</summary>
    /// <summary>Начальное состояние: с Г1 — если в проекте заданы InitialInstances, они
    /// становятся зафиксированной схемой «ДО» (база для поиска); пусто — как раньше, все свободны.</summary>
    public static State InitialState(ProjectSpec project)
    {
        var committed = project.InitialInstances ?? Array.Empty<AppInstance>();
        var b = new StateBuilder(new State());
        if (committed.Count > 0)
        {
            b.Committed = committed;
            var used = committed.Select(i => i.ApparatusId).Distinct().ToHashSet();
            b.FreeApparatusIds = project.Apparatus.Select(a => a.Id).Where(id => !used.Contains(id)).ToList();
            b.ResidualHot = ResidualSegments(project, committed).Where(s => s.IsHot).ToList();
            b.ResidualCold = ResidualSegments(project, committed).Where(s => !s.IsHot).ToList();
        }
        else
        {
            b.FreeApparatusIds = project.Apparatus.Select(a => a.Id).ToList();
            b.ResidualHot = ResidualSegments(project, Array.Empty<AppInstance>()).Where(s => s.IsHot).ToList();
            b.ResidualCold = ResidualSegments(project, Array.Empty<AppInstance>()).Where(s => !s.IsHot).ToList();
        }
        return b.Build();
    }

    /// <summary>UA_fix активных аппаратов, МВт/К.</summary>
    public static double UaFix(ProjectSpec project, State state)
    {
        double ua = 0;
        foreach (var g in state.Committed.Where(i => !i.Bypass).GroupBy(i => i.ApparatusId))
        {
            var app = project.Apparatus.FirstOrDefault(a => a.Id == g.Key);
            if (app is not null) ua += app.AreaM2 * app.K0Wm2K;
        }
        return ua / 1e6;
    }

    /// <summary>
    /// Метрики частичного состояния: Q_fix — суммарная нагрузка посчитанной части
    /// (симулятор coarse), UA_fix — сумма A·K0 активных аппаратов (fine-K — в fine-оценке S6+).
    /// </summary>
    public static (double QFixMw, double UaFixMwK) EvaluateMetrics(ProjectSpec project, State state, SimLevel level = SimLevel.Coarse)
    {
        var sim = new Simulator(project);
        var result = sim.Simulate(state.Committed, level);
        double ua = state.Committed
            .Where(i => !i.Bypass)
            .GroupBy(i => i.ApparatusId)
            .Sum(g => (project.Apparatus.FirstOrDefault(a => a.Id == g.Key)?.AreaM2 ?? 0) *
                      (project.Apparatus.FirstOrDefault(a => a.Id == g.Key)?.K0Wm2K ?? 0)) / 1e6;
        return (result.QTotalMw, ua);
    }
}
```

### 3.8 Moves.cs — генератор ходов (полный листинг)

```csharp









namespace Pinchess.Engine.Search;

using Pinchess.Engine.Domain;

/// <summary>Типовые клеше-ходы (ТЗ v3, Приложение В; раскладка v1.2).</summary>
public enum MoveKind
{
    /// <summary>Перестановка: смена позиции и/или сопряжения существующего аппарата (М1 не растёт).</summary>
    R1Swap,
    /// <summary>S2 (ревью-3, 1.3): обмен позициями двух аппаратов одной стороны потока (М1 не растёт) —
    /// раскрывает пространство перестановок плотной цепочки (раньше — только хвост).</summary>
    R1PairSwap,
    /// <summary>Новое сопряжение: вставка свободного аппарата парой сторон (М1 +1).</summary>
    R2Insert,
    /// <summary>Деление потока (полная гидравлика ветвей — S8; в S5 — структурная заготовка).</summary>
    R3Split,
    /// <summary>Обход: включение/снятие байпаса аппарата.</summary>
    R4Bypass,
    /// <summary>Изъятие: аппарат возвращается в свободные.</summary>
    R5Remove,
}

/// <summary>
/// Ход. Null-поля — «без изменения». Для R1 меняется hot и/или cold подключение;
/// для R2 задаются оба; для R4 — Bypass; для R3 — сегмент и доля ветви A.
/// </summary>
public sealed record Move(
    MoveKind Kind,
    string ApparatusId,
    string? HotFlowId = null,
    int? HotPosition = null,
    string? ColdFlowId = null,
    int? ColdPosition = null,
    bool? Bypass = null,
    string? SegmentId = null,
    double? SplitFractionA = null)
{
    public string MoveId
    {
        get
        {
            var parts = new List<string> { Kind.ToString(), ApparatusId };
            if (HotFlowId is not null) parts.Add($"H:{HotFlowId}:{HotPosition?.ToString() ?? "?"}");
            if (ColdFlowId is not null) parts.Add($"C:{ColdFlowId}:{ColdPosition?.ToString() ?? "?"}");
            if (Bypass is not null) parts.Add($"B:{Bypass}");
            if (SegmentId is not null) parts.Add($"S:{SegmentId}:{SplitFractionA:G12}");
            return string.Join("|", parts);
        }
    }
}

/// <summary>
/// Генератор ходов (S5): валидные клеше по текущему состоянию.
/// Г2-ограничение «новые сопряжения открывают возможности» — в правилах отсечений (S6).
/// R3 генерируется только при AllowSplit потока; гидравлика ветвей — S8.
/// </summary>
public sealed class MoveGenerator
{
    private readonly ProjectSpec _project;
    // v22.1 (детерминизм): список потоков фиксирован Ordinal — рандомизация строкового хэша
    // .NET меняла порядок обхода ходов между процессами и строгие сканы флейкнули.
    private readonly List<string> _hotFlows;
    private readonly List<string> _coldFlows;
    private readonly Dictionary<string, HashSet<string>> _allowed;

    public MoveGenerator(ProjectSpec project)
    {
        _project = project;
        _hotFlows = project.Flows.Where(f => f.IsHot).Select(f => f.Id).OrderBy(x => x, StringComparer.Ordinal).ToList();
        _coldFlows = project.Flows.Where(f => !f.IsHot).Select(f => f.Id).OrderBy(x => x, StringComparer.Ordinal).ToList();
        _allowed = project.Flows.ToDictionary(f => f.Id, f => f.AllowedApparatusIds.ToHashSet());
    }

    public List<Move> Generate(State state, bool allowShiftPositions = false)
    {
        var moves = new List<Move>();
        var committed = state.Committed;

        var byId = committed.GroupBy(i => i.ApparatusId).ToDictionary(g => g.Key, g => g.ToList());
        // позиции ограничены количеством инстанций в КОНКРЕТНОМ потоке (включая bypass —
        // позиция уникальна независимо от байпаса)
        int CountIn(string flowId, Side side) => committed.Count(i => i.FlowId == flowId && i.Side == side);

        // R1: перестановки
        foreach (var (appId, insts) in byId)
        {
            var hotInst = insts.FirstOrDefault(i => i.Side == Side.Hot);
            var coldInst = insts.FirstOrDefault(i => i.Side == Side.Cold);

            if (hotInst is not null)
            {
                // S8 (шаг 2б): R1 разрешён и на делённых потоках — но позиции в пределах пути;
                // S2: сдвиг отозван (регресс At5Economy, PSR 2.26а) — фильтр занятости узкий
                // (v21-семантика); перестановки в середину — через R1PairSwap в RefineBest.
                bool hotPathLocked = state.Splits.Any(s => s.FlowId == hotInst.FlowId) || hotInst.HotPathId != "P0";
                foreach (var pos in PathPositions(state, hotInst))
                {
                    if (pos == hotInst.PositionIndex) continue;
                    if (!IsValidHotPlacement(appId, hotInst.FlowId, pos, committed)) continue;
                    moves.Add(new Move(MoveKind.R1Swap, appId, HotFlowId: hotInst.FlowId, HotPosition: pos));
                }
                // смена горячей стороны на другой поток — только если горячая сторона целая (не ветвь и не делённый поток)
                if (!hotPathLocked)
                    foreach (var flowId in _hotFlows.Where(f => _allowed[f].Contains(appId) && f != hotInst.FlowId && !state.Splits.Any(s => s.FlowId == f)))
                        for (int pos = 0; pos <= CountIn(flowId, Side.Hot); pos++)
                            if (IsValidHotPlacement(appId, flowId, pos, committed))
                                moves.Add(new Move(MoveKind.R1Swap, appId, HotFlowId: flowId, HotPosition: pos));
            }

            if (coldInst is not null)
            {
                bool coldPathLocked = state.Splits.Any(s => s.FlowId == coldInst.FlowId) || coldInst.ColdPathId != "P0";
                foreach (var pos in PathPositions(state, coldInst))
                {
                    if (pos == coldInst.PositionIndex) continue;
                    if (!IsValidColdPlacement(appId, coldInst.FlowId, pos, committed)) continue;
                    moves.Add(new Move(MoveKind.R1Swap, appId, ColdFlowId: coldInst.FlowId, ColdPosition: pos));
                }
                if (!coldPathLocked)
                    foreach (var flowId in _coldFlows.Where(f => _allowed[f].Contains(appId) && f != coldInst.FlowId && !state.Splits.Any(s => s.FlowId == f)))
                        for (int pos = 0; pos <= CountIn(flowId, Side.Cold); pos++)
                            if (IsValidColdPlacement(appId, flowId, pos, committed))
                                moves.Add(new Move(MoveKind.R1Swap, appId, ColdFlowId: flowId, ColdPosition: pos));
            }
        }

        // S2 (ревью-3, 1.3): R1PairSwap — обмен позициями двух аппаратов одной стороны потока.
        // Пары внутри одного пути (монотонность/правила отсекут недопустимые обмены).
        // v22: PairSwap генерируется ТОЛЬКО для RefineBest (allowShiftPositions: true) —
        // в основном потоке PairSwap раздувал frontier и ломал строгие сканы (PSR 2.26а).
        if (allowShiftPositions)
        {
        foreach (var group in committed.Where(i => !i.Bypass)
                     .GroupBy(i => (i.FlowId, i.Side, Path: i.Side == Side.Hot ? i.HotPathId : i.ColdPathId)))
        {
            var chain = group.OrderBy(i => i.PositionIndex).ToList();
            for (int a = 0; a < chain.Count; a++)
                for (int b = a + 1; b < chain.Count; b++)
                {
                    if (group.Key.Side == Side.Hot)
                        moves.Add(new Move(MoveKind.R1PairSwap, chain[a].ApparatusId,
                            HotFlowId: group.Key.FlowId, HotPosition: chain[b].PositionIndex));
                    else
                        moves.Add(new Move(MoveKind.R1PairSwap, chain[a].ApparatusId,
                            ColdFlowId: group.Key.FlowId, ColdPosition: chain[b].PositionIndex));
                }
        }

        }

        // R2: вставка свободных аппаратов. S2: сдвиг отозван (PSR 2.26а) — фильтр занятости узкий.
        foreach (var appId in state.FreeApparatusIds)
        {
            foreach (var hotFlow in _hotFlows.Where(f => _allowed[f].Contains(appId)))
                for (int hp = 0; hp <= CountIn(hotFlow, Side.Hot); hp++)
                {
                    if (!IsValidHotPlacement(appId, hotFlow, hp, committed)) continue;
                    foreach (var coldFlow in _coldFlows.Where(f => _allowed[f].Contains(appId)))
                        for (int cp = 0; cp <= CountIn(coldFlow, Side.Cold); cp++)
                        {
                            if (hotFlow == coldFlow) continue;
                            if (!IsValidColdPlacement(appId, coldFlow, cp, committed)) continue;
                            moves.Add(new Move(MoveKind.R2Insert, appId,
                                HotFlowId: hotFlow, HotPosition: hp,
                                ColdFlowId: coldFlow, ColdPosition: cp));
                        }
                }
        }

        // S8: R2 в ветви делений (сторона деления — в конец ветви, противоположная — обычная позиция пути)
        foreach (var split in state.Splits)
        {
            Side splitSide = split.IsHot ? Side.Hot : Side.Cold;
            foreach (var branch in new[] { split.PathIdA, split.PathIdB })
            {
                var branchInsts = committed.Where(i => i.Side == splitSide &&
                            (splitSide == Side.Hot ? i.HotPathId : i.ColdPathId) == branch)
                    .OrderBy(i => i.PositionIndex).ToList();
                double anchorPos = -1;
                if (split.AnchorApparatusId.Length > 0)
                    anchorPos = committed.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId)?.PositionIndex ?? -1;
                int posBranch = (int)anchorPos + 1 + branchInsts.Count;

                foreach (var appId in state.FreeApparatusIds)
                {
                    if (splitSide == Side.Hot)
                    {
                        foreach (var coldFlow in _coldFlows.Where(f => _allowed[f].Contains(appId)))
                            for (int cp = 0; cp <= CountIn(coldFlow, Side.Cold); cp++)
                                if (IsValidColdPlacement(appId, coldFlow, cp, committed))
                                    moves.Add(new Move(MoveKind.R2Insert, appId,
                                        HotFlowId: split.FlowId, HotPosition: posBranch,
                                        ColdFlowId: coldFlow, ColdPosition: cp, SegmentId: branch));
                    }
                    else
                    {
                        foreach (var hotFlow in _hotFlows.Where(f => _allowed[f].Contains(appId)))
                            for (int hp = 0; hp <= CountIn(hotFlow, Side.Hot); hp++)
                                if (IsValidHotPlacement(appId, hotFlow, hp, committed))
                                    moves.Add(new Move(MoveKind.R2Insert, appId,
                                        HotFlowId: hotFlow, HotPosition: hp,
                                        ColdFlowId: split.FlowId, ColdPosition: posBranch, SegmentId: branch));
                    }
                }
            }
        }

        // R4: обход (toggle)
        foreach (var appId in byId.Keys.OrderBy(x => x, StringComparer.Ordinal))
        {
            bool current = byId[appId].Any(i => i.Bypass);
            moves.Add(new Move(MoveKind.R4Bypass, appId, Bypass: !current));
        }

        // R5: изъятие (S8: якорь деления не изымается)
        foreach (var appId in byId.Keys.OrderBy(x => x, StringComparer.Ordinal))
        {
            if (state.Splits.Any(s => s.AnchorApparatusId == appId)) continue;
            moves.Add(new Move(MoveKind.R5Remove, appId));
        }

        // R3: деления корневых сегментов (S8; MVP — одно деление на поток)
        foreach (var flow in _project.Flows.Where(f => f.AllowSplit && f.MaxSplits > 0))
        {
            if (state.Splits.Any(s => s.FlowId == flow.Id)) continue; // MVP: одно деление на поток
            var segs = flow.IsHot ? state.ResidualHot.Where(s => s.FlowId == flow.Id && !s.PathId.Contains('|'))
                                  : state.ResidualCold.Where(s => s.FlowId == flow.Id && !s.PathId.Contains('|'));
            foreach (var seg in segs)
                foreach (double frac in _project.Parameters.SplitGridPct)
                {
                    double f = frac / 100.0;
                    if (f < _project.Parameters.FMinFrac || f > 0.5) continue;
                    moves.Add(new Move(MoveKind.R3Split, "", SegmentId: seg.PathId, SplitFractionA: f));
                }
        }

                // Б11 (аудит 20.11): дедуп ходов — мусорные дубли (пустые/совпадающие диапазоны позиций)
        // не проходят в конвейер (StructuralDistinct по record-сравнению)
        return moves.Distinct().ToList();
    }

    /// <summary>
    /// S8 (шаг 2б): допустимые позиции перестановки аппарата — в пределах его пути.
    /// Целый поток: 0..n (вставка в конец); делённый поток, путь P0: [0..якорь] ∪ [после слияния..n];
    /// ветвь: позиции внутри своей ветви (между якорем и слиянием).
    /// </summary>
    private List<int> PathPositions(State state, AppInstance inst)
    {
        var result = new List<int>();
        Side side = inst.Side;
        var chain = state.Committed
            .Where(i => i.FlowId == inst.FlowId && i.Side == side && !i.Bypass)
            .OrderBy(i => i.PositionIndex).ToList();
        int maxPos = chain.Count > 0 ? chain[^1].PositionIndex : -1;
        var split = state.Splits.FirstOrDefault(s => s.FlowId == inst.FlowId);
        if (split is null || split.IsHot != (side == Side.Hot))
        {
            // S7-поведение: диапазон по числу инстанций потока (включая байпасные позиции)
            int countIn = state.Committed.Count(i => i.FlowId == inst.FlowId && i.Side == side);
            for (int pos = 0; pos <= countIn; pos++) result.Add(pos);
            return result;
        }

        double anchorPos = -1;
        if (split.AnchorApparatusId.Length > 0)
            anchorPos = chain.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId)?.PositionIndex ?? -1;
        var branchPositions = chain
            .Where(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) != "P0")
            .Select(i => i.PositionIndex).ToList();
        int maxBranch = branchPositions.Count > 0 ? branchPositions.Max() : (int)anchorPos;
        string path = side == Side.Hot ? inst.HotPathId : inst.ColdPathId;

        if (path == "P0")
        {
            for (int pos = 0; pos <= (int)anchorPos; pos++) result.Add(pos); // до деления
            for (int pos = maxBranch + 1; pos <= maxPos + 1; pos++) result.Add(pos); // после слияния
        }
        else
        {
            for (int pos = (int)anchorPos + 1; pos <= maxBranch; pos++) result.Add(pos); // внутри ветви
        }
        return result;
    }

    /// <summary>S2 (ревью-3, 1.3): проверка только допустимости сопряжения (позиция может быть
    /// занята — вставка выполняется со сдвигом).</summary>
    private bool IsHotAllowed(string appId, string flowId) =>
        _hotFlows.Contains(flowId) && _allowed.TryGetValue(flowId, out var set) && set.Contains(appId);

    private bool IsValidHotPlacement(string appId, string flowId, int pos, IReadOnlyList<AppInstance> committed) =>
        _hotFlows.Contains(flowId) && _allowed.TryGetValue(flowId, out var set) && set.Contains(appId) &&
        !committed.Any(i => i.Side == Side.Hot && i.FlowId == flowId && i.PositionIndex == pos);

    private bool IsColdAllowed(string appId, string flowId) =>
        _coldFlows.Contains(flowId) && _allowed.TryGetValue(flowId, out var set) && set.Contains(appId);

    private bool IsValidColdPlacement(string appId, string flowId, int pos, IReadOnlyList<AppInstance> committed) =>
        _coldFlows.Contains(flowId) && _allowed.TryGetValue(flowId, out var set) && set.Contains(appId) &&
        !committed.Any(i => i.Side == Side.Cold && i.FlowId == flowId && i.PositionIndex == pos);
}
```

### 3.9 Canonizer.cs — канонизация состояний С1/С4/С5 (полный листинг)

```csharp









using System.Globalization;

namespace Pinchess.Engine.Search;

using Pinchess.Engine.Domain;

/// <summary>
/// Канонизация состояний (ТЗ v3 разд. 23, раскладка С1/С4/С5).
/// С1: float-нормализация 12 значащих цифр (ToString G12), БЕЗ квантования —
/// разные состояния не схлопываются, эквивалентные совпадают.
/// С4: эквивалентности — порядок в списке подключений не несёт смысла: ключ строится
/// по отсортированным записям; S8 (шаг 3): ветви делений физически неразличимы —
/// канонический порядок ветвей по лексикографии состава: вставка аппарата в ветвь A
/// при долях (f, 1−f) эквивалентна вставке в ветвь B; оба состояния дают один ключ.
/// С5: инвариантность — ключ зависит только от структуры состояния, не от порядка генерации ходов.
/// </summary>
public static class Canonizer
{
    /// <summary>Нормализация числа: 12 значащих цифр (G12); NaN/∞ — литералами.</summary>
    public static string Normalize(double x)
    {
        if (double.IsNaN(x)) return "nan";
        if (double.IsPositiveInfinity(x)) return "inf";
        if (double.IsNegativeInfinity(x)) return "-inf";
        return x.ToString("G12", CultureInfo.InvariantCulture);
    }

    /// <summary>Состав ветви (для канонического порядка): отсортированные Id аппаратов пути.</summary>
    private static string BranchSignature(State state, string pathId) =>
        string.Join(",", state.Committed
            .Where(i => i.HotPathId == pathId || i.ColdPathId == pathId)
            .Select(i => i.ApparatusId)
            .OrderBy(x => x, StringComparer.Ordinal));

    /// <summary>
    /// Нормализация порядка ветвей С4 (S8 шаг 3): ветви физически неразличимы ТОЛЬКО вместе
    /// со своими долями — перестановка меняет и доли: (f, 1−f) ↔ (1−f, f). Переставляем,
    /// если канонически меньший «состав+доля» у ветви B: сравнение (состав, доля) пар лексикографически;
    /// при равных составах — меньшая доля остаётся в A (f ≤ 0,5 — сетка генератора).
    /// </summary>
    private static bool ShouldSwap(State state, SplitSpec sp)
    {
        string sigA = BranchSignature(state, sp.PathIdA);
        string sigB = BranchSignature(state, sp.PathIdB);
        int c = string.CompareOrdinal(sigB, sigA);
        if (c != 0) return c < 0;
        return 1.0 - sp.FractionA < sp.FractionA - 1e-12;
    }

    /// <summary>Канонический путь инстанции: для делённого потока ветви переименовываются по каноническому порядку.</summary>
    private static Dictionary<string, string> CanonicalPaths(State state)
    {
        var map = new Dictionary<string, string>();
        foreach (var sp in state.Splits)
        {
            bool swap = ShouldSwap(state, sp);
            map[sp.PathIdA] = swap ? sp.SegmentPathId + "|B" : sp.SegmentPathId + "|A";
            map[sp.PathIdB] = swap ? sp.SegmentPathId + "|A" : sp.SegmentPathId + "|B";
        }
        return map;
    }

    /// <summary>
    /// Канонический ключ частичного состояния: нормализованные пути ветвей + отсортированные
    /// записи подключений (аппарат | сторона | поток | плотная позиция | доли | байпас)
    /// + нормализованные записи делений + отсортированные сегменты.
    /// Эквивалентность С4: позиции с «дырками» эквивалентны плотной раскладке —
    /// позиции нормализуются плотными рангами по каждому (поток, сторона).
    /// </summary>
    public static string CanonicalKey(State state)
    {
        var paths = CanonicalPaths(state);
        string P(string p) => paths.TryGetValue(p, out var v) ? v : p;

        var lines = new List<string>();
        foreach (var group in state.Committed.GroupBy(i => (i.FlowId, i.Side)))
        {
            // плотные ранги — только по активным (не-bypass); байпас вне цепочки — без ранга
            int rank = 0;
            foreach (var inst in group.Where(i => !i.Bypass).OrderBy(i => i.PositionIndex))
            {
                lines.Add(string.Create(CultureInfo.InvariantCulture,
                    $"A|{inst.ApparatusId}|{(inst.Side == Side.Hot ? "H" : "C")}|{inst.FlowId}|{rank}|{Normalize(inst.SplitFractionA)}|{Normalize(inst.HotFraction)}|{Normalize(inst.ColdFraction)}|{P(inst.HotPathId)}|{P(inst.ColdPathId)}|0"));
                rank++;
            }
            foreach (var inst in group.Where(i => i.Bypass).OrderBy(i => i.ApparatusId, StringComparer.Ordinal))
            {
                lines.Add(string.Create(CultureInfo.InvariantCulture,
                    $"A|{inst.ApparatusId}|{(inst.Side == Side.Hot ? "H" : "C")}|{inst.FlowId}|b|{Normalize(inst.SplitFractionA)}|{Normalize(inst.HotFraction)}|{Normalize(inst.ColdFraction)}|{P(inst.HotPathId)}|{P(inst.ColdPathId)}|1"));
            }
        }
        foreach (var sp in state.Splits)
        {
            bool swap = ShouldSwap(state, sp);
            double fracA = swap ? 1.0 - sp.FractionA : sp.FractionA;
            lines.Add(string.Create(CultureInfo.InvariantCulture,
                $"D|{sp.FlowId}|{(sp.IsHot ? "H" : "C")}|{sp.SegmentPathId}|{Normalize(fracA)}|{sp.AnchorApparatusId}|{sp.SegmentPathId}|A|{sp.SegmentPathId}|B"));
        }
        foreach (var seg in state.ResidualHot.Concat(state.ResidualCold))
        {
            lines.Add(string.Create(CultureInfo.InvariantCulture,
                $"S|{(seg.IsHot ? "H" : "C")}|{seg.FlowId}|{seg.PathId}|{Normalize(seg.RateKgH)}|{Normalize(seg.TLowC)}|{Normalize(seg.THighC)}"));
        }
        lines.Sort(StringComparer.Ordinal);
        return string.Join(";", lines);
    }
}
```

### 3.10 SplitRefiner.cs — Нелдер–Мид по доле деления (полный листинг)

```csharp









using Pinchess.Engine.Domain;
using Pinchess.Engine.Sim;

namespace Pinchess.Engine.Search;

/// <summary>
/// S8 шаг 7: непрерывная оптимизация долей делений (Нелдер–Мид, 1-D последовательно).
/// Дискретная сетка R3 задаёт старт; после нахождения complete-состояния с делениями
/// доля деления уточняется NM-поиском по Q(f) на отрезке [FMinFrac; 0,5].
/// Функция цели — fine-нагрузка сходящегося состояния; несошедшиеся — −∞ (не принимаются).
/// Детерминизм: тайбрейки по значениям/индексам, без Rng.
/// </summary>
public static class SplitRefiner
{
    public static (State State, double Q) Refine(
        ProjectSpec project, State state, Simulator sim,
        double epsConv = 1e-3, int maxEvalPerDim = 24)
    {
        if (state.Splits.Count == 0) return (state, double.NegativeInfinity);
        double epsQ = 1e-6;

        double Goal(double f)
        {
            var st = WithFractions(state, f);
            var r = sim.Simulate(st, SimLevel.Fine);
            return r.AllConverged ? r.QTotalMw : double.NegativeInfinity;
        }

        double cur = state.Splits[0].FractionA;
        double qCur = Goal(cur);
        if (double.IsNegativeInfinity(qCur)) return (state, qCur);

        double lo = Math.Max(project.Parameters.FMinFrac, 1e-6), hi = 0.5;
        // Нелдер–Мид 1-D: simplex из двух точек вокруг стартовой доли
        double a = Math.Min(Math.Max(cur - 0.08, lo), hi);
        double b = Math.Min(Math.Max(cur + 0.08, lo), hi);
        double fa = Goal(a), fb = Goal(b);
        int evals = 2;
        double bestX = cur, bestQ = qCur;
        if (fa > bestQ) { bestQ = fa; bestX = a; }
        if (fb > bestQ) { bestQ = fb; bestX = b; }
        while (evals < maxEvalPerDim && Math.Abs(b - a) > epsConv)
        {
            if (fa > fb) { (a, b) = (b, a); (fa, fb) = (fb, fa); } // a — лучший
            double xr = Math.Min(Math.Max(a + (a - b), lo), hi);   // отражение
            double fr = Goal(xr); evals++;
            if (fr < fa)
            {
                double xe = Math.Min(Math.Max(a + 2.0 * (a - b), lo), hi); // расширение
                double fe = Goal(xe); evals++;
                if (fe < fr) { b = a; fb = fa; a = xe; fa = fe; }
                else { b = xr; fb = fr; }
            }
            else
            {
                double xc = Math.Min(Math.Max(a + 0.5 * (b - a), lo), hi); // сжатие
                double fc = Goal(xc); evals++;
                if (fc < fb) { b = xc; fb = fc; }
                else { b = a; fb = fa; a = xc; fa = fc; }                  // усадка
            }
            if (fa > bestQ) { bestQ = fa; bestX = a; }
            if (fb > bestQ) { bestQ = fb; bestX = b; }
        }
        if (bestQ > qCur + epsQ) return (WithFractions(state, bestX), bestQ);
        return (state, qCur);
    }

    /// <summary>Состояние с заменой доли первого деления: FractionA = f, доли инстансов ветвей пересчитаны.</summary>
    public static State WithFractions(State state, double f)
    {
        var sp = state.Splits[0];
        var splits = new List<SplitSpec> { sp with { FractionA = f } };
        var committed = new List<AppInstance>();
        foreach (var inst in state.Committed)
        {
            if (sp.FlowId != inst.FlowId || sp.IsHot != (inst.Side == Side.Hot)) { committed.Add(inst); continue; }
            if (sp.IsHot)
            {
                if (inst.HotPathId == sp.PathIdA) committed.Add(inst with { HotFraction = f });
                else if (inst.HotPathId == sp.PathIdB) committed.Add(inst with { HotFraction = 1.0 - f });
                else committed.Add(inst);
            }
            else
            {
                if (inst.ColdPathId == sp.PathIdA) committed.Add(inst with { ColdFraction = f });
                else if (inst.ColdPathId == sp.PathIdB) committed.Add(inst with { ColdFraction = 1.0 - f });
                else committed.Add(inst);
            }
        }
        return state.With(b =>
        {
            b.Splits = splits;
            b.Committed = committed;
        });
    }
}
```

```csharp
        var crv = new EnthalpyCurve(project.Environments.First(e => e.Id == f.EnvironmentId));

        -FurnaceModel.Compute(project, sim.QTotalMw).FuelMw;
```

```csharp
namespace Pinchess.Engine.Furnace;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Sim;

/// <summary>
/// КП1.5: печной модуль в движке (раньше — только в runner). Печь = терминирующий
/// потребитель холодного потока: сеть греет нефть до tNetOut, печь добирает до TTargetC.
/// Энтальпии — ПО КРИВОЙ СРЕДЫ движка (env-таблица), не по собственному cp-профилю runner'а —
/// экономика согласована с сетевой моделью (аудит-2, п. 1.4).
/// η=0,80; Q_сгорания газа=33,5 МДж/м³ — значения runner'а (П1.5: редактируемые).
/// </summary>
public sealed record FurnaceInfo(double TNetOutC, double FuelMw, double GasM3h);

public static class FurnaceModel
{
    /// <summary>Газ из печной нагрузки: м³/ч = МВт · 3,6 · 1000 / (η · Q_сгорания).</summary>
    public static double GasFromFuelMw(double fuelMw, double eta = 0.80, double gasMjM3 = 33.5) =>
        fuelMw / eta * 3.6 * 1000.0 / gasMjM3;

    /// <summary>
    /// Печь: вход из сети qNetworkMw → tNetOut (по кривой среды, смешанная навалка всего потока —
    /// как в runner'е); добор до TTargetC; печная нагрузка и газ.
    /// </summary>
    public static FurnaceInfo Compute(ProjectSpec project, double qNetworkMw, string? flowId = null,
        double eta = 0.80, double gasMjM3 = 33.5)
    {
        var f = flowId is not null
            ? project.Flows.First(x => x.Id == flowId)
            : project.Flows.Where(x => !x.IsHot).OrderByDescending(x => x.TTargetC).First(); // печной — холодный с максимальной целью
        var crv = new EnthalpyCurve(project.Environments.First(e => e.Id == f.EnvironmentId));
        double qk = qNetworkMw * 1e3 * 3600.0 / f.FlowRateKgH + crv.H(f.TStartC); // кДж/кг (как runner: Q·1e3/(m/3600))
        double tOut = SolveIn(crv, qk, f.TStartC, f.TTargetC + 1.0);
        double fuelMw = Math.Max(0.0, f.FlowRateKgH * (crv.H(f.TTargetC) - crv.H(tOut)) / 3600.0 / 1000.0);
        return new FurnaceInfo(tOut, fuelMw, GasFromFuelMw(fuelMw, eta, gasMjM3));
    }

    private static double SolveIn(EnthalpyCurve crv, double qkJkg, double lo, double hi)
    {
        if (crv.H(lo) >= qkJkg) return lo;
        while (hi - lo > 1e-3)
        {
            double mid = 0.5 * (lo + hi);
            if (crv.H(mid) < qkJkg) lo = mid; else hi = mid;
        }
        return lo;
    }
}
```

### 3.14 PRules.cs — правила П1–П8, Ф1–Ф4 (полный листинг)

```csharp









namespace Pinchess.Engine.Rules.Impl;

using Pinchess.Engine.Domain;
using Pinchess.Engine.Sim;

/// <summary>Общие утилиты правил: напоры, допуски слоя.</summary>
public static class RuleHelp
{
    /// <summary>Противоточный напор d(a) = min(T_h_in − T_c_out; T_h_out − T_c_in).</summary>
    public static double DOf(AppCalc a) =>
        Math.Min(a.ThInC - a.TcOutC, a.ThOutC - a.TcInC);

    /// <summary>Допуск слоя: coarse — половина сетки, fine — 0,1 °C (float-шум, Р7).</summary>
    public static double Tolerance(RuleContext ctx) =>
        ctx.Coarse ? ctx.Project.Parameters.DGridC / 2.0 : 0.1;

    public static AppCalc? Find(SimResult sim, string appId) =>
        sim.Apparatus.FirstOrDefault(a => a.ApparatusId == appId);

    /// <summary>Активная (не-bypass) цепочка стороны потока по позициям.</summary>
    public static List<AppInstance> Chain(State state, string flowId, Side side) =>
        state.Committed
            .Where(i => i.FlowId == flowId && i.Side == side && !i.Bypass)
            .OrderBy(i => i.PositionIndex)
            .ToList();

    /// <summary>
    /// S1 (ревью-3, 1.4): «худший» FLAG из накопленных. Раньше правила возвращали Flag при первом
    /// мягком нарушении — CUT на следующих аппаратах пропускался. Теперь FLAG накапливается,
    /// CUT возвращается немедленно, Flag — после полного прохода.
    /// </summary>
    public static RuleResult WorseFlag(RuleResult? current, RuleResult candidate) =>
        current is null || candidate.Severity > current.Severity ? candidate : current;
}

/// <summary>
/// П1. Термодинамическая разрешимость аппарата: d(a) ≥ 0; жёсткий 0 °C.
/// [Р1]: d &lt; −tol — CUT; −tol ≤ d &lt; 0 — FLAG MED (только coarse); иначе PASS. На fine — жёстко.
/// </summary>
public sealed class P1Thermodynamic : ICutRule
{
    public string Id => "П1";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        if (ctx.Sim is null) return RuleResult.Pass(Id);
        double tol = RuleHelp.Tolerance(ctx);
        // S1 (ревью-3, 1.4): FLAG накапливается — CUT на последующем аппарате не должен пропускаться
        RuleResult? worstFlag = null;
        foreach (var a in ctx.Sim.Apparatus)
        {
            double d = RuleHelp.DOf(a);
            // S8-дополнение: «спящий» аппарат (Q=0 при d<0) — корректное выключение (нет напора —
            // нет теплообмена, второй закон не нарушен): FLAG, не CUT; П8 не режет спящие аппараты.
            // Ограничитель: |d| ≤ SleepTolC (default 0 — бит-в-бит прежнее поведение; факт-сцены — 8)
            bool sleeping = Math.Abs(a.QMw) <= 1e-9 && d < 0 && d >= -ctx.Project.Parameters.SleepTolC;
            if (d < -tol && !sleeping)
                return RuleResult.Cut(Id, $"d={d:0.0} °C < −tol ({-tol:0.0})",
                    new Dictionary<string, double> { ["d"] = d, ["tol"] = -tol });
            if (d < 0 && sleeping)
                worstFlag = RuleHelp.WorseFlag(worstFlag, RuleResult.Flag(Id, $"спящий аппарат: d={d:0.0} °C при Q=0",
                    SoftSeverity.Med, new Dictionary<string, double> { ["d"] = d }));
            if (!ctx.Coarse && d < 0)
                return RuleResult.Cut(Id, $"fine: d={d:0.0} °C < 0",
                    new Dictionary<string, double> { ["d"] = d });
            if (ctx.Coarse && d < 0)
                worstFlag = RuleHelp.WorseFlag(worstFlag, RuleResult.Flag(Id, $"coarse: d={d:0.0} °C в допуске", SoftSeverity.Med,
                    new Dictionary<string, double> { ["d"] = d }));
        }
        return worstFlag ?? RuleResult.Pass(Id);
    }
}

/// <summary>
/// П2. Монотонность «слева горячий сильнее» (единый критерий Д3).
/// Перекрёстие разрешено при P ≤ ΔT_overlap и h = min(d(a_i), d(a_{i+1})) ≥ ΔT_overlap.
/// [Р2]: P=0 → PASS; 0 &lt; P ≤ ΔT_overlap и h ≥ ΔT_overlap → FLAG LOW; иначе CUT.
/// S8-дополнение: «спящий» аппарат (Q=0 при d&lt;0) из пар монотонности исключается —
/// корректное выключение не нарушает монотонность активной части пути.
/// </summary>
public sealed class P2Monotonic : ICutRule
{
    public string Id => "П2";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        if (ctx.Sim is null) return RuleResult.Pass(Id);
        double tol = RuleHelp.Tolerance(ctx);
        double overlap = ctx.Project.Parameters.DtolOverlapC;
        var byId = ctx.Sim.Apparatus.ToDictionary(a => a.ApparatusId);
        // S1 (ревью-3, 1.4): FLAG накапливается — CUT на последующей паре не должен пропускаться
        RuleResult? worstFlag = null;

        foreach (var flow in ctx.Project.Flows)
        {
            var side = flow.IsHot ? Side.Hot : Side.Cold;
            var chain = RuleHelp.Chain(ctx.State, flow.Id, side);
            for (int i = 0; i + 1 < chain.Count; i++)
            {
                var ai = RuleHelp.Find(ctx.Sim, chain[i].ApparatusId);
                var an = RuleHelp.Find(ctx.Sim, chain[i + 1].ApparatusId);
                if (ai is null || an is null) continue;
                // S8-дополнение: «спящий» аппарат (Q=0 при d<0) из пар монотонности исключается —
                // корректное выключение не нарушает монотонность активной части пути
                bool sleepA = Math.Abs(ai.QMw) <= 1e-9 && RuleHelp.DOf(ai) < 0 && RuleHelp.DOf(ai) >= -ctx.Project.Parameters.SleepTolC;
                bool sleepB = Math.Abs(an.QMw) <= 1e-9 && RuleHelp.DOf(an) < 0 && RuleHelp.DOf(an) >= -ctx.Project.Parameters.SleepTolC;
                if (sleepA || sleepB) continue;
                // S8 (шаг 4): сравнение монотонности — только в пределах ОДНОГО пути.
                // Аппараты разных ветвей деления параллельны (не соседи по потоку),
                // переходы путь→путь идут через смеситель — сравнение между путями не применяется.
                // П1/П3 индивидуально проверяют напор каждого аппарата ветви.
                string pathA = chain[i].Side == Side.Hot ? chain[i].HotPathId : chain[i].ColdPathId;
                string pathB = chain[i + 1].Side == Side.Hot ? chain[i + 1].HotPathId : chain[i + 1].ColdPathId;
                if (!string.Equals(pathA, pathB, StringComparison.Ordinal)) continue;
                double p, h;
                if (flow.IsHot)
                {
                    p = an.ThInC - ai.ThOutC;   // > 0: горячий «поднялся» по ходу — нарушение
                    h = Math.Min(RuleHelp.DOf(ai), RuleHelp.DOf(an));
                }
                else
                {
                    p = ai.TcOutC - an.TcInC;   // > 0: холодный «опустился» — нарушение
                    h = Math.Min(RuleHelp.DOf(ai), RuleHelp.DOf(an));
                }

                if (p <= tol)
                    continue; // PASS (в пределах допуска слоя)

                if (p <= overlap && h >= overlap)
                {
                    worstFlag = RuleHelp.WorseFlag(worstFlag, RuleResult.Flag(Id,
                        $"{flow.Id}: перекрёстие P={p:0.0} °C при напоре h={h:0.0} °C — норма противотока",
                        SoftSeverity.Low,
                        new Dictionary<string, double> { ["P"] = p, ["h"] = h, ["overlap"] = overlap }));
                    continue; // пара обработана как FLAG — CUT только для пар вне порога
                }

                return RuleResult.Cut(Id,
                    $"{flow.Id}: P={p:0.0} °C, h={h:0.0} °C, ΔT_overlap={overlap:0.0}",
                    new Dictionary<string, double> { ["P"] = p, ["h"] = h, ["overlap"] = overlap });
            }
        }
        return worstFlag ?? RuleResult.Pass(Id);
    }
}

/// <summary>
/// П3. Минимальный напор Tmin: d(a) ≥ Tmin; d &lt; Tmin − tol — CUT;
/// [Tmin−tol; Tmin) — FLAG MED (coarse); на fine — жёстко.
/// </summary>
public sealed class P3MinApproach : ICutRule
{
    public string Id => "П3";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        if (ctx.Sim is null) return RuleResult.Pass(Id);
        double tol = RuleHelp.Tolerance(ctx);
        double tmin = ctx.Project.Parameters.TminC;
        // S1 (ревью-3, 1.4): FLAG накапливается — CUT на последующем аппарате не должен пропускаться
        RuleResult? worstFlag = null;
        foreach (var a in ctx.Sim.Apparatus)
        {
            double d = RuleHelp.DOf(a);
            // S8-дополнение: «спящий» аппарат (Q=0 при d<0) — корректное выключение: FLAG, не CUT
            bool sleeping = Math.Abs(a.QMw) <= 1e-9 && d < 0 && d >= -ctx.Project.Parameters.SleepTolC;
            if (d < tmin - tol && !sleeping)
                return RuleResult.Cut(Id, $"d={d:0.0} °C < Tmin−tol ({tmin:0.0})",
                    new Dictionary<string, double> { ["d"] = d, ["tmin"] = tmin });
            if (ctx.Coarse && d < tmin)
                worstFlag = RuleHelp.WorseFlag(worstFlag, RuleResult.Flag(Id, $"coarse: d={d:0.0} °C в допуске до Tmin={tmin:0.0}", SoftSeverity.Med,
                    new Dictionary<string, double> { ["d"] = d, ["tmin"] = tmin }));
        }
        return worstFlag ?? RuleResult.Pass(Id);
    }
}

/// <summary>
/// П4. Скоростные ограничения: r_out = max(0, (v_min−v)/v_min, (v−v_max)/v_max);
/// r_out &gt; 0,20 — CUT; 0 &lt; r_out ≤ 0,20 — FLAG LOW. Границы: жидкости 0,5–2,0; газы 10–30 м/с.
/// </summary>
public sealed class P4Speeds : ICutRule
{
    public string Id => "П4";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        if (ctx.Sim is null) return RuleResult.Pass(Id);
        var p = ctx.Project.Parameters;
        var svc = new Props.EnvironmentService(ctx.Project);
        // S1 (ревью-3, 1.4): FLAG накапливается — CUT на последующем аппарате не должен пропускаться
        RuleResult? worstFlag = null;
        foreach (var inst in ctx.State.Committed.Where(i => !i.Bypass))
        {
            var app = ctx.Project.Apparatus.FirstOrDefault(x => x.Id == inst.ApparatusId);
            var flow = ctx.Project.Flows.FirstOrDefault(f => f.Id == inst.FlowId);
            if (app is null || flow is null) continue;
            var calc = RuleHelp.Find(ctx.Sim, inst.ApparatusId);
            if (calc is null) continue;

            bool isHot = inst.Side == Side.Hot;
            var env = ctx.Project.Environments.First(e => e.Id == flow.EnvironmentId);
            double tAvg = isHot ? 0.5 * (calc.ThInC + calc.ThOutC) : 0.5 * (calc.TcInC + calc.TcOutC);
            // S8 (шаг 4): аппарат в ветви — фактический расход = доля ветви; номинал — полный расход потока
            double frac = isHot ? Math.Clamp(inst.HotFraction, 0.0, 1.0) : Math.Clamp(inst.ColdFraction, 0.0, 1.0);
            double rate = flow.FlowRateKgH * frac;
            var sideCtx = new Physics.SideContext(flow.EnvironmentId, rate, flow.FlowRateKgH,
                isHot ? calc.ThInC : calc.TcInC, isHot ? calc.ThOutC : calc.TcOutC, isHot);
            double v = Physics.FinePhysics.VelocityOf(app, sideCtx, svc);
            double vMin = env.Kind == "gas" ? p.VGasMinMs : p.VTurbMinMs;
            double vMax = env.Kind == "gas" ? p.VGasMaxMs : p.VTurbMaxMs;
            double rOut = Physics.PressureDrop.SpeedRelOut(v, vMin, vMax);
            if (rOut > p.VRoutCut)
                return RuleResult.Cut(Id, $"{inst.ApparatusId}·{flow.Id}: v={v:0.00} м/с, r_out={rOut:0.00}",
                    new Dictionary<string, double> { ["v"] = v, ["rOut"] = rOut });
            if (rOut > 0)
                worstFlag = RuleHelp.WorseFlag(worstFlag, RuleResult.Flag(Id, $"{inst.ApparatusId}·{flow.Id}: v={v:0.00} м/с (r_out={rOut:0.00})",
                    SoftSeverity.Low,
                    new Dictionary<string, double> { ["v"] = v, ["rOut"] = rOut }));
        }
        return worstFlag ?? RuleResult.Pass(Id);
    }
}

/// <summary>
/// П5-lb. Оптимистичная нижняя оценка dP по потоку: Σ dP_nom·(v_min/v_nom)² по committed
/// + Σ dP_min обязательных аппаратов с allowed={p} (+ узлы пути — S8). Превышение бюджета
/// + eps_dP — CUT. Монотонность dP(v) подтверждена тестом (S4) — условие Р3.
/// </summary>
public sealed class P5Lb : ICutRule
{
    public string Id => "П5-lb";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        var p = ctx.Project.Parameters;
        foreach (var flow in ctx.Project.Flows)
        {
            if (flow.DpBudgetMpa <= 0) continue;
            double vMin = ctx.Project.Environments.First(e => e.Id == flow.EnvironmentId).Kind == "gas"
                ? p.VGasMinMs : p.VTurbMinMs;
            double lb = 0;
            foreach (var inst in ctx.State.Committed.Where(i => i.FlowId == flow.Id && !i.Bypass))
            {
                var app = ctx.Project.Apparatus.FirstOrDefault(x => x.Id == inst.ApparatusId);
                if (app is null) continue;
                double vNom = inst.Side == Side.Hot ? app.NominalVhMs : app.NominalVcMs;
                double dpNom = inst.Side == Side.Hot ? app.DpNomHMPa : app.DpNomCMPa;
                if (dpNom <= 0) continue;
                // S8 (шаг 4): аппарат в ветви — расход = доля ветви; нижняя оценка dP масштабируется
                // квадратом доли (dP ∝ v² в турбулентной форме) — занижаем, для lb это безопасно
                double frac = inst.Side == Side.Hot ? Math.Clamp(inst.HotFraction, 0.0, 1.0)
                                                    : Math.Clamp(inst.ColdFraction, 0.0, 1.0);
                lb += dpNom * (vMin > 0 && vNom > 0 ? (vMin / vNom) * (vMin / vNom) : 0) * frac * frac;
            }
            // обязательные аппараты, которые могут быть только на этом потоке
            foreach (var app in ctx.Project.Apparatus.Where(a => a.IsMandatory && !ctx.State.Committed.Any(i => i.ApparatusId == a.Id)))
            {
                bool onlyHere = ctx.Project.Flows.Where(f => f.AllowedApparatusIds.Contains(app.Id))
                    .All(f => f.Id == flow.Id);
                if (!onlyHere) continue;
                double dpNom = flow.IsHot ? app.DpNomHMPa : app.DpNomCMPa;
                if (dpNom > 0) lb += dpNom; // при v_min сверх номинала dP не меньше минимального
            }

            if (lb > flow.DpBudgetMpa + p.DpTolFrac * flow.DpBudgetMpa)
                return RuleResult.Cut(Id,
                    $"{flow.Id}: lb={lb:0.000} МПа > бюджет {flow.DpBudgetMpa:0.000}",
                    new Dictionary<string, double> { ["lb"] = lb, ["budget"] = flow.DpBudgetMpa });
        }
        return RuleResult.Pass(Id);
    }
}

/// <summary>
/// П6. Структурные лимиты: аппарат не более одного раза на поток; обязательные аппараты
/// использованы (если «неполный набор» запрещён — CUT, если разрешён — FLAG LOW).
/// Деления (n_split/f) — в полной реализации S8.
/// </summary>
public sealed class P6Structure : ICutRule
{
    public string Id => "П6";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        var dup = ctx.State.Committed
            .GroupBy(i => (i.ApparatusId, i.FlowId, i.Side))
            .FirstOrDefault(g => g.Count() > 1);
        if (dup is not null)
            return RuleResult.Cut(Id, $"аппарат {dup.Key.ApparatusId} повторно на {dup.Key.FlowId}");

        var unusedMandatory = ctx.Project.Apparatus
            .Where(a => a.IsMandatory && !ctx.State.Committed.Any(i => i.ApparatusId == a.Id))
            .ToList();
        if (unusedMandatory.Count > 0)
        {
            if (ctx.Project.IncompleteSetAllowed)
                return RuleResult.Flag(Id, "неполный набор: не использованы " + string.Join(",", unusedMandatory.Select(a => a.Id)), SoftSeverity.Low);
            return RuleResult.Cut(Id, "обязательные аппараты не использованы: " + string.Join(",", unusedMandatory.Select(a => a.Id)));
        }
        return RuleResult.Pass(Id);
    }
}

/// <summary>
/// П5. Полный перепад давления по каждому пути (финальное, только complete; S8).
/// Путь: цепочка P0 (аппараты целого расхода) + ветви делений (расход = доля ветви) со смесителем:
/// dP сети потока = Σ dP аппаратов пути P0 до деления + max(dP_ветви) + Σ dP аппаратов после слияния.
/// Форма: dP_i = dP_nom·(v_i/v_nom)^1,75 (турбулентная форма S4; вязкостные поправки — в fine-слое
/// полной модели, здесь упрощение с пометкой). CUT, если любой путь превышает бюджет с eps_dP = 1 %.
/// Для состояния без делений сводится к сумме по цепочке потока (эквивалент П5-lb при v≥v_min —
/// но здесь по ФАКТИЧЕСКИМ скоростям, а не по нижней границе).
/// </summary>
public sealed class P5Full : ICutRule
{
    public string Id => "П5";
    public string Version => "v1.3";
    public RuleResult Evaluate(RuleContext ctx)
    {
        var p = ctx.Project.Parameters;
        double eps = p.DpTolFrac;
        foreach (var flow in ctx.Project.Flows)
        {
            if (flow.DpBudgetMpa <= 0) continue;
            Side side = flow.IsHot ? Side.Hot : Side.Cold;
            var split = ctx.State.Splits.FirstOrDefault(s => s.FlowId == flow.Id);
            var chain = RuleHelp.Chain(ctx.State, flow.Id, side)
                .OrderBy(i => i.PositionIndex).ToList();

            double PathDp(IEnumerable<AppInstance> insts)
            {
                double dp = 0;
                foreach (var inst in insts)
                {
                    var app = ctx.Project.Apparatus.FirstOrDefault(x => x.Id == inst.ApparatusId);
                    if (app is null) continue;
                    double vNom = inst.Side == Side.Hot ? app.NominalVhMs : app.NominalVcMs;
                    double dpNom = inst.Side == Side.Hot ? app.DpNomHMPa : app.DpNomCMPa;
                    if (dpNom <= 0 || vNom <= 0) continue;
                    double frac = inst.Side == Side.Hot ? Math.Clamp(inst.HotFraction, 0.0, 1.0)
                                                        : Math.Clamp(inst.ColdFraction, 0.0, 1.0);
                    dp += dpNom * Math.Pow(frac, 1.75);
                }
                return dp;
            }

            double total;
            if (split is null)
            {
                total = PathDp(chain);
            }
            else
            {
                var pre = chain.Where(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) == "P0")
                    .Where(i => i.PositionIndex <= AnchorPosOf(split, chain))
                    .ToList();
                var post = chain.Where(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) == "P0")
                    .Where(i => i.PositionIndex > MaxBranchPosOf(split, chain))
                    .ToList();
                double dpA = PathDp(BranchOf(split, chain, side, split.PathIdA));
                double dpB = PathDp(BranchOf(split, chain, side, split.PathIdB));
                total = PathDp(pre) + Math.Max(dpA, dpB) + PathDp(post);
            }

            if (total > flow.DpBudgetMpa * (1 + eps))
                return RuleResult.Cut(Id,
                    $"{flow.Id}: dP пути {total:0.000} МПа > бюджет {flow.DpBudgetMpa:0.000} + {eps:P0}",
                    new Dictionary<string, double> { ["dp"] = total, ["budget"] = flow.DpBudgetMpa });
        }
        return RuleResult.Pass(Id);
    }

    private static int AnchorPosOf(SplitSpec split, List<AppInstance> chain)
    {
        if (split.AnchorApparatusId.Length == 0) return -1;
        var anchor = chain.FirstOrDefault(i => i.ApparatusId == split.AnchorApparatusId);
        return anchor?.PositionIndex ?? -1;
    }

    private static int MaxBranchPosOf(SplitSpec split, List<AppInstance> chain)
    {
        var positions = chain
            .Where(i => (split.IsHot ? i.HotPathId : i.ColdPathId) != "P0")
            .Select(i => i.PositionIndex).ToList();
        return positions.Count > 0 ? positions.Max() : -1;
    }

    private static List<AppInstance> BranchOf(SplitSpec split, List<AppInstance> chain, Side side, string pathId) =>
        chain.Where(i => (side == Side.Hot ? i.HotPathId : i.ColdPathId) == pathId).ToList();
}

/// <summary>
/// П7. Балансная замкнутость (финальное): невязка по аппаратам |Σ qHot − Σ qCold|
/// ≤ eps_balance = max(0,01 МВт; 0,1 % Q_glob). В последовательной схеме баланс держит
/// симулятор; правило фиксирует невязку честно (для S8 со смесителями).
/// </summary>
public sealed class P7Balance : ICutRule
{
    public string Id => "П7";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        if (ctx.Sim is null) return RuleResult.Pass(Id);
        double eps = Math.Max(ctx.Project.Parameters.EpsBalanceAbsMw,
            ctx.Project.Parameters.EpsBalanceRel * Math.Max(ctx.QglobMw, 1e-9));
        double sumHot = ctx.Sim.Apparatus.Sum(a => a.QMw);
        double residual = Math.Abs(sumHot - ctx.Sim.QTotalMw); // полная сумма уже сбалансирована симулятором
        // Б1 (аудит 20.11): честная невязка по фактическим нагрузкам сторон (Simulator.AppCalc).
        // В однородной модели узла (q = mh·Δh = mc·Δh по построению) невязка ≈ 0 — мёртвости больше нет,
        // а при будущих расширениях (фазовые переходы, Network-смесители) правило активируется само.
        double worst = 0;
        foreach (var a in ctx.Sim.Apparatus)
        {
            double qh = a.QHotMw, qc = a.QColdMw;
            if (qh == 0 && qc == 0) continue; // топология/байпас — не расчётный узел
            worst = Math.Max(worst, Math.Abs(qh - qc));
        }
        if (worst > eps)
            return RuleResult.Cut(Id, $"невязка баланса {worst:0.000} МВт > eps {eps:0.000}",
                new Dictionary<string, double> { ["residual"] = worst, ["eps"] = eps });
        return RuleResult.Pass(Id);
    }
}

/// <summary>П8. Сходимость симулятора (финальное): не сошлось — CUT (классификация в Simulator).</summary>
public sealed class P8Convergence : ICutRule
{
    public string Id => "П8";
    public string Version => "v1.2";
    public RuleResult Evaluate(RuleContext ctx)
    {
        if (ctx.Sim is null) return RuleResult.Pass(Id);
        if (!ctx.Sim.AllConverged)
            return RuleResult.Cut(Id, $"симулятор: {ctx.Sim.FirstFailure ?? FailureClass.Iterations}",
                new Dictionary<string, double> { ["globalIter"] = ctx.Sim.GlobalIterations });
        return RuleResult.Pass(Id);
    }
}
```

```csharp
/// <summary>Строитель дельты состояния: читает базовое состояние, накапливает изменения.</summary>
public sealed class StateBuilder
{
    private List<AppInstance> _committed;
    private List<ResidualSegment> _hot;
    private List<ResidualSegment> _cold;
    private List<string> _free;
    private List<SoftViolation> _soft;
    private List<SplitSpec> _splits;

    public double QFixMw { get; set; }
    public double UaFixMwK { get; set; }
    public double DpFixMpa { get; set; }
    public int Depth { get; set; }
    /// <summary>М1: счётчик монтажных изменений на пути ходов (переподключения, новые аппараты, деления).</summary>
    public int MountChanges { get; set; }
    public string? ParentKey { get; set; }
    public string? LastMoveId { get; set; }
    public string CanonicalKey { get; set; } = "";
    public bool Complete { get; set; }

    public StateBuilder(State baseState)
    {
        _committed = new List<AppInstance>(baseState.Committed);
        _hot = new List<ResidualSegment>(baseState.ResidualHot);
        _cold = new List<ResidualSegment>(baseState.ResidualCold);
        _free = new List<string>(baseState.FreeApparatusIds);
        _soft = new List<SoftViolation>(baseState.Soft);
        _splits = new List<SplitSpec>(baseState.Splits);
        QFixMw = baseState.QFixMw;
        UaFixMwK = baseState.UaFixMwK;
        DpFixMpa = baseState.DpFixMpa;
        Depth = baseState.Depth;
        // Ревизия: MountChanges копируется — иначе любое With(...) сбрасывало счётчик монтажных
        // изменений в 0 и М1 терял контроль суммарного числа переподключений на пути ходов
        MountChanges = baseState.MountChanges;
        ParentKey = baseState.ParentKey;
        LastMoveId = baseState.LastMoveId;
        CanonicalKey = baseState.CanonicalKey;
        Complete = baseState.Complete;
    }

    public IReadOnlyList<AppInstance> Committed
    {
        get => _committed;
        set => _committed = new List<AppInstance>(value);
    }
    public IReadOnlyList<ResidualSegment> ResidualHot
    {
        get => _hot;
        set => _hot = new List<ResidualSegment>(value);
    }
    public IReadOnlyList<ResidualSegment> ResidualCold
    {
        get => _cold;
        set => _cold = new List<ResidualSegment>(value);
    }
    public IReadOnlyList<string> FreeApparatusIds

    }
    public IReadOnlyList<SoftViolation> Soft

    }

    public IReadOnlyList<SplitSpec> Splits

    }

    public void Commit(AppInstance app) => _committed.Add(app);
    public void RemoveFree(string apparatusId) => _free.RemoveAll(id => id == apparatusId);
    public void AddSoft(SoftViolation v) => _soft.Add(v);
    public void ReplaceResidual(ResidualSegment old, IEnumerable<ResidualSegment> parts)
    {
        var target = old.IsHot ? _hot : _cold;
        // Ревизия: ResidualSegment — record; поиск по значению (если передан эквивалентный,
        // но другой экземпляр — например, из baseState — удаление обязано сработать)
        target.RemoveAll(s => Equals(s, old));
        target.AddRange(parts);
    }
    public void AddResidual(ResidualSegment seg) => (seg.IsHot ? _hot : _cold).Add(seg);

    public State Build() => new()
    {
        // Ревизия: отдаваемые списки — КОПИИ внутренних; иначе изменение builder'а после Build()
        // мутировало бы «иммутабельный» State
        Committed = new List<AppInstance>(_committed),
        ResidualHot = new List<ResidualSegment>(_hot),
        ResidualCold = new List<ResidualSegment>(_cold),
        FreeApparatusIds = new List<string>(_free),
        QFixMw = QFixMw,
        UaFixMwK = UaFixMwK,
        DpFixMpa = DpFixMpa,
```

```csharp
using Pinchess.Engine.Domain;

namespace Pinchess.Engine.Search;

public enum VisitResult { Inserted, Replaced, Dominated }

/// <summary>
/// С2 (ТЗ): карта посещённых состояний по каноническому ключу с Q-первичным доминированием.
/// Coarse — сравнение с относительным допуском DomEpsQRel·|Q|; fine — без допуска.
/// При равенстве Q (в допуске) — soft вторичен (правка Р10): лучший soft доминирует/заменяет.
/// Д6: замена обновляет запись (Entries) — потомки ссылаются на актуальные метрики узла.
/// Детерминизм: ключи сравниваются по значению, перечисления не зависят от порядка вставки.
/// </summary>
public sealed class Visited
{
    public sealed record Entry(string Key, double QFixMw, double UaFixMwK, SoftVector Soft, bool Coarse, bool Retained);

    private readonly Dictionary<string, Entry> _entries = new(StringComparer.Ordinal);
    private readonly CutParameters _p;

    public Visited(CutParameters parameters) { _p = parameters; }

    public IReadOnlyDictionary<string, Entry> Entries => _entries;
    public int Count => _entries.Count;

    public VisitResult Add(string key, double q, double ua, SoftVector soft, bool coarse)
    {
        if (!_entries.TryGetValue(key, out var e))
        {
            _entries[key] = new Entry(key, q, ua, soft, coarse, false);
            return VisitResult.Inserted;
        }
        double tol = coarse ? Math.Max(0.0, _p.DomEpsQRel) * Math.Abs(e.QFixMw) : 0.0;
        if (q > e.QFixMw + tol)
        {
            _entries[key] = e with { QFixMw = q, UaFixMwK = ua, Soft = soft, Coarse = coarse, Retained = e.Retained };
            return VisitResult.Replaced;
        }
        if (q < e.QFixMw - tol) return VisitResult.Dominated;
        if (soft.NotWorseThan(e.Soft) && e.Soft.NotWorseThan(soft) && soft.Count == e.Soft.Count)
            return VisitResult.Dominated; // эквивалентные по Q и soft — удерживаем существующий
        if (soft.NotWorseThan(e.Soft))
        {
            _entries[key] = e with { QFixMw = q, UaFixMwK = ua, Soft = soft, Coarse = coarse, Retained = e.Retained };
            return VisitResult.Replaced;
        }
        return VisitResult.Dominated;
    }

    public void MarkRetained(string key)
    {
        if (_entries.TryGetValue(key, out var e))
            _entries[key] = e with { Retained = true };
    }
}

namespace Pinchess.Engine.Physics;

/// <summary>
/// Корреляции теплопередачи по обеим сторонам (ТЗ v3 разд. 2.4, S4).
/// Зоны режима: Re ≤ 2300 — ламинарный (Зидер–Тейт); 2300 &lt; Re &lt; 10000 — переходная
/// (Хаузен со склейкой к Диттусу–Бёльтеру по ln Re); Re ≥ 10000 — Диттус–Бёльтер.
/// Поправка (μ/μс)^0,14 в MVP — 1 (сопротивления стенки не заданы в модели аппарата).
/// Все формулы — относительные: нормировка на номинал из таблицы факта.
/// </summary>
public static class KCorrelations
{
    public const double ReLaminar = 2300.0;
    public const double ReTurbulent = 10000.0;

    /// <summary>Диттус–Бёльтер: Nu = 0,023·Re^0,8·Pr^0,4 (нагреваемая среда).</summary>
    public static double NusseltDittusBoelter(double re, double pr) =>
        0.023 * Math.Pow(re, 0.8) * Math.Pow(pr, 0.4);

    /// <summary>Зидер–Тейт: Nu = 1,86·(Re·Pr·d/L)^(1/3); кламп к 3,66 (полностью развитый поток).</summary>
    public static double NusseltSiederTate(double re, double pr, double dOverL)
    {
        double nu = 1.86 * Math.Pow(re * pr * dOverL, 1.0 / 3.0);
        return Math.Max(nu, 3.66);
    }

    /// <summary>Хаузен: Nu = 0,116·(Re^(2/3) − 125)·Pr^(1/3)·(1 + (d/L)^(2/3)); кламп к 3,66.</summary>
    public static double NusseltHausen(double re, double pr, double dOverL)
    {
        double nu = 0.116 * (Math.Pow(re, 2.0 / 3.0) - 125.0) * Math.Pow(pr, 1.0 / 3.0) * (1.0 + Math.Pow(dOverL, 2.0 / 3.0));
        return Math.Max(nu, 3.66);
    }

    /// <summary>Маршрутизатор по режиму течения.</summary>
    public static double Nusselt(double re, double pr, double dOverL)
    {
        if (re <= ReLaminar) return NusseltSiederTate(re, pr, dOverL);
        if (re < ReTurbulent)
        {
            // склейка Хаузен → Диттус–Бёльтер по ln Re (устраняет скачок на Re = 10000)
            double w = (Math.Log(re) - Math.Log(ReLaminar)) / (Math.Log(ReTurbulent) - Math.Log(ReLaminar));
            double nuH = NusseltHausen(re, pr, dOverL);
            double nuDb = NusseltDittusBoelter(re, pr); // М4 (аудит 20.11): DB при текущем Re — клейка без ступени значения
            return (1 - w) * nuH + w * nuDb;
        }
        return NusseltDittusBoelter(re, pr);
    }

    /// <summary>Число Рейнольдса: Re = ρ·v·d/μ (SI; d — внутренний диаметр трубки, м).</summary>
    public static double Reynolds(double densityKgM3, double velocityMs, double tubeDiM, double viscosityPaS) =>
        viscosityPaS > 0 ? densityKgM3 * velocityMs * tubeDiM / viscosityPaS : double.PositiveInfinity;

    /// <summary>Число Прандтля: Pr = μ·cp/λ (cp в Дж/(кг·К): кДж·1000).</summary>
    public static double Prandtl(double viscosityPaS, double cpKjKgK, double conductivityWmK) =>
        conductivityWmK > 0 ? viscosityPaS * cpKjKgK * 1000.0 / conductivityWmK : double.PositiveInfinity;
}


















namespace Pinchess.Engine.Sim;

using Pinchess.Engine.Domain;

/// <summary>
/// Энтальпийная кривая среды: H(T) = ∫cp dT, кДж/кг, построенная по таблице T–свойство
/// (ТЗ v3 разд. 8.5 — интегральные кривые вместо cp-констант). Инверсия T(H) — бинарным
/// поиском; за пределами таблицы — линейная экстраполяция по крайнему участку.
/// </summary>
public sealed class EnthalpyCurve
{
    private readonly double[] _t;
    private readonly double[] _h;

    public EnthalpyCurve(EnvironmentSpec env)
    {
        if (env.Points.Count == 0) throw new ArgumentException("Таблица свойств пуста.");
        var sorted = env.Points.OrderBy(p => p.TC).ToList();
        int n = sorted.Count;
        _t = new double[n];
        _h = new double[n];
        _t[0] = sorted[0].TC;
        _h[0] = 0.0;
        for (int i = 1; i < n; i++)
        {
            double dT = sorted[i].TC - sorted[i - 1].TC;
            double cpMid = 0.5 * (sorted[i - 1].CpKjKgK + sorted[i].CpKjKgK);
            _t[i] = sorted[i].TC;
            _h[i] = _h[i - 1] + cpMid * dT;
        }
        TLowC = _t[0];
        THighC = _t[^1];
    }

    public double TLowC { get; }
    public double THighC { get; }

    /// <summary>Энтальпия, кДж/кг.</summary>
    public double H(double tC)
    {
        if (_t.Length == 1) return 0; // единственная точка — плоская кривая (H ≡ 0)
        if (tC <= _t[0])
            return _h[0] + Slope(0) * (tC - _t[0]);
        if (tC >= _t[^1])
            return _h[^1] + Slope(_t.Length - 2) * (tC - _t[^1]);

        int lo = 0, hi = _t.Length - 1;
        while (hi - lo > 1)
        {
            int mid = (lo + hi) / 2;
            if (_t[mid] <= tC) lo = mid; else hi = mid;
        }
        double frac = (_t[hi] - _t[lo]) == 0 ? 0 : (tC - _t[lo]) / (_t[hi] - _t[lo]);
        return _h[lo] + frac * (_h[hi] - _h[lo]);
    }

    /// <summary>Инверсия: температура по энтальпии, °C.</summary>
    public double T(double hKjKg)
    {
        if (_t.Length == 1) return _t[0];
        if (hKjKg <= _h[0])
            return _t[0] + (Slope(0) == 0 ? 0 : (hKjKg - _h[0]) / Slope(0));
        if (hKjKg >= _h[^1])
            return _t[^1] + (Slope(_t.Length - 2) == 0 ? 0 : (hKjKg - _h[^1]) / Slope(_t.Length - 2));

        int lo = 0, hi = _t.Length - 1;
        while (hi - lo > 1)
        {
            int mid = (lo + hi) / 2;
            if (_h[mid] <= hKjKg) lo = mid; else hi = mid;
        }
        double span = _h[hi] - _h[lo];
        double frac = span == 0 ? 0 : (hKjKg - _h[lo]) / span;
        return _t[lo] + frac * (_t[hi] - _t[lo]);
    }

    private double Slope(int segment)
    {
        double dT = _t[segment + 1] - _t[segment];
        return dT == 0 ? 0 : (_h[segment + 1] - _h[segment]) / dT;
    }
}

/// <summary>Общая термодинамика симулятора (S3+).</summary>
public static class Thermo
{
    /// <summary>
    /// Среднелогарифмический напор: LMTD = (d1 − d2)/ln(d1/d2).
    /// Предельный переход при d1 ≈ d2 → d1; при неположительных напорах — NaN.
    /// </summary>
    public static double Lmtd(double d1, double d2)
    {
        if (d1 <= 0 || d2 <= 0 || double.IsNaN(d1) || double.IsNaN(d2)) return double.NaN;
        if (Math.Abs(d1 - d2) < 1e-9) return d1;
        return (d1 - d2) / Math.Log(d1 / d2);
    }

    /// <summary>кДж/ч в МВт (1 МВт = 3,6e6 кДж/ч).</summary>
    public static double KjPerHourToMw(double kjPerHour) => kjPerHour / 3.6e6;
```

```csharp
    private readonly ITestOutputHelper _out;
    public At5EconomyTests(ITestOutputHelper o) => _out = o;

    [Fact]
    public void BaseState_Simulates_And_T9_Calibration_Sets_K0()
    {
        var p = At5Fixtures.Scene();
        var baseState = At5Fixtures.BaseState(p);
        Assert.True(baseState.FreeApparatusIds.Count == 6, "База: 6 свободных аппаратов");

        // Верификация Т-9 (Э1): факт Q=2,28 МВт при ΔTlm=75 К, A=120 м² → K0_факт = 253,3;
        // расчётная Q при эталоне K0=250 — 2,25 МВт; погрешность 1,3 % ≤ 2 % (контрольная запись S2)
        double qFact = 2.28, aM2 = 120.0, dTlm = 75.0;
        double k0Fact = qFact * 1e6 / (aM2 * dTlm);
        double qCalc = 250.0 * aM2 * dTlm / 1e6;
        double errPct = Math.Abs(qFact - qCalc) / qFact * 100;
        Assert.True(errPct <= 2.0, $"Т-9: |{qFact:0.00}−{qCalc:0.00}|/{qFact:0.00} = {errPct:0.0} % > 2 %");
        Assert.InRange(k0Fact, 245.0, 255.0);

        var pipe = new Pinchess.Engine.Rules.CutPipeline(p);
        var outcome = pipe.Evaluate(baseState, coarse: false, qBestMw: 0);
        foreach (var r in outcome.Results)
            _out.WriteLine($"  {r.RuleId}: {r.Verdict} {r.Reason}");
        Assert.False(outcome.Cut, $"Базовое состояние должно проходить конвейер: {outcome.FirstCut?.RuleId} {outcome.FirstCut?.Reason}");
        Assert.True(outcome.Sim.QTotalMw > 0.1, $"Базовая рекуперация: {outcome.Sim.QTotalMw:0.000} МВт");
        _out.WriteLine($"Q_base = {outcome.Sim.QTotalMw:0.000} МВт");
    }

    [Fact]
    public void Search_Finds_Economy_Over_BaseState()
    {
        var p = At5Fixtures.Scene();
        var baseState = At5Fixtures.BaseState(p);

        // Q_base — рекуперация исходного состояния (fine)
        var pipe = new Pinchess.Engine.Rules.CutPipeline(p);
        var baseOutcome = pipe.Evaluate(baseState, coarse: false, qBestMw: 0);
        foreach (var r in baseOutcome.Results)
            _out.WriteLine($"  {r.RuleId}: {r.Verdict} {r.Reason}");
        Assert.False(baseOutcome.Cut);
        double qBase = baseOutcome.Sim.QTotalMw;

        // поиск оптимальной переобвязки (R1/R2/R4/R5 — без делений, они в S8)
        var run = new SearchRun(SearchModeKind.StrictBnB, BeamW: 200, MaxStates: 30_000,
            WarmStart: baseState, Seed: null, CancellationToken.None);
        var engine = new SearchEngine(p, run);
        var outcome = engine.Run();
        double qBest = outcome.QBestMw;

        Assert.True(qBest > 0, "Поиск должен найти положительную рекуперацию");
        double economy = qBest - qBase;
        Assert.True(economy > -0.001, $"Оптимум не может быть хуже базы: {qBest:0.000} < {qBase:0.000}");
        _out.WriteLine($"Q_base = {qBase:0.000} МВт; Q_best = {qBest:0.000} МВт; экономия = {economy:0.000} МВт");
        _out.WriteLine(outcome.Certificate.ToString());
        Assert.True(outcome.Best is not null);

        // Т-9-подобный аппарат в оптимуме: краткая расшифровка схемы
        if (outcome.Best is { } best)
        {
            foreach (var inst in best.Committed.OrderBy(i => i.FlowId).ThenBy(i => i.PositionIndex))
                _out.WriteLine($"  {inst.FlowId}: {inst.ApparatusId} [{inst.Side}] pos={inst.PositionIndex}" +
                               (inst.Bypass ? " BYPASS" : ""));
        }
    }
```

## 6. Хронические проблемы — схемы вопроса

### 6.1 Строгость глобальной UB при перекрестиях (SleepTolC-кумулятив)
СИМПТОМ: v20-грань ∫min(H,C) при τ=6 давала 17,45–18,86 МВт против beam-оптимума 27,739 —
«сеть обменивается не уровнево». Профиль факт-сцены легализует перекрестия SleepTolC=20.
ГИПОТЕЗА: перекрестия в допуске SleepTolC допускаются ПО ОТДЕЛЬНЫМ аппаратам; их кумулятивный
эффект вдоль цепочки может превышать «односдвиговую» модель. В v23 грань считается при
ΔT_eff = TminC − SleepTolC = −14 (сдвиг отрицательный, перекрестия легализованы в грань).
ОЖИДАЕМОЕ: если грань честная — strict не теряет оптимум на факт-сцене (E2Tests зелёные).
ТОЧЕЧНЫЕ ВОПРОСЫ:
1. Достаточно ли ΔT_eff как глобального допуска, или нужен пер-аппаратный анализ (цепочка
   перекрестий даёт эффективный сдвиг < Tmin − SleepTolC)?
2. Правильно ли НЕ клампить ΔT_eff снизу нулём (сессия А клампит: min(0, Tmin−SleepTolC))?
   На факт-сцене грань hot-ограничена — сдвиг не влияет; на сценах, где bind — влияет.
3. Как проверить строгость PTA-грани теоретически (формулировка теоремы) и как построить
   сетевой пример, где PTA-грань нарушается (если это вообще возможно)?

### 6.2 Э2: хвостовая UB и перестановки R1
СИМПТОМ: UbTailMw считает оболочку по остаточным хвостам; перестановка R1 меняет температуры
на входах аппаратов — хвостовая UB родителя НЕ покрывает Q ребёнка (историческая потеря
оптимума 23,084 vs 27,739). Сейчас: StrictSafeUb=true → max(tail, apparatus, global).
ОЖИДАЕМОЕ: Г1-Safe не режет перестановочных детей.
ТОЧЕЧНЫЕ ВОПРОСЫ:
1. Существует ли точная перестановочно-безопасная хвостовая грань (не через max)?
2. Приемлема ли текущая цена: StrictSafeUb отключает П1 на coarse для WarmStart-корня (Э1)?

### 6.3 Сходимость fine-слоя
СИМПТОМ: на факт-сцене NIterMax=1000 (поднят с 100), RelaxAlpha=0,5; Вегстейн с клампом q∈[0;0,9]
и ограничителем шага (новый x не дальше 2× классического шага).
ТОЧЕЧНЫЕ ВОПРОСЫ:
1. Корректно ли совмещать Вегстейн и релаксацию (сейчас взаимоисключающие ветки: UseWegstein
   приоритетнее)?
2. Критерий сходимости «по Q И по ΔT» (epsT=0,2 К fine) — достаточно? Обратный случай —
   колебания ΔT при сошедшемся Q — пойманы; а колебания Q при сошедшемся ΔT?
3. Ньютон вместо Вегстейна — v24: ожидаемая выгода на факт-сцене? Стоит ли (сходимость уже
   приемлема)?

### 6.4 Дубль реализаций PTA (сессия А vs сессия Б)
СИМПТОМ: две параллельные ветки v23. Сессия А (атомы 1–2): UbPtaMw добавлен ЧЕТВЁРТЫМ членом
max в Г1-Safe, UbGlobal не тронут (множители остались), ΔT_eff = min(0, Tmin − SleepTolC) —
кламп от 0. Сессия Б (эта выдача): UbGlobal ЗАМЕНЁН на PTA, ΔT_eff без клампа, множители
глобальной грани сняты, + IObjective. Обе зелёные на своих тестах; базы не совместимы.
ТОЧЕЧНЫЕ ВОПРОСЫ:
1. Какая база становится актуальной? (Мнение агента: Б — цельнее: одна честная грань вместо
   «интеграл с множителями + PTA-диагностика»; но у А меньше дифф.)
2. Кламп ΔT_eff: на факт-сцене не влияет (hot-limited); на сценах, где грань связана сдвигом —
   кламп может СРЕЗАТЬ легализованные перекрестия → потеря оптимума. Это осознанный риск?

### 6.5 Fuel-объектив: домен и монотонность
СИМПТОМ: IObjective.FurnaceFuelObjective реализован, но не подключён к движку.
Узкое место: fuel = Q_печной_остаток монотонно убывает по Q_сети ТОЛЬКО при одном печном
потоке. При нескольких печных потоках Q-макс ≠ fuel-мин (нагрев «не в печь»).
ТОЧЕЧНЫЕ ВОПРОСЫ:
1. Подключение требует перевода всех правил (Г1/Г2/Г4) в домен критерия — масштаб правки?
2. Приемлем ли промежуточный вариант: считать движком Q, а fuel-оценку выдавать только в
   отчётности (Top10/сертификат) до полной интеграции?

### 6.6 Регресс At5Economy от insert-with-shift — корень не установлен
СИМПТОМ: ShiftSide в R2-Apply (сдвиг всех потоков стороны) давал Best=4,632 < base 7,736;

цели явно. Гипотеза: позиции якорей ветвлений (AnchorPos) ломаются при сдвигах (дыры позиций).
ТОЧЕЧНЫЕ ВОПРОСЫ:
1. Пересчитывать ли якорные позиции при сдвиге (сейчас — нет)?
2. Нужен ли вообще сдвиг: RefineBest+PairSwap закрывает перестановочный потенциал середины?

### 6.7 Детерминизм: закрыто частично

### 6.8 K0-калибровка и корреляции

## 7. Математические вопросы — позиция агента

1. PTA-грань как глобальная UB: Q_rec = ColdTotal − Q_H_min(ΔT_eff) — классический пинч-предел;
   для сетей с делениями энтальпийные тоталы не меняются → грань покрывает все конфигурации.
   Контрпример ревьюера подтверждает формулу (PTA=20, ∫min=0). Мнение: замена UbGlobal на PTA
   корректна; множители в tail-UB оставлены сознательно до Э1-калибровки.
2. Экономика: fuel = Q_печной_остаток; Gas = fuel/η·3,6·1000/33,5. NPV/CAPEX — линейные модели;
   IRR NaN при отрицательном CAPEX-потоке — известный артефакт.
3. RefineBest: подъём только по complete-состояниям; R5 (изъятие) порождает не-complete и в
   подъёме не участвует — ограничение метода, не баг; R2/R3 исключены (восстановление подрезает
   смысл подъёма).
4. Beam: UB coarse завышен к fine — сертификат честно печатает «гарантия ограничена W»;
   rescue по UB > Q_best — Г3.
