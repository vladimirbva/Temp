=== 2. ТЕКУЩАЯ UB-АРХИТЕКТУРА ===
(1) UbGlobalMw = PtaMw: PTA-каскад Q_rec = ColdTotal − QHmin; кривые по ПОЛНЫМ диапазонам
    потоков; горячие сдвигаются на −ΔT_eff ЦЕЛИКОМ (не полусдвиг), холодные без сдвига.
    На факт-сцене: ΔT_eff = Tmin − max(SleepTolC, DtolOverlapC) − TauMarginC = 6 − 20 − 0 = −14
    (отрицательный!); PtaMw = 29,339 МВт.
(2) UbTailMw — интеграл по парам остаточных хвостов (после ResidualTails) С множителями
    BranchesMaxOf (M/N — безопасное завышение на деления).
(3) UbApparatusMw — грубая max-оболочка по аппаратам.
(4) StrictSafeUb = max(UbTail, UbApp, UbGlobal). Beam: UB = max(UB фронтира, Q_best).

=== 3. УРОК М1 (эталонная защита, НЕ трогать без решения СС) ===
В v16 снятие множителей BranchesMaxOf дало ЛОЖНЫЕ ОТСЕЧЕНИЯ: UbGlobal=24,752 < beam 27,739
(тест E2Tests.UbGlobal_CoversFactSceneBeams КРАСНЫЙ). Причина: каскадный предел int(min(H,C))
по целым потокам НЕ покрывает делённые конфигурации: min(h,c) не супераддитивно по разбиению
— сумма интегралов по ветвям может БЫТЬ БОЛЬШЕ интеграла по целому (контрпример: деление
холодного потока против источников разных температур; в целом потоке горячий источник не
может отдать тепло на низкотемпературном участке из-за Tmin). Множители ВОЗВРАЩЕНЫ.
Математическое решение коллеги (принято в план): вогнутая мажоранта Q(xi)=min(h(xi),c(xi)) —
UB родителя = Q_fix + int вогнутой оболочки по остаткам; для <=2 ветвей int min(2h, c).

=== 4. ВОПРОСЫ СС-1 (ответ — разбор с числовыми проверками) ===
В.1 (ГЛАВНЫЙ, безопасность min). План v26: заменить max(...) на min(UbApparatusMw, PtaMw) в
StrictSafeUb. Вопрос: доказуема ли PtaMw как верхняя грань для ЛЮБОЙ легальной конфигурации
при действующих правилах coarse (П1-перекрестия допускаются до −SleepTolC; «спящий» аппарат
Q<=1e-9 при |d|<=SleepTolC)? Урок М1 говорит: НЕ доказуема для делённых (PTA по целым потокам
занижает). Требуется: (а) точный контрпример PTA-занижения на делённой конфигурации
(числовой, 2–3 потока); (б) безопасная замена min — например
UB_strict = max(min(UbApp, Pta + Деления-надбавка), Q_best), где надбавка — вогнутая
мажоранта по делениям; (в) минимальный тест-набор, доказывающий безопасность.
В.2 (τ-полнота). ΔT_eff = Tmin − max(SleepTolC, DtolOverlapC) − TauMarginC. Достаточно ли
этой формулы, чтобы PTA-каскад накрывал ВСЕ легальные перекрестия coarse-правил (включая
случай «перекрестие ровно на границе П1»)? Требуется: (а) доказательство или контрпример
сцены «на пределе П1»: hot_in − cold_out = −SleepTolC + eps, горячий при этом почти спящий
(Q~0) — даёт ли каскад при сдвинутой шкале Q >= фактического? (б) если нет — правильная
формула ΔT_eff (включая знак: факт-сцена даёт ΔT_eff=−14 — сдвиг в минус расширяет каскад;
проверить монотонность PtaMw по ΔT_eff и границу легальности).
В.3 (сегментированный LMTD). План: LMTD по сегментам кривой cp (внутренние пинчи при
кривом cp) вместо одного LMTD на аппарат. Вопрос: меняет ли это отсечения на эталонах
(k=0 константные cp — сегменты должны дать бит-в-бит тот же результат; растущий cp —
сегментированный LMTD МЕНЬШЕ одного общего => Q_cap меньше => строже; безопасно ли?).
Дать схему проверки и один числовой контроль.
В.4 (Ньютон fine). Жёсткие сцены (большие UA, 21–42 итерации релаксации alpha=0,5/1,0;
Вегстейн сходится при шаге <=2x). Оценить целесообразность Ньютона в fine: выигрыш в итерациях
vs риск недосходимости/разрыва на склейках корреляций. Требование: детерминизм байт-в-бит,
эталоны coarse не трогаются.
