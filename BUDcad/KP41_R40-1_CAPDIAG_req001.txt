=== ОПИСАНИЕ ПРОЕКТА (С НАЧАЛА) ===
BUDcad 2.3 — десктопный гидравлический/PVT симулятор технологических схем (WinForms, .NET 8, C#).
Пользователь рисует схему: сосуды-ёмкости, терминалы (границы сети), трубы/связи, насосы, арматура.
Каждый шаг времени («тик», dt = 1 с) состоит из двух фаз:
1) ГИДРАВЛИЧЕСКАЯ СЕТЬ: HydraulicEngine.BuildNetwork строит NetworkSpec (узлы — штуцеры ёмкостей и
   границы терминалов; рёбра — связи с трубным законом q = sign(dpNet)·sqrt(|dpNet|/R), насосы —
   квадратичная парабола с кавитационной рампой/NPSH, обратные клапаны, ребро-водослив R38);
   далее HydraulicEngine.Solve решает сеть ПО ФРАГМЕНТАМ связности: для каждого фрагмента узлов
   вызывается GgaSolver.Solve (GGA — градиентный гидравлический алгоритм: узловые балансы расходов
   + рёберные законы, итерации, невязка scaledResidual). Результат — HydraulicResult: Nodes/Edges
   (P бар, Q м3/с), Warnings, Errors, Converged, ScaledResidual, MaxImbalanceRel и т.д.
2) ЯЧЕЙКИ-ЁМКОСТИ (CapacityCells, фазная динамика): моли по фазам (газ/УВ-жидкость/вода/пар подушки),
   уровень, PVT-пересчёт давления.
СОГЛАСОВАНИЕ сеть↔ёмкость (ключевая механика R35-б): каждый подключённый штуцер ёмкости — ВНУТРЕННИЙ
узел сети с ЁМКОСТНЫМ ЧЛЕНОМ C_i (податливость: C_i = vGas/pGas + vLiq·β_жидк, делённая по штюцерам;
в GgaSolver — диагональный член capG = C_i/dt в матрице и сток capG·(P−P0) в балансе; P0 — засев
initP = подушка + гидростатический столб через HydraulicEngine.HydrostaticP).
АУДИТ согласования (Э12-усиление, R38): для подключённых штюцеров P сети узла обязана совпадать с
гидростатикой ячейки в допуске 0.05 бара (тест R38OverflowTests.R38_E12_DynamicPadNetworkSync).

                        $"тик {t} штюцер {nzId}: P сети {nN.Pressure:0.####} бар ≠ гидростатика {pH:0.####} бар (>0.05) — факт R37 (сеть тянет узел ниже ячейки)\n{sbDiag}");
                    double col = HydraulicEngine.HydrostaticColumn(sep, zN);
                    double tol = Math.Max(0.05, 0.05 * Math.Max(0.05, Math.Abs(sep.GasPressure)));
                    Assert.True(Math.Abs(sep.GasPressure - (nN.Pressure - col)) <= tol,
                        $"тик {t} штюцер {nzId}: GasPressure {sep.GasPressure:0.####} ≠ P сети − столб {nN.Pressure - col:0.####}\n{sbDiag}");
                }
                if (t == 4)
                {
                    foreach (var nn in r.Nodes) sbDiag.AppendLine($"node {nn.Key} P={nn.Pressure:0.####} iso={nn.Isolated}");
                    sbDiag.AppendLine($"lvl={sep.LiquidLevel:0.####} GasP={sep.GasPressure:0.####}");
                }
            }
        }
    }
