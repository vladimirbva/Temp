# ТЕЧЕТ 01 — ПЛАН РАЗВИТИЯ (переработанный и дополненный)

Подручный калькулятор технолога. Версия плана: 29.11.2026.
Автор идеи — владелец. Переработка, приоритизация и дополнения — рецензент.

---

## ПРИНЦИПЫ (уточнённые)

1. Никакого 3D, никаких тяжёлых серверных расчётов, никаких больших моделей.
2. Каждый калькулятор = один экран + формула + источник + эталон самопроверки.
3. Не симулятор и не замена HYSYS/Petro-SIM — только попутные прикидки дня.
4. **НОВОЕ:** Все калькуляторы по максимуму тянут данные из существующей базы 287 веществ (Tc, Pc, ω, M, Антуан, теплоёмкости). Пользователь не вводит константы руками — выбирает вещество из пикера.
5. **НОВОЕ:** Мобильный сценарий первичен. Полевой инженер считает на телефоне у колонны, не за столом. Крупные поля, работа одной рукой, читаемость на солнце.
6. **НОВОЕ:** Каждый расчёт сохраняет историю локально (последние 20 значений) — вернуться, поправить, пересчитать без повторного ввода.

## ЧАСТЬ 1. НОВЫЕ КАЛЬКУЛЯТОРЫ

### P0 — КВИК-БЛОК «одна строка — один ответ»

Карманные прикидки, которые нужны по 10 раз на дню. Каждое — 2–4 поля, результат мгновенно.

**1. Конвертер единиц** *(уточнено)*
Давление: МПа / кгс·см² / бар / psi / мм рт.ст. / м в.ст. / атм.
Температура: °C / K / °F.
Расход: т/ч / м³/ч / л/мин / л/с / ММНм³/сут.
Плотность: кг/м³ / кг/л / г/см³ / °API / удельная (ρ/ρводы).
Энтальпия: кДж/кг / ккал/кг / БТЕ/фунт.
Вязкость: мПа·с / сСт / °ВУ / сС (секунды Сейболта) / Па·с.
Расход газа: Нм³/ч / м³/ч при раб. усл. / млн м³/сут.
Мощность: кВт / МВт / Гкал/ч / л.с. / БТЕ/ч.
Длина/диаметр: мм / дюймы / Ду (условный проход).
Вход: значение + единица → все остальные единицы сразу.
Эталон: 1 кгс/см² = 98.0665 кПа = 0.980665 бар = 14.2233 psi.

**2. Давление насыщенных паров** *(уточнено)*
Вход: выбор вещества из базы (или ручной ввод констант Антуана) + температура.
Выход: Рнас в кПа / бар / мм рт.ст. / кгс·см².
Дополнительно: обратная задача — температура кипения при заданном давлении.
Графика: номограмма Кокса (логарифмическая) + линейный график Рнас(Т).
Для нефти/фракций: ДНП по ГОСТ Р ЕН 13016-1 (через корреляцию от Т начала кипения и плотности).
Источник: константы Антуана из базы 287 веществ. Если вещества нет в базе — ручной ввод трёх констант.
Эталон: вода 100 °C → 101.325 кПа; бензол 80.1 °C → 101.3 кПа.

**3. Плотность по температуре** *(уточнено)*
Вход: плотность при 20 °С (или 15 °С) + рабочая температура.
Выход: плотность при рабочей Т в кг/м³, г/см³, °API.
Два метода:
- Линейный (ГОСТ 3900): ρ(t) = ρ(20) − γ·(t−20), где γ — коэффициент объёмного расширения.
- Табличный (ГОСТ 2517 / Приложение 2 к ГОСТ 3900): поправка по таблице для конкретной плотности.
Дополнительно: перевод массы в объём и обратно при рабочей Т.
Эталон: вода 20 °C → ρ = 998.2 кг/м³; при 80 °C → ρ ≈ 971.8 кг/м³.

**4. Вязкостный пересчёт** *(уточнено)*
Вход: динамическая вязкость + плотность → кинематическая и наоборот.
Зависимость от Т: формула Валтера (μ = A·10^(B/(T−147)), для нефтепродуктов) или Рей–Бонд.
Индекс вязкости (ИВ) по ГОСТ 2517 / метод упрощённый: ИВ из вязкостей при 40 и 100 °С.
Графика: график μ(Т) в логарифмических координатах — прямая Валтера.
Эталон: вода 20 °C → 1.002 мПа·с; ИВ = 100 для базового масла.

**5. Тепловые свойства фракций** *(уточнено и расширено)*
Теплоёмкость: Ср = (1.687 + 0.0033·t) / √d¹⁵₄ (ккал/кг·°С), где d¹⁵₄ — относительная плотность.
Дополнительно: теплопроводность нефтепродуктов (корреляция Крейга), теплота сгорания (по элементам или по плотности), энтальпия нагрева потока: Q = G·Cp·ΔT.
Выход: Ср при заданной Т, теплота сгорания (низшая), тепловая мощность потока.
Эталон: для керосина Ср ≈ 0.5 ккал/кг·°С при 20 °С.

**6. НОВОЕ: Газовый объём — пересчёт между условиями**
Самый частый полевой расчёт. Вход: расход/объём при одних условиях → при других.
Формула: V₂ = V₁ · (P₁/P₂) · (T₂/T₁) · (Z₂/Z₁).
Z-фактор: из базы (если чистый газ) или по правилу соответственных состояний (Стоянович / Кей).
Вход: объём/расход, P₁ T₁ Z₁ → P₂ T₂ Z₂. Выход: пересчитанный объём.
Эталон: 1000 м³ при 1 атм 20 °С → при 10 атм 20 °С ≈ 100 м³ (идеальный газ).

**7. НОВОЕ: Скорость звука в газе**
Вход: газ (из базы: M, k = Cp/Cv) + температура.
Выход: скорость звука а = √(k·R·T/M).
Применение: проверка критического течения через клапаны и сужения.
Эталон: воздух 20 °C → 343 м/с; метан 20 °C → 446 м/с.

**8. НОВОЕ: Водяной пар — свойства на линии насыщения**
Вход: давление ИЛИ температура.
Выход: Т кипения, давление, ρ пара, ρ воды, энтальпия испарения, энтропия.
Источник: таблицы водяного пара (Вукалович / Ривкин). Хранятся как массив в коде (не запрос к серверу).
Применение: оценка конденсации, паровой инжекции, эжекторов.
Эталон: 1 атм → 100 °C, r = 2257 кДж/кг; 10 атм → 179.9 °C, r = 2015 кДж/кг.

**9. НОВОЕ: Аффинитетные законы насоса**
Вход: паспортные (n₁, Q₁, H₁) + новая скорость/диаметр.
Выход: Q₂ = Q₁·(n₂/n₁), H₂ = H₁·(n₂/n₁)², N₂ = N₁·(n₂/n₁)³.
Применение: «поставили частотник на 45 Гц — сколько будет напор/подача».
Эталон: снижение оборотов на 10% → подача −10%, напор −19%, мощность −27%.

**10. НОВОЕ: СМТД (средняя логарифмическая разность температур)**
Вход: Т вх.гор / Т вых.гор / Т вх.хол / Т вых.хол + схема (противоток / прямоток).
Выход: ΔТср логарифмическая. Для многоходовых — поправочный коэффициент F (упрощённо, по номограмме для 1-2).
Применение: оценка площади теплообмена, подбор аппарата.
Эталон: 150→80 / 30→100 противоток → ΔТср ≈ 65.4 °С.

**11. НОВОЕ: Плотность газа (идеальный + реальный)**
Вход: газ из базы (M) или ручной ввод, давление, температура, опционально состав для смеси.
Выход: плотность, удельный вес по воздуху, сжимаемость (если задана).
Формула: ρ = P·M/(Z·R·T). Для смеси: Mсм = ΣyᵢMᵢ.
Эталон: метан при 1 атм 0 °C → 0.717 кг/м³; воздух → 1.293 кг/м³.

**12. НОВОЕ: Расход через отверстие (жидкость)**
Вход: диаметр отверстия, перепад давления, плотность, коэффициент расхода (по умолчанию 0.61 для острого края).
Выход: массовый и объёмный расход.
Формула: Q = μ·A·√(2·ΔP/ρ).
Применение: прикидка утечки через дренаж, пропускная способность дренажного клапана, отбор пробы.
Эталон: отверстие 10 мм при ΔP = 1 атм вода → ≈ 1.85 л/с.

### P1 — МОСТ К КОНСТРУКТОРУ НПЗ (фракции и псевдокомпоненты)

**13. Разбивка ИТК на узкие фракции** *(уточнено)*
Вход: таблица ИТК (температура — выход %).
Разбиение на N узких фракций (5–30).
Выход для каждой фракции: Тср (арифметическая / мольная / массовая — переключатель), плотность, М, UOP K, условная формула (по Ке).
Привязка к базе: для каждой псевдокомпоненты генерируются Tc, Pc, ω (через корреляции Кеслера-Ли или Твю).
Результат — готовый набор псевдокомпонент для загрузки в конструктор НПЗ (экспорт в JSON / прямая загрузка в сессию).
Эталон: для фракции 100–150 °С с ρ = 0.74 → М ≈ 110–120, UOP K ≈ 12.5.

**14. Пересчёт ИТК ↔ Д86** *(уточнено)*
Вход: 5–7 точек Д86 (по ГОСТ 2177 / Р ИСО 3405).
Выход: кривая ТБП и обратно.
Метод: корреляция Эдмистера / Риази-Доберта / табличный пересчёт по ГОСТ.
Графика: обе кривые на одном графике + таблица отклонений.
Применение: сверка лабораторных данных с расчётной моделью.
Эталон: для прямогонного бензина Д86 50% ≈ ТБП 50% ± 15 °С.

**15. Характеристический фактор Уотсона** *(уточнено)*
Вход: Тср.кип (любая из трёх: мольная, массовая, объёмная) + плотность.
Выход: UOP K = ∛(1.8·T_K) / d, где T_K — средняя температура кипения в Кельвинах.
Подсказки:
- K > 12.5 — парафиновая основа
- 11.5 < K < 12.5 — промежуточная
- 10.5 < K < 11.5 — нафтеновая
- K < 10.5 — ароматическая
Дополнительно: корреляция между мольной, массовой и объёмной Тср.кип.
Эталон: для н-гептана К ≈ 12.8; для толуола К ≈ 10.0.

**16. Молекулярная масса фракции** *(уточнено)*
Вход: Тср.кип + плотность.
Выход: М по Риази-Доберт / Кеслер-Ли / Твю (три метода, сравнение).
Таблица: для набора псевдокомпонент из п.13 — автоматический расчёт М для каждой.
Эталон: бензол Ткип 80.1 °С, ρ = 0.879 → М = 78.1; гексан Ткип 69 °С → М = 86.

**17. НОВОЕ: Оценка выхода продуктов из сырой нефти**
Вход: характеристики сырой нефти (плотность, сера, К по Уотсону, ИТК в 5 точках).
Выход: оценочный выход фракций (газ, бензин, керосин, дизель, мазут) в % масс.
Метод: корреляция по ИТК (интегрирование кривой по границам фракций) + поправка на плотность.
Применение: быстрая оценка потенциала нефти для конструктора НПЗ.
Связка: результат можно загрузить как выходы ЭЛОУ-АВТ в конструкторе.
Эталон: для средней западно-сибирской ρ = 0.86 → бензин НК-180 ≈ 18–22%, дизель 180–360 ≈ 30–35%.

**18. НОВОЕ: Водородный баланс установки**
Вход: расход сырья, содержание серы в сырье и продуктах, объём переработки.
Выход: оценка расхода водорода на гидроочистку (м³/т сырья).
Метод: эмпирические корреляции (3–5 м³ Н₂ на 1% удаляемой серы + стехиометрия десульфуризации).
Применение: прикидка потребности водородной установки, связь с конструктором НПЗ (потоки «Водородсод. газ»).
Эталон: гидроочистка дизеля с 1% серы до 0.2% → ≈ 15–25 Нм³/т.

### P1b — БЛЕНДИНГ / КОМПАУНДИРОВАНИЕ

**19. Линейные свойства смешения** *(уточнено)*
Свойства: плотность (объёмно-аддитивная), сера (массово-аддитивная), содержание парафинов, анилиновая точка, зольность.
Вход: до 5 потоков + доли (по объёму или по массе — переключатель).
Выход: свойства смеси.
Предупреждение: «Плотность аддитивна только по объёму; сера — только по массе. Переключите базу смешения».
Эталон: 50% потока ρ=800 + 50% ρ=900 → смесь ρ = 850 (по объёму).

**20. Октановый индекс смешения** *(уточнено)*
Вход: компоненты с ОЧИ/ОЧМ + объёмные доли.
Выход: ОЧИ и ОЧМ смеси.
Метод: не линейный, а через индексы смешения (блиндинговые числа). Таблица индексов для типовых потоков: прямогонный бензин, риформат, алкилат, изомеризат, МТБЭ, бутан, катбензин.
Предупреждение: «Индексы смешения нелинейны; для пар с сильной неаддитивностью (ароматика + парафины) погрешность до 2–3 пунктов».
Эталон: 50% алкилата (ОЧИ 96) + 50% изомеризата (ОЧИ 88) → смесь ОЧИ ≈ 92–93.

**21. Цетановый индекс и холодные свойства дизтоплива** *(уточнено)*
Цетановый индекс: по плотности и Т50% Д86 (формула Кетана / упрощённая корреляция).
Холодные свойства: Т помутнения и Т застывания смеси — через индекс смешения (не линейно!).
Т предельной фильтруемости (ТХФ): оценка от цетанового индекса и парафинов.
Вход: до 5 компонентов с Т помутнения, Т застывания, плотностью, цетаном.
Выход: цетановый индекс смеси, Т помутнения, Т застывания, ТХФ.
Эталон: для зимнего дизеля ТХФ ≤ −20 °С, цетановый индекс ≥ 45.

**22. РВП (давление насыщенных паров по Рейду) смеси** *(уточнено)*
Вход: компоненты с РВП + доли.
Выход: РВП смеси.
Метод: индекс смешения РВП (нелинейный). Для бутана в смеси с бензином — синергия (поправка).
Применение: летний/зимний бензин.
Эталон: 90% бензина РВП=60 кПа + 10% бутана РВП=350 кПа → смесь ≈ 90–100 кПа.

**23. Обратная задача смешения** *(уточнено)*
«Сколько добавить компонента Х, чтобы свойство У стало равно Z».
Вход: свойства двух потоков + целевое свойство + объём/масса одного потока.
Выход: требуемое количество второго потока (методом подбора / секущей).
Применение: «Сколько бутана добавить к 100 т бензина, чтобы РВП стало 500 мм рт.ст.».
Эталон: при РВП₁ = 60, РВП₂ = 350, цель 100 → доля бутана ≈ 13–15%.

**24. НОВОЕ: Температура вспышки смеси**
Вход: компоненты с Т вспышки + доли.
Выход: Т вспышки смеси.
Метод: индекс смешения по Лайману / формула Ли. Вспышка — НЕ аддитивное свойство, смесь может быть ниже минимального компонента.
Применение: товарное дизтопливо (Т вспышки ≥ 55 °С по ГОСТ).
Эталон: керосин Твсп 40 °С + дизель Твсп 65 °С, 50/50 → ≈ 48–52 °С.

**25. НОВОЕ: Дымление керосина (высота некоптящего пламени)**
Вход: компоненты с высотой некоптящего пламени + доли.
Выход: высота пламени смеси (линейно по объёму с поправкой).
Применение: авиационный керосин ТС-1, Т-1 — требование ГОСТ ≥ 25 мм.
Эталон: чистый керосин ТС-1 ≈ 28–35 мм; при добавлении ароматики снижается.

### P2 — ПОЛЕВОЙ РЕЖИМ СУЩЕСТВУЮЩИХ РАСЧЁТОВ

**26. NPSH / кавитация** *(уточнено)*
Вход: единицы прибора (манометры: кгс/см², м в.ст., мм рт.ст.; вакуумметры).
Выход: NPSHa (располагаемый кавитационный запас), сравнение с NPSHr (паспортный).
Подсказки:
- «Если NPSHa < NPSHr + 0.5 м — кавитация. Поднимите уровень, увеличьте диаметр всаса».
- «Проверьте температуру: при нагреве растёт давление паров».
Графика: столбик давления по тракту всаса (атмосфера + статика − потери − Рнас).
Связка: плотность и Рнас брать из пикера веществ.

**27. Сепаратор** *(уточнено)*
Вход: расходы газа и жидкости, плотности, давление, температура.
Выход: диаметр по Саудерсу-Брауну (скорость всплытия), высота цилиндра, время отстоя.
Полевой вопрос: «Займёт ли сепаратор?» — вход: реальные габариты (диаметр × высота) → выход: «Да, с запасом 15%» / «Нет, нужно 2 параллельных».
Графика: диаграмма фазового состояния на входе (доля пара / жидкости по мольному балансу).

**28. Гидраты и ингибирование** *(уточнено)*
Вход: состав газа (или выбор из типовых: метан, газ с сероводородом, газ с азотом), давление, температура.
Выход: температура гидратообразования при данном Р; если Т раб ниже — «Гидраты образуются».
Ингибирование: массовая доля метанола/МЭГ по Хаггеншмидту: ΔT = K·w/(M·(100−w)).
Пошаговый вывод: 1) находим Тгидр; 2) требуемый ΔT; 3) концентрация метанола; 4) расход метанола (т/сут) по расходу газа и влагосодержанию.
Связка: влагосодержание газа по корреляции (Бюкачарда / Мак-Кетта).
Эталон: для чистого метана при 7 МПа Тгидр ≈ 15 °С. При ΔT = 10 °С нужна ≈ 20% концентрация метанола.

**29. НОВОЕ: Гидравлика трубопровода — полевой режим**
Упрощённая версия существующего расчёта: только ввод диаметра, длины, расхода, плотности, вязкости → перепад давления.
Полевой вывод: «Перепад 0.8 бар на 100 м — норма» / «Перепад 3 бара — проверьте засорение».
Скорость потока: «Скорость 2.3 м/с — в норме для нефти» / «Скорость 6 м/с — выше нормы, эрозионный износ».
Связка: подтягивает плотность и вязкость из пикера веществ.

**30. НОВОЕ: Изоляция и теплопотери**
Вход: диаметр трубы, Т поверхности, толщина изоляции, λ изоляции, Т воздуха, скорость ветра.
Выход: теплопотери (Вт/м), температура поверхности изоляции.
Полевой вопрос: «Какая толщина изоляции нужна, чтобы поверхность была ≤ 60 °С (безопасность)?» — обратный расчёт.
Эталон: труба Ду100 при 150 °С с изоляцией 50 мм (λ = 0.04) → поверхность ≈ 45 °С, теплопотери ≈ 80 Вт/м.

**31. НОВОЕ: Сбросной клапан — предварительный подбор**
Вход: расход (газ/пар/жидкость), давление срабатывания, молекулярная масса, температура.
Выход: минимальная площадь сечения по АР 520 (упрощённо), типоразмер (буква: D, E, F, G, H, J, K, L, M).
Предупреждение: «Это предварительный подбор. Точный расчёт — по АР 520 с учётом противодавления и свойств среды».
Эталон: для воздуха 1000 кг/ч при 10 бар срабатывания → ≈ типоразмер «Е».

**32. НОВОЕ: Дыхание резервуара (АПИ 2000)**
Вход: объём резервуара, диаметр, максимальный расход заполнения/опорожнения, тип продукта.
Выход: объём дыхания при заполнении/опорожнении, требуемая пропускная способность дыхательного клапана.
Применение: проверка дыхательных клапанов, оценка потерь от испарения.
Эталон: резервуар РВС-5000 при заполнении 200 м³/ч → дыхание ≈ 200 м³/ч + поправка на испарение.

### P2b — ЖУРНАЛ ПРИКИДОК «ПРОТОКОЛ СМЕНЫ»

**33. Кнопка «Снять расчёт в протокол»** *(уточнено)*

- Название калькулятора, версию формулы.

Хранение: таблица в БД (расширение SavedCalc). Не только локально — доступно в протоколе смены и в отчёте.
Экспорт: кнопка «Экспорт протокола в PDF» с шапкой (организация, смена, дата, ФИО) — через существующий PdfReport.
Дополнительно: кнопка «Скопировать ссылку на расчёт» — для передачи коллеге (см. п. 34).

**34. Диплинк «поделиться расчётом»** *(уточнено)*
Все входные параметры упаковываются в URL (base64 или query-параметры).
Открыл коллега — видит готовый расчёт с заполненными полями и результатом.
Без сервера: всё в URL. Но есть кнопка «Сохранить на сервер» — тогда появляется в протоколе смены.
Формат: /calc/{type}?data={base64}.
Ограничение: если параметров > 30 — только серверное сохранение.

**35. Избранные / недавние** *(уточнено)*
На главной странице:
- «Недавние расчёты» — последние 5–10 (время, тип, краткий результат). Клик — открывает с сохранёнными значениями.
- «Избранные» — калькуляторы, которые пользователь добавил в избранное (закладка).
- «Быстрый старт» — типовые сценарии: «Рассчитать перепад в трубе», «Подобрать предохранительный клапан».
Фильтр: по типу (тепловые / гидравлические / свойства / смешение).

**36. НОВОЕ: Отчёт смены**
В конце смены: кнопка «Сформировать отчёт» → собирает все расчёты протокола в один документ (таблица + график).
Формат: «Смена 2, 29.11.2026, инженер Иванов. Выполнено 12 расчётов: 3 гидравлики, 4 теплообмена, 2 смешения, 3 свойства».
Экспорт: PDF с подписью (ФИО, время) — для передачи следующей смене или мастеру.

Применение: сверка материального баланса НПЗ с данными ЭВР / АСУ ТП.

### P4 — НОВОЕ: РАСЧЁТЫ, КОТОРЫХ НЕТ (мои предложения)

**40. Газопровод — перепад давления**
Вход: диаметр, длина, расход, плотность/М газа, давление на входе, шероховатость.
Выход: давление на выходе, перепад, скорость газа.
Метод: упрощённый (Веймут / Панадл А / формула для критического течения — переключатель).
Применение: проверка пропускной способности газопровода, оценка необходимости лупинга.
Эталон: газопровод Ду100, 5 км, расход 10000 Нм³/ч, газ ρ = 0.7 → перепад ≈ 0.3–0.5 бар (по Панадлу А).

**41. Колонна — проверка по фактору захлёбывания**
Вход: диаметр колонны, расход пара и жидкости, плотности, межтарельчатое расстояние.
Выход: фактическая скорость пара, скорость захлёбывания (Саудерс-Браун / Фэйр), % захлёбывания.
Предупреждение: «Если > 80% — колонна работает на пределе, возможна нестабильность».
Эталон: для колонны Ду2000 при нагрузке 8000 м³/ч пара → скорость ≈ 0.7 м/с, захлёбывание ≈ 2.5 м/с → 28%.

**42. Теплообменник — оценочный расчёт площади**
Вход: тепловая нагрузка, ΔТср (из п.10), коэффициент теплопередачи (выбор из типовых).
Выход: площадь теплообмена. Обратная задача: по площади и ΔТ → нагрузка.
Таблица типовых К: «газ–газ 30–60», «вода–масло 150–300», «конденсация пара–вода 2000–4000».
Применение: прикидка «подойдёт ли теплообменник» / «какая площадь нужна».
Эталон: нагрузка 500 кВт, ΔТср = 30 °С, К = 500 → А = 33 м².

**43. Ограничительная диафрагма / сужающее устройство**
Вход: диаметр трубы, перепад давления, плотность среды.
Выход: диаметр отверстия диафрагмы для заданного перепада / перепад для заданного отверстия.
Применение: подбор диафрагмы для ограничения расхода, защита клапана.
Формула: та же, что п.12, но для трубы.
Эталон: труба Ду50, отверстие 20 мм при расходе 5 м³/ч воды → перепад ≈ 0.5 бар.

**44. Регулирующий клапан — пропускная способность (Кv)**
Вход: расход, перепад давления, плотность (жидкость) или газ/пар + давление + температура.
Выход: Кv / Cv.
Формула: жидкость: Кv = Q·√(ρ/1000 / ΔP_бар); газ: Кв = Q·√(ρ/ΔP)·(1 + ΔP/(2·Р₁)) (упрощённо).
Применение: подбор клапана по Кв из каталога.
Эталон: вода 10 м³/ч при перепаде 1 бар → Кv = 10.

**45. Факельная линия — радиационная проверка**
Вход: расход сбрасываемого газа, теплота сгорания, высота факела, расстояние до объекта.
Выход: плотность теплового излучения на объекте (кВт/м²).
Сравнение с нормами: 1.58 кВт/м² — безопасно для длительного пребывания; 4.73 — до 1 мин; 9.46 — до 10 с.
Применение: проверка «не перегреется ли оператор / оборудование при сбросе».
Метод: точечный источник (упрощённый АР 521).
Эталон: сброс 10000 кг/ч газа с Тсгор 50 МДж/кг на высоте 30 м → на расстоянии 40 м ≈ 1.2 кВт/м² (безопасно).

**46. Продувка аппарата / депрессуризация**
Вход: объём аппарата, начальное давление, конечное давление, диаметр сбросной линии, газ.
Выход: время сброса давления (по изотермической модели), расход газа через сбросную линию.
Применение: проверка «успеем ли сбросить за 15 минут по АР 521».
Формула: τ = (V / (μ·А·а)) · ln(P₁/P₂), где а — скорость звука.
Эталон: аппарат 10 м³, сброс с 10 до 1 бар через Ду25 → ≈ 2–4 минуты.

**47. Тепловое расширение трубы**
Вход: длина трубы, материал (сталь / нержавеющая / алюминий), ΔТ.
Выход: удлинение ΔL = α·L·ΔT.
Дополнительно: усилие на опору, если труба закреплена (упрощённо).
Применение: прикидка «на сколько вырастет труба при нагреве», проверка компенсаторов.
Эталон: сталь 100 м при ΔТ = 100 °С → удлинение ≈ 120 мм.

**48. Огнезащитная подушка / водоснабжение**
Вход: площадь поверхности аппарата, тип (гладкий / с рёбрами), наличие дренажа.
Выход: расход охлаждающей воды по АР 521 / СП 155.
Применение: проверка достаточности оросительной системы.
Эталон: аппарат с поверхностью 50 м² → ≈ 10–15 л/с воды на охлаждение.

**49. Влагосодержание газа**
Вход: газ, давление, температура.
Выход: влагосодержание (г/м³), точка росы воды при данном Р.
Метод: корреляция Мак-Кетта / Бюкачарда.
Применение: оценка количества метанола для ингибирования гидратов (связка с п.28), расчёт влагоотделения.
Эталон: метан при 7 МПа 20 °С → влагосодержание ≈ 0.5 г/м³, точка росы ≈ −10 °С.

**50. Потери давления в арматуре (эквивалентная длина)**
Вход: тип арматуры (задвижка, вентиль, шаровой, обратный), диаметр, количество.
Выход: эквивалентная длина (в метрах трубы / в кол-ве скоростных напоров).
Применение: добавка к расчёту перепада давления трубопровода.
Таблица: задвижка открытая ≈ 8 Ду; вентиль ≈ 340 Ду; обратный клапан ≈ 100 Ду.
Эталон: задвижка Ду100 → эквивалентная длина ≈ 0.8 м; вентиль Ду100 → ≈ 34 м.

## ЧАСТЬ 2. ВИЗУАЛ И ЮЗАБИЛИТИ

**51. Тёмная тема + высококонтрастный режим** *(уточнено)*
Три режима: светлая / тёмная / высокая контрастность (улица, солнце, перчатки).
Переключатель в шапке. Сохранение выбора в профиле пользователя.
В режиме контрастности: увеличенные шрифты, жирные линии, чистые цвета (чёрный/белый/жёлтый), минимум серого.
Мобильный: все кнопки ≥ 44×44 пикселя (требование iOS/Android).

**52. Единица измерения прямо в поле** *(уточнено)*
Суффикс единицы в каждом поле ввода: «Диаметр, мм», «Расход, т/ч», «Давление, кгс/см²».
Автопереключение системы единиц: СИ / технические (кгс, °С) / английские (psi, °F). Сохранение выбора.
Мгновенная валидация: «Расход не может быть отрицательным», «Температура выше 500 °С — проверьте ввод».
Подсказка допустимого диапазона под полем: «Диапазон: 0–100 атм».

**53. Интерактивные номограммы** *(уточнено)*
Номограммы на SVG: Кокс (давление паров), Максвелл (теплота), Уотсон (К-фактор).
Линия проводится мышью/пальцем — результат подсвечивается.
Рядом с номограммой: та же формула + ссылка на источник (ГОСТ, справочник) + таблица контрольных точек.
Применение: доверие инженера — видит и график, и формулу, и «почему».

**54. Командная навигация** *(уточнено)*
Строка поиска в шапке. Ввёл «нпс» → открыт калькулятор NPSH. Ввёл «итк» → разбивка ИТК. Ввёл «клапан» → предохранительный.
Нечёткий поиск: опечатки, синонимы (гидравлика = труба = перепад давления).
Быстрые клавиши: «/» — фокус на поиск, «1» — конвертер, «2» — последний расчёт.

**55. Полоса доверия результата** *(уточнено)*
Цветовые зоны: зелёная (норма) / жёлтая (близко к границе) / красная (вне нормы).
Нормы: из ГОСТ / АР / СП (для каждого калькулятора — свой набор порогов).
Предупреждение о границах применимости: «Расчёт верен для жидкостей с μ < 1000 сСт. У вас 1200 — экстраполяция».
Пример: для диаметра трубы — «Скорость 5.2 м/с выше нормы 3 м/с для нефти — проверьте эрозию».

**56. Скорость** *(уточнено)*
Цель: время до первого результата < 2 секунд на среднем телефоне.
Методы:
- Все расчёты на фронте (нет сетевого запроса).
- Сжатие бандла (уже сделано в Р32).
- Ленивая загрузка калькуляторов: загружается только тот модуль, который открыт (код-сплиттинг).
- Никаких спиннеров на арифметике — результат появляется мгновенно.
- Для графики: предвычисление при вводе (не ждать кнопки «Рассчитать»).

**57. Русская документация у каждого калькулятора** *(уточнено)*
Для каждого калькулятора — вкладка «Паспорт»:
- Что считается (физический смысл).
- Входные и выходные параметры.
- Формула (в читаемом виде, с обозначениями).
- Допущения и границы применимости.
- Источник (ГОСТ, АР, справочник — с номером).
- Эталон для самопроверки.
- Кнопка «Пожаловаться на неточность» — отправляет владельцу.

**58. НОВОЕ: Пакетный расчёт с графиком**
Для каждого калькулятора — режим «диапазон»: вместо одного значения задать диапазон входного параметра (например, расход от 1 до 20 т/ч с шагом 1).
Выход: таблица + график «перепад давления от расхода».
Применение: построение характеристики системы, подбор рабочей точки.
Экспорт: график в PNG, таблица в CSV.

**59. НОВОЕ: Печать / сохранение в PDF одного расчёта**
Кнопка «Сохранить расчёт» → формирует одностраничный PDF:
- Заголовок (название калькулятора, дата, ФИО).
- Входные данные (таблица).
- Результаты (таблица + график если есть).
- Формула и источник.
- Подпись (место для подписи инженера).
Использует существующий PdfReport.

**60. НОВОЕ: Мини-справочник на полях**
В каждом калькуляторе — кнопка «?» рядом с полем. Клик → всплывающая подсказка: «Что такое ДНП и почему важно» / «Почему вводим при 20 °С».
Кратко, 2–3 предложения. Для полевых инженеров без глубокой теории.

## ЧАСТЬ 3. ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ

**61.** Все расчёты — чистый TypeScript на фронте. Никаких вычислений на сервере (кроме хранения протоколов и базы веществ).

**62.** Никакого 3Д, никаких тяжёлых зависимостей. Вся графика — рукописный SVG.

**63.** Импорт файлов — парсинг на фронте. Для .xlsx — SheetJS (если уже в проекте) или лёгкий парсер для простых таблиц. Для .csv — нативный парсер. Никаких новых пакетов без обоснования.

**64.** Каждый новый калькулятор вносится ТОЛЬКО с эталоном + самопроверкой в коде. Без эталона — не принимается.

**65. НОВОЕ:** Ленивая загрузка модулей калькуляторов. Бандл не растёт линейно с числом калькуляторов.

**66. НОВОЕ:** Все формулы хранятся в одном модуле `formulas/` с юнит-тестами. Расчётный модуль не содержит бизнес-логики — только вызов формул.

**67. НОВОЕ:** База веществ (287 шт.) доступна калькуляторам через единый интерфейс `substanceService.getSubstance(name)`. Калькулятор не читает базу напрямую.

**68. НОВОЕ:** Офлайн-режим: после первой загрузки все калькуляторы работают без сети (сервис-воркер уже есть в PWA). База веществ кэшируется локально.

## ЧАСТЬ 4. НОВОЕ: СКВОЗНЫЕ УЛУЧШЕНИЯ

**69. Пикер веществ (сквозной)**
Единый компонент «Выбрать вещество» для всех калькуляторов. Поиск по названию/формуле/ГОСТ. Автоподстановка: М, ρ при 20 °С, Ткип, Тпл, Ткрит, Ркрит, ω, константы Антуана.
Вещества: из существующей базы 287 шт. + 20–30 частых нефтепродуктов (бензин, дизель, мазут, керосин, СУГ).
Если вещества нет — кнопка «Добавить вручную» (локально, без сервера).

**70. История расчётов (локальная)**
Каждый калькулятор хранит последние 20 входов/выходов (в localStorage или IndexedDB).
Кнопка «История» — список с мини-результатами. Клик — восстановить.
Применение: «я вчера считал для этой трубы — верни».

**71. Единообразие единиц**
Пользователь выбирает систему единиц (СИ / технические / английские) один раз в профиле.
Все калькуляторы показывают результаты в выбранной системе.
Входные поля позволяют ввести в любой единице (суффикс-селектор), конвертация автоматическая.

**72. Отчёты и протоколы (развитие)**
Протокол смены (п.33–36) + отчёт по расчётам за период + выгрузка в корпоративный формат (если потребуется).
Шаблоны: «Отчёт по гидравлике за смену», «Протокол смешения бензина».

**73. НОВОЕ: Горячие клавиши для полевых**
На мобильном: жест «свайп влево» — очистить, «свайп вправо» — в протокол.
На десктопе: «С» — копировать результат, «П» — в протокол, «И» — история.

**74. НОВОЕ: Тестирование на реальных данных**
Для каждого калькулятора — 3–5 реальных примеров из практики (не только эталоны из учебников).
Пример: «На установке ЭЛОУ-АВТ при подаче 5 млн т/год нефти ρ = 0.86 перепад на печи составил 1.2 бар. Наш расчёт должен дать 1.0–1.4 бар».

## ЧАСТЬ 6. РИСКИ И ОГРАНИЧЕНИЯ

**75. Диапазоны применимости формул.**
Каждая корреляция имеет границы (давление, температура, состав). Если пользователь выходит за границы — показываем предупреждение, но не блокируем расчёт.

**76. Версии ГОСТов и стандартов.**
ГОСТы меняются. Для каждого расчёта фиксируем версию стандарта и дату. В паспорте калькулятора указываем: «Расчёт по ГОСТ 3900-85 (ред. 2020)».

**77. Ответственность за результат.**
В футере каждого калькулятора: «Результат является ориентировочным. Для проектных решений используйте верифицированные расчёты».

**78. Нагрузка самопроверки.**
Каждый эталон — это тест. При 50 калькуляторах и 3–5 эталонах на каждый — 150–250 тестов. Запуск на фронте (при загрузке страницы) должен быть < 3 секунд.

**79. Оффлайн-база.**
База 287 веществ + таблицы пара + номограммы — объём данных ≈ 2–5 МБ. Должна кэшироваться сервис-воркером без проблем.

**80. Поддержка старых браузеров.**
Пользователи в поле могут быть на старых планшетах. Минимум: Chrome 90+, Safari 14+, Firefox 90+. IE — нет.
