16:15-16:33. СТАРТ: версии владельца + замечания СС
Запрос: применить замечания Claude Code (СС) к присланным версиям владельца
(«от AI lh123» = LH1 v27 + LH2 v41 + LH3 v27; «сп4» = CG4 v13).
Сделано:
- LH3 -> v28 (Ф41/Ф41-б, «канарейка»): эталонный тест канарейки сравнивал результат
  с жёстко зашитым числом 0.9999698915, а вычисление через Log(2.7182) даёт отличие
  ~1e-9 — это роняло тест (ложный FAIL 1.16e-9 против порога 1e-9). Эталон переведён
  на вычисление через Log(2.7182); выходные константы юнитов НЕ менялись, сверка 1:1
  сгенерированного текста сохранена.
- CG4 -> v14 (Ф44..Ф47): снят запрет на вставку блока деклараций, когда включены
  определённые отладочные флаги (на входе «м2+LH1» оставались необъявленные GR_*,
  это ломало компиляцию FPC сразу на входе); сводка по GR вынесена в отдельную
  процедуру-сканер, вызываемую всегда (раньше срабатывала не во всех маршрутах);
  четыре жёстко вписанные версии заменены одной константой CG4_VER; добавлен
  Option Explicit и закрыты незаявленные переменные.
- LH1 v27 и LH2 v41 выданы без изменений (переиздание для комплекта).
Первый сбой дня: платформа отчиталась «выдано», но карточки у владельца не
отрисовались. Повторная выдача с обязательной проверкой файла перед выдачей
решила проблему (LH1_Convert_v27, LH2_Convert_v41, LH3_Convert_v28, CG4_Convert_v14).

16:33-17:3x. ПАНЕЛЬ UT4 (Utilite_4 GDC)
Запрос: книга XLSX с одним листом: фон, ячейка с путём к папке юнитов, кнопки.
Логика работы: сначала выбрать папку (путь попадает в окно), затем выбрать
конверсию (LH1/LH2/LH3/CG4). Модули владелец ставит сам, книгу сохранит как .xlsm.
Сделано:
- Книга Utilite_4 GDC (v1.01).xlsx: лист U4, синий фон, тёмно-синяя шапка,
  жёлтая объединённая ячейка пути C4:J4, пять кнопок-форм-контролов (VML) в строке 7:
  ВЫБРАТЬ ПАПКУ / LH1 (К1) / LH2 (К2) / LH3 (К4) / CG4 (К3). Сетка скрыта,
  внизу блок «Порядок работы». Проверено: все 5 кнопки присутствуют в vmlDrawing1,
  книга открывается без ошибок.
- Модуль U4_UI_v1: публичная переменная U4_PTH; выбор папки (результат пишется
  в ячейку C4 листа U4); четыре кнопки-запуска (путь из C4 -> U4_PTH -> вызов
  соответствующего конвертора -> сброс U4_PTH); пересоздание кнопок (U4_BuildUI).
- УНИВЕРСАЛЬНЫЙ ГЕЙТ ДИАЛОГА во всех конверторах (Ф7/Ф10, позже Ф43/Ф48):
  если U4_PTH непустая — диалог выбора папки пропускается; иначе конвертор
  ведёт себя по-старому. Важный нюанс: конверторы работают и в генераторе
  (там модулей 11/12/15/6, U4_UI нет), и в UT4. Итоговая механика: попытка
  запросить путь через вызов U4_GetPTH под «On Error Resume Next» — в UT4
  срабатывает (путь из C4), в генераторе тихо падает и открывается свой диалог.
- Порядок сборки для владельца: открыть xlsx -> импортировать 5 модулей ->
  сохранить как .xlsm. До импорта кнопки не найдут макросы — это норма.

17:45. ОШИБКА «SET PD - VARIABLE NOT DEFINED» (волна 1)
Запрос: в LH1 на строке создания пресетов давлений — «variable not defined»,
вопрос с раздражением: «это кончится когда-нибудь?»
Причина (установлена): разрезка LH1 на две процедуры (из-за лимита VBA
«Procedure too large», фикс Ф9) вынесла одиннадцать локальных объявлений из
тела процедуры на уровень модуля. Блок объявлений стоял ВНИЗУ файла, перед
диспетчером. При ручной вставке процедур в проект блок оставался в старом
тексте — и первая же строка диспетчера упиралась в необъявленную переменную.
Решение в этот ход: дал список 11 строк для вставки на уровень модуля +
рекомендацию импортировать модуль целиком. ЭТО БЫЛО ПОЛМЕРЫ: ошибка вернулась
(см. 18:12) — блок по-прежнему стоял внизу файла и терялся при ручной сборке.
Урок зафиксирован: радикальное решение только в 18:12 (блок перенесён в шапку).
