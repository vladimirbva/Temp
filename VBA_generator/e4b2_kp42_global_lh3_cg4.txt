3.6. БАГ замены Power→Exp в насосных блоках (главная причина A1):
   Конверторная подстановка (Module15, ветки С1а-1) превращает Power(a,b) в
   Exp(a·b·LH3_LNG2E) — а тождество: Power(a,b)=Exp(b·Ln(a)).
   LNG2E=0.9999698915=ln(2.7182) — корректна ТОЛЬКО для основания 2.7182
   (замены Power(2.7182,X)→Exp(X·LNG2E) верны: печи, « _ 2_LH3», 15 строк).
   Для прочих оснований результат мусорный. Насосные блоки (kerr 110010/110020):
     м2:   aa04:=Power((po+1)/(pi+1),0.23);  // политропный нагрев,
           Tc_out := aa04·(Tc_in+273)−273
     LH3:  aa04:=Exp(r·0.23·LNG2E)≈Exp(0.23r)  // вместо r^0.23
           r=1..10 → r^0.23 = 1.00/1.17/1.45/1.70; Exp(0.23r) =
           1.26/1.58/3.16/9.97 → +26%…+487% перегрева
     м2:   aa06:=1.3·Kpop/(1+Power(2.7182,e27+10·GTc/(35·S_PUMP)−5))
           // логистика напора по расходу
     LH3:  aa06:=1.3·Kpop/(1+Exp(2.7182·LNG2E)) = 0.0804·Kpop
           // константа: расходная зависимость потеряна
   В _LH3: ровно 22 строки «aa04:=» (44 Exp: 22 aa04 + 22 aa06).
   Канарейка, которая обязана была это поймать: тест тождества Power↔Exp.
