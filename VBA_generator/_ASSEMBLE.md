# Сборка файлов из частей (деплой 26.11.2026)

Канал GitHub-плагина ограничен ~22 КБ на один вызов, поэтому крупные конверторы
и PSR загружаются частями. Сборка — конкатенация частей по возрастанию номера
(без дополнительных разделителей, байт в байт).

## LH1_Convert_v26.txt (4 части, готовы)
```
copy /b LH1_Convert_v26.part01.txt+LH1_Convert_v26.part02.txt+LH1_Convert_v26.part03.txt+LH1_Convert_v26.part04.txt LH1_Convert_v26.txt
```

## Ожидаются следующими ходами (по команде «продолжи деплой»)
- LH2_Convert_v40.txt (~163 КБ, ~7 частей)
- LH3_Convert_v25.txt (~184 КБ, ~8 частей)
- CG4_Convert_v11.txt (~190 КБ, ~8 частей)
- VBA_GEN_PSR.txt (~260 КБ, ~10 частей)

## Контроль после сборки (обязательно)
1. Число строк: LH1 v26 = 1375; LH2 v40 = 2912; LH3 v25 = 2890; CG4 v11 = 3369.
2. Шапка первой строки: соответствующая версия («LH1 v26...», «LH2 CONVERT v40...», «LH3 CONVERT v25...», «CG4 CONVERT v11...»).
3. Прогон vba_decl_check.py по каждому собранному файлу — необъявленных 0.
4. Сверка kerr-счётчиков конвертора с журналом фиксов.
5. При расхождении сообщить ассистенту — повторная сборка части.

Примечание: исходные файлы в хранилище ассистента содержат BOM (UTF-8);
части на GitHub загружены без BOM. Для VBA-импорта в Excel это не влияет
(файлы читаются построчно).
